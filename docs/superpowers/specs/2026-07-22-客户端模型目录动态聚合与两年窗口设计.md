# 客户端模型目录动态聚合与两年窗口设计

> 历史设计：对应 `PLAN-20260722T124946657Z`。用户已取消最近两年过滤并改为返回全部可用模型，本文不得作为当前实现依据；当前权威设计和完成记录以 `PLAN-20260722T120806000Z` 为准。

## 1. 问题与证据

- 线上 `GET /models` 当前返回 Gemini 原生 `{ models: [...] }`，而 `GET /v1/models` 返回 OpenAI `{ object: "list", data: [...] }`。
- 根因是 `/models` 同时被 `isOpenAIModelsRequest()` 和 `isGeminiModelsRequest()` 判定为真，`resolveGatewayModelsResponseProtocol()` 又优先选择 Gemini。
- `GET /v1/models` 当前包含多个供应商，但网关响应读取 `default/codex` 持久化发布快照，没有使用已经计算出的 API Key 分组供应商集合。
- 当前模型目录只按 `releaseDate` 排序，没有执行“客户端只展示最近两年模型”的发布边界；2026-07-22 线上仍返回 14 个早于 2024-07-22 的 GPT 模型。
- GLM、Gemini、xAI 和部分 Anthropic 可见内置模型缺少 `releaseDate`，不能使用数据库写入时间冒充模型发布时间。

## 2. 目标

1. `/models` 和 `/v1/models` 默认返回 OpenAI-compatible 模型列表，不再因无特征请求误判为 Gemini。
2. `/v1beta/models` 或带明确 Gemini 客户端特征的 `/models` 返回 Gemini 原生模型列表；明确 Anthropic 客户端特征时返回 Anthropic 原生列表。
3. 无 API Key 的公开模型接口聚合全部已启用、非混合虚拟供应商的客户端可见目录。
4. 携带有效 API Key 时，只聚合该 Key 所绑定路由策略中全部启用分组涉及的供应商目录。
5. 内置模型在客户端列表中只保留当前 UTC 日期向前两年的模型；旧模型仍保留在计价和历史用量解析路径。
6. 网关模型列表直接复用供应商级模型目录缓存，不再读取或生成 `default/codex` 发布响应快照；AI Chat 的 `chat_list:*`、`chat_model:*` 能力快照继续保留。

## 3. 协议识别

模型列表协议按以下优先级确定：

1. 路径显式为 `/v1beta/models`：Gemini。
2. `/models` 带 `X-Juhe-Client-Profile: gemini|generic_gemini|gemini_cli`、`X-Goog-API-Key`、`key` query 或 Gemini CLI User-Agent：Gemini。
3. `/models` 或 `/v1/models` 带 Anthropic / Claude Code 明确信号：Anthropic。
4. 其余 `/models`、`/v1/models`：OpenAI。

路径本身只有 `/models` 时不得推断 Gemini，因为它同时是 OpenAI-compatible 的无版本别名。

## 4. 供应商范围

### 4.1 公开请求

- 调用 `listProvidersAsync()`，只保留 `enabled=true` 且不是 `hybrid` 的供应商。
- 对每个供应商并行调用 `listProviderModelCatalogAsync()`，复用已有进程内 / Redis 供应商目录缓存。
- 公开请求不加载个人自定义模型；仍可加载启用且允许发布的全局自定义模型。

### 4.2 API Key 请求

- API Key 校验结果中的 `group_bindings` 已包含其路由策略全部启用分组。
- 从所有 `status=active` 的 binding 收集 `provider_code`，去重后作为目录来源。
- 使用 API Key 所属 `system_account_id` 读取目录，使个人自定义模型仍按所有者作用域可见。
- 如果 API Key 没有有效供应商绑定，返回空目录，不得回退为公开全量目录。

## 5. 客户端目录筛选

每个供应商目录先独立筛选，再跨供应商合并：

- 只保留 `status=active`。
- 只保留 `catalogVisible !== false`，隐藏计价别名、测试别名和 `mapping_target_only` 模型不得暴露。
- 保持现有可计价约束；本次不把未定价模型自动开放给客户端。
- 内置模型必须有可信 `releaseDate`，且 `releaseDate >= UTC 当前日期减两年`。
- 全局 / 个人自定义模型由用户维护，不套用内置模型两年窗口，但仍受状态和发布开关约束。
- 同一模型 ID 被多个供应商提供时只返回一项；优先级依次为个人自定义、全局自定义、内置模型，再按发布时间和供应商代码稳定排序。

两年窗口按日历年计算。例如当前日期为 2026-07-22，则包含 `2024-07-22`，排除 `2024-07-21`。

## 6. 发布快照边界调整

- `fixed-responses.ts` 不再调用 `readPublishedModelCatalogResponseAsync()` 构造网关 `/models` 响应。
- `published-model-catalog.service.ts` 只负责 AI Chat 的 `chat_list:*` 和 `chat_model:*` 快照。
- 重建时用新的 chat 快照集合替换旧集合，从持久化表和缓存中自然清除历史 `default/codex` 行。
- `gateway_model_catalog_snapshots` 表、dirty 重建请求和当前未提交的 chat variant 前向迁移继续保留，因为 AI Chat 仍依赖它们。

## 7. 错误处理与缓存

- 各供应商目录并行读取；任一必需目录读取失败时整个模型接口失败，不能静默漏掉一个供应商并返回伪完整结果。
- 不新增聚合级持久化快照。供应商目录已有共享缓存，单次请求只承担有限个并行缓存读取和内存合并。
- 已认证响应继续使用 `Cache-Control: private, no-cache` 和当前 `Vary` 头，防止不同 API Key 的供应商范围互相污染。
- 公开响应可以继续由反向代理按 ETag / 压缩处理，但应用层不缓存跨日期两年窗口结果超过 UTC 日期边界。

## 8. 测试设计

- 协议回归：`/models` 默认 OpenAI；`/v1/models` OpenAI；`/v1beta/models` Gemini；明确 Gemini / Anthropic 信号分别返回对应协议。
- API Key 范围：一个 Key 绑定两个不同供应商分组时返回两者合集，不返回未绑定供应商模型。
- 公开范围：包含所有启用供应商，不包含停用供应商和 `hybrid` 虚拟供应商。
- 两年边界：包含 cutoff 当天，排除 cutoff 前一天；自定义模型不因旧发布日期被删除。
- 隐藏边界：`catalogVisible=false`、停用和内部计价别名不进入客户端响应。
- 快照边界：网关固定响应不再依赖 `default/codex` 快照；AI Chat 快照回归继续通过。
- 完整验证：模型目录回归、网关模型预认证回归、发布快照契约回归、后端 typecheck、前端 typecheck、构建和真实 HTTP 形态检查。

## 9. 风险与控制

- 供应商数量增加会增加并行缓存读取次数；通过供应商级 Redis / 本地缓存和 `Promise.all` 控制，不串行读取。
- 缺失或错误发布日期会造成误隐藏或误展示；可见内置模型必须补齐来源可追溯的日期，并用回归固定。
- API Key 路由策略修改后依赖现有 API Key validation cache 精确失效；模型接口不另建长期聚合缓存。
- 旧 `default/codex` 快照删除不能影响 AI Chat；chat variant 必须在同一轮验证中覆盖。

## 10. 发布时间来源基线

本次只接受供应商官方页面或官方 dated ID：

- Anthropic：`https://docs.anthropic.com/en/docs/about-claude/models/overview`。该页明确 Claude Fable 5 / Mythos 5 从 2026-06-09 起提供；`claude-haiku-4-5-20251001`、`claude-sonnet-4-5-20250929`、`claude-opus-4-5-20251101` 和 `claude-opus-4-1-20250805` 可直接使用 dated ID 日期，稳定别名继承同族日期。
- Gemini：`https://ai.google.dev/gemini-api/docs/models` 及各模型详情页。日期优先取官方 changelog / dated preview ID；不能把文档页面更新时间当模型发布时间。
- xAI：`https://docs.x.ai/docs/models`。官方页面内嵌当前模型清单和 alias；`grok-4.20-0309-*`、`grok-code-fast-1-0825`、`grok-imagine-image-2026-03-02` 等 dated alias 可作为日期证据。
- GLM：`https://docs.bigmodel.cn/cn/guide/start/model-overview` 及 `/cn/guide/models/*` 单模型页。`*-250414` 使用 2025-04-14；其他稳定模型必须从官方发布公告或迁移说明确认，不能使用页面 `dateModified`。
- OpenAI：沿用 `docs/functions/厂商模型目录更新与清洗指南.md` 中已核对的官方 model / pricing / deprecations 来源和现有 `releaseDate`。

任何无法从上述来源确认日期的可见内置模型在本次客户端目录中默认不发布，并由回归输出具体缺失项，不能回退数据库 `created_at`。
