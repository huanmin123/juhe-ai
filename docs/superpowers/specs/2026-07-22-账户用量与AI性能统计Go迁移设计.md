# 账户用量与 AI 性能统计 Go 迁移设计

## 目标与范围

把 Node `stats.routes.ts` 当前提供的以下只读接口以 opt-in 方式迁移到 Go：

- `GET /__aisys__/api/stats/account-usage`
- `GET /__aisys__/api/stats/account-usage/trend`
- `GET /__aisys__/api/my-stats/account-usage`
- `GET /__aisys__/api/my-stats/account-usage/trend`
- `GET /__aisys__/api/stats/ai-performance`
- `GET /__aisys__/api/stats/ai-performance/accounts`
- `GET /__aisys__/api/my-stats/ai-performance`
- `GET /__aisys__/api/my-stats/ai-performance/accounts`

本切片只读现有 PostgreSQL 预聚合表，不读取 `juhe_usage.usage_records`，不新增 writer、worker 或 migration，不登记冷窗口重算请求。Node 继续作为聚合 writer 和回滚路径。

## 契约

所有接口继续使用 System API IP limiter、认证用户 read limiter、read-only session 验证和 `Cache-Control: no-store`。`stats/*` 只允许管理员；`my-stats/*` 强制使用当前登录系统账户，忽略 `systemAccountId`。管理员 `systemAccountId` 为空或 `all` 时使用全局统计 scope，指定值时使用该账户的 `caller_account` scope。

日期按设置项 `usageStatsTimezone` 解释，最大 31 个自然日。缺失日期沿用 Node 默认：账户用量列表默认最近 31 天，趋势缺失日期归一到当天；AI 性能缺失日期默认最近 31 天，单边日期同时作为另一边。非法日期字符串按 Node 的归一化行为回落，AI 性能 handler 对非 `YYYY-MM-DD` 参数返回 400。

账户用量列表默认 `page=1`、`pageSize=10`，`pageSize` 限制到 `1..200`，总可访问窗口限制为 1000 行。排序固定为请求数、费用、输入输出 token、最后使用时间、账户 ID；显式 `accountIds` 去重并限制 50 个，附加到当前页且不重复。`trend` 去重并最多读取 10 个账户。`schedulable` 保持 Node 当前事实：接受已知值，但统计查询不据此过滤。

账户用量读取 `juhe_stats.usage_scope_range_windows`、`usage_rank_snapshots` 与 `usage_stats_daily`；trend 对范围内每个自然日补齐零值点。AI 性能读取 `usage_rank_snapshots`、`usage_stats_hourly` 与 `ai_performance_summary_windows`。所有 ID 列表、页大小、offset 和时间范围有界，SQL 不包含 raw usage 回扫、聚合函数或动态排序片段。

账户 metadata 来自 `juhe_business.accounts`、`system_accounts`、`resource_authorizations`、`group_accounts`。个人 scope 只返回当前 caller scope 已聚合且仍可映射的自有/授权账户，并标注 `owner` / `authorized`；账户用量个人 DTO 不暴露 `systemAccountId` / `systemAccountName`，但保留 owner 字段。AI 性能保持 Node/前端契约，始终返回账户 `systemAccountId`，同时返回真实 owner 字段。

AI 性能默认账户取最新 `last7d/request_count` 排名的前 10 个；显式选中账户去重后最多 20 个，并按请求顺序追加。账户筛选默认/最大 50 个，关键字采用 NFKC 后的大小写敏感名称前缀，结果与显式选中项合并去重。返回的 hourly series 为范围内每个自然小时补齐空点，平均值和最大值只在对应 count 大于零时出现。

## 代码边界

- `internal/store/port/management_stats.go`：只读输入、预聚合行和 reader 接口。
- `internal/store/postgres/managementstats.go`：固定 SQL、可见性、分页和批量读取。
- `internal/modules/managementstats/service.go`：scope、日期、合并、补零、DTO 和边界归一化。
- `internal/httpapi/management_stats.go`：admin/self handler、参数解析、错误映射。
- `internal/httpapi/router.go` 与 `internal/app/server.go`：只在 handler 完整存在时注册八条 GET。

## 验证与回滚

单元测试覆盖日期归一化、scope、分页、最多 10/20/50 个选择、权限字段、空桶补齐、平均/最大值和 handler 权限/限流/session no-touch/no-store。PostgreSQL adapter 测试固定只能读取预聚合表并限制 SQL。最低门禁为定向 `go test`、`go test ./...` 和 `go vet ./...`。真实 PostgreSQL/前端 smoke 后置；回滚只需关闭 Go management opt-in 或移除 handler 接线，Node 路由和 writer 不变。
