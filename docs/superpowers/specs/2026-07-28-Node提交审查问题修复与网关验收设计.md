# Node 提交审查问题修复与网关验收设计

## 范围

本轮只修复 2026-07-28 本地 `master` 的 Node 与 Vue 提交审查问题，不修改 Go。工作区已有未提交修改均视为并行开发成果，修复必须在其基础上增量完成。

## 修复边界

- 补齐分组字段级 PATCH 缺失的 helper，并保持 SQLite/PostgreSQL 查询、权限与字段投影一致。
- 账户表单默认值必须使用已按需加载并合并的完整供应商定义。
- Codex 大请求最终历史清理不得在 Node 主事件循环重复解析大 JSON。
- OpenAI OAuth 锁迁移必须兼容滚动发布；取消信号不得被记为真实刷新失败。
- 策略路由 PostgreSQL 更新必须在行锁后重读并校验当前模式与绑定。
- 账户显式激活、启用调度前必须校验已有套餐到期时间。
- API Key 缓存代际竞争耗尽不得伪装成凭据无效。
- SQLite 分组编辑纯读必须进入 query-only read worker。

## 验收标准

- 前后端 TypeScript 检查和构建通过。
- 每项修复都有定向回归或现有回归覆盖；并发、过期、取消、缓存代际和大正文路径均有证据。
- 网关核心鉴权、候选选择、协议适配、流式/非流式响应、重试和缓存失效回归通过。
- 使用隔离端口、隔离数据库与开发自动登录启动本地前后端；Browser 验证页面非空、无错误覆盖层、控制可交互且控制台无相关错误。

## 非目标

- 不部署生产，不修改生产数据。
- 不把 Go 迁移或 Go 测试纳入本轮完成条件。
- 不清理或回退与本轮无关的工作区修改。
