# 分组渐进加载契约对齐实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Go 管理端 / 个人端分组读取契约与最新 Node 的静态列表、独立状态快照和轻量授权下拉一致。

**Architecture:** 列表 service 只组装静态 DTO、预聚合账户计数和授权来源摘要；新的 status snapshot service 使用专用可见行查询，再批量读取预聚合并发与当天 usage。授权 grantee groups 与 group authorization options 使用独立最小投影，避免复用重型 option DTO。

**Tech Stack:** Go 1.26、chi、pgx/sqlc、PostgreSQL、标准库 `net/http` / `encoding/json` / `testing`。
