# AI Composer Interaction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复富文本块与发送快捷键冲突，并完成底栏宽度、上下文提示和按钮位置优化。

**Architecture:** 将键盘决策和宽度计算拆成无 DOM 纯函数，`AIComposer.vue` 只负责把 Tiptap 状态映射到决策并执行副作用。结构块普通 Enter 返回 `false` 交给 StarterKit；命令查询始终从当前 selection 的 textblock 解析。

**Tech Stack:** Vue 3、TypeScript、Tiptap 3、ProseMirror、Ant Design Vue、Node assert 回归脚本
