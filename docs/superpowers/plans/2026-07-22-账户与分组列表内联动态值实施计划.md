# 账户与分组列表内联动态值实施计划

## 完成标准

- [x] 账户列表响应保留动态字段，并在服务端补齐当前页用量、API Key 运行态和 runtime snapshot。
- [x] 分组列表响应在服务端批量计算当前页并发和当日用量。
- [x] 前端账户、分组列表移除自动 `status-snapshot` 请求、分批 helper 和快照合并逻辑。
- [x] 保留显式快照接口，不让其参与列表加载。
- [x] 增加内联列表回归并更新接口契约文档。

## 验证

1. 运行账户列表投影回归，确认动态字段随列表返回。
2. 运行账户、分组前端内联回归，确认无额外快照请求。
3. 运行并发快照和不可用契约回归，确认显式快照接口保持兼容。
4. 运行前端类型检查与生产构建；后端完整类型检查若环境缺少既有依赖，记录具体缺失项。
