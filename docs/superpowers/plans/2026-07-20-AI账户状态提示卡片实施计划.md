# AI 账户状态提示卡片 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为所有 AI 账户有效状态提供单一、用户导向且时间语义可靠的状态 presentation，并让完整列表与 30 秒状态快照持续返回一致摘要。

**Architecture:** 后端新增纯 presentation 构造器，按 effective availability 选择唯一主状态，并把最近检查 observation、下次计划 schedule 与业务状态边界分开。完整列表和状态快照复用构造器；前端只消费 presentation，不再拼接健康、冷却、运行态、来源和 Key 池底层字段。

**Tech Stack:** Node.js 22、TypeScript、SQLite / PostgreSQL、Redis runtime state、Vue 3、Ant Design Vue、pnpm、tsx regression scripts
