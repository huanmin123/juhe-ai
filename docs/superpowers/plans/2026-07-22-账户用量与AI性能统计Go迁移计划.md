# 账户用量与 AI 性能统计 Go 迁移实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不触碰统计 writer 和 raw usage 的前提下，以 Go opt-in 提供账户用量与 AI 性能 admin/self 只读接口。

**Architecture:** 扩展现有 `managementstats` 服务复用 timezone 缓存和 System API 读链路；新增只读 port 与 PostgreSQL adapter。服务负责 Node 契约归一化和 DTO 组装，store 只执行有界固定 SQL。

**Tech Stack:** Go 1.24、chi、pgx v5、PostgreSQL、标准库 `testing`。
