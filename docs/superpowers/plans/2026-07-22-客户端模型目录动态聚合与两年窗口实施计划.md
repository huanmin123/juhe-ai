# 客户端模型目录动态聚合与两年窗口实施计划

> 历史计划：本方案登记为 `PLAN-0153-20260722T124946657Z`，但用户已取消最近两年过滤并改为返回全部可用模型。不得继续执行本文，最终实现以 `PLAN-0152-20260722T120806000Z` 为准。
>
> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 `/models` Gemini 误判，按公开全部启用供应商或 API Key 路由分组供应商动态聚合客户端模型目录，并对内置模型执行滚动最近两年窗口。

**Architecture:** 网关模型接口绕过 `default/codex` 发布响应快照，直接并行读取已有供应商级目录缓存。纯函数负责协议识别、两年窗口和跨供应商去重；AI Chat 继续使用 `chat_list:*` / `chat_model:*` 持久化快照。

**Tech Stack:** Node.js、TypeScript、Express、SQLite/PostgreSQL repository、Redis shared cache、tsx 回归脚本。
