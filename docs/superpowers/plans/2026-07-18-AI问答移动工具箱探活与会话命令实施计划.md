# AI 问答移动工具箱、探活与会话命令实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 用户明确要求本次不提交、不推送、不部署，因此所有 commit 步骤均省略，由主 Agent 在共享隔离工作树中复核每个增量。

**Goal:** 彻底删除登录会话管理，并完成 AI 问答手机工具箱、手动上下文动作、5 秒 SSE 探活、10 秒权威确认、动态思考、失败尾轮重试和真实验收环境。

**Architecture:** 登录会话管理按产品撤销从前端、Go 灰度后端、配置、查询、测试和当前事实文档完整删除。聊天新增能力继续使用现有 Node Chat 模块、独立聊天存储、generation registry、SSE 和 IndexedDB，不引入 WebSocket 或第二套运行时；transport heartbeat 只更新活动时间，submission status 和 sync 才是终态事实源。移动工具使用应用壳 Teleport 容器，输入工具箱仍由 `AIComposer` 所有；手动压缩和清空是服务端确认动作，发送、重试、图片预览、重命名和置顶使用可回滚乐观投影。

**Tech Stack:** PowerShell 7、Vue 3、TypeScript、Ant Design Vue、Tiptap、Node.js/Express、SQLite/PostgreSQL 抽象、Go 1.26.5、sqlc、Codex 内置浏览器。

**Authoritative Spec:** `docs/superpowers/specs/2026-07-18-AI问答移动工具箱与探活设计.md`
