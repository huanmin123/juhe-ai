# 页面级版本确认聚合实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不升级 page-data v2 协议、不新增数据库 schema 的前提下，将 `/my-accounts` 分散的 confirm 收敛为页面级有界批次，并补齐 mutation/lifecycle 围栏与 read 限流语义。

**Architecture:** 新增独立 activation coordinator 负责三域登记、50ms pre-confirm 收集、一次 post-confirm barrier、token 冲突和 writeEpoch；现有 `PageDataCacheController` 继续负责 IndexedDB、GET、delta 和 CAS。`/my-accounts` 使用一个 lifecycle scheduler，后端只修正 confirm 的限流分类并保持现有 v2 Redis 单 EVAL 契约。

**Tech Stack:** Vue 3、TypeScript、IndexedDB、BroadcastChannel、Axios、Node.js 22、Express、PostgreSQL session、Redis、pnpm、tsx、Go 回归。
