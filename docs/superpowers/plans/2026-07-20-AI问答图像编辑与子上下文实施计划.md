# AI 问答图像编辑与子上下文 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 用户已要求当前会话直接执行，且未授权暂存、提交或推送，因此本计划不包含 Git 写操作。

**Goal:** 让 AI 问答能以同会话 `assetId` 为稳定引用对生成图片进行二次编辑，并提供会话级默认图像模型命令。

**Architecture:** 主对话只装载有界图像谱系元数据，图片像素只在内部图像工具执行时从受控资产存储读取。后端注册表选择 `gpt-image-2` 适配器，生成走 JSON `/v1/images/generations`，编辑走 multipart `/v1/images/edits`；前端只操作模型设置和资产引用。

**Tech Stack:** Node.js 22、TypeScript、Express、SQLite/PostgreSQL 双驱动 SQL、Vue 3、Ant Design Vue、Tiptap、Sharp、SSE。
