## 验收标准

- task payload 不含凭据、URL、代理秘密或原始请求/响应。
- 排队后账户 config revision 变化时不使用新配置执行旧任务，request fingerprint 能检测同 run ID 的不可变事实漂移。
- 排队跨部署仍使用 payload 固定的 `probeSetVersion`；基础设施重试从 probe checkpoint 续跑，不重复已完成探针。
- 重复任务、worker crash 和重试不会重复 item/observation，也不会改变既有终态。
- `canceled` 不能被晚到 `completed/failed` 覆盖。
- SSE 客户端断开后任务继续，显式 stop 能在 deadline 内终结为 canceled。
- stale running 有界恢复并带安全原因码。
- Node 单 owner 删除前，Go 真实依赖和前端联调证据完整。
