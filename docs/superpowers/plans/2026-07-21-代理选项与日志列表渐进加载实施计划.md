# 代理选项与日志列表渐进加载实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Node 生产 owner、Go opt-in 和 Vue 前端中统一代理按需加载及两类日志窄列表契约，并用 SQLite、真实 PostgreSQL、浏览器和仓库级门禁完成验证。

**Architecture:** 账户列表/基础详情直接投影有权限展示的代理最小字段，代理 options 仅服务编辑下拉；操作日志和公开 API 日志分别建立专用 ListItem、SQL 投影和 mapper，详情路径不变。Node/Go 共同接口保持等价，生产 owner 不切换。

**Tech Stack:** Vue 3、TypeScript、Ant Design Vue、Express、SQLite、PostgreSQL、Go、sqlc、pnpm、浏览器网络验证。
