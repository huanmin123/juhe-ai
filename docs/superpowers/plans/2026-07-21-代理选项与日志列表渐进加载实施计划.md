# 代理选项与日志列表渐进加载实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让账户页面的代理候选真正按交互加载，并让操作日志、公开 API 日志列表从 repository 开始使用窄投影，同时保持权限、筛选、分页和详情契约。

**Architecture:** 代理 options 保留现有路由，增加有界 `selectedIds` 补齐，并以独立 composable 管理身份隔离缓存、搜索和竞态。两类日志分别新增 ListItem 类型、显式 SELECT 和 mapper，详情继续使用既有 Summary/Detail 查询；前端列表只消费 ListItem。

**Tech Stack:** Vue 3、TypeScript、Ant Design Vue、Express、Zod、SQLite、PostgreSQL、pnpm/tsx 回归脚本。

---

## 文件结构

- `backend/src/modules/proxies/proxies.routes.ts`：解析和校验代理 options 查询参数。
- `backend/src/storage/proxy.repository.ts`：SQLite/PostgreSQL 窄候选窗口与已选项补齐。
- `backend/src/storage/sqlite-read-worker-pool.types.ts`：传递新增代理查询参数和日志 ListItem 结果类型。
- `backend/src/scripts/regression/proxy-options-progressive-http-regression.ts`：代理 HTTP 字段、边界和已选项补齐测试。
- `frontend/src/views/accounts/useAccountProxyOptions.ts`：代理候选的按需加载、缓存、搜索和竞态控制。
- `frontend/src/views/accounts/AccountsView.vue`、`AccountEditModal.vue`、`AccountStrategySection.vue`、`AccountBatchEditModal.vue`：接入首次展开和搜索事件。
- `frontend/src/scripts/regression/account-proxy-options-lazy-loading-regression.ts`：真实 composable 行为测试。
- `backend/src/storage/operation-log-types.ts`、`operation-log-mappers.ts`、`operation-log-read.repository.ts`：操作日志 ListItem 契约和窄查询。
- `backend/src/modules/operation-logs/operation-logs.routes.ts`：直接返回 repository ListItem，不再 route 裁剪完整 Summary。
- `frontend/src/types/domain/operation-logs.ts`、相关列表组件：消费 `OperationLogListItem`，详情类型不变。
- `backend/src/scripts/regression/operation-log-list-lightweight-regression.ts`：字段白名单、权限和详情兼容测试。
- `backend/src/storage/public-api-logs.repository.ts`：公开 API 日志 ListItem、显式查询和 mapper。
- `frontend/src/types/domain/public-api-logs.ts`、`PublicApiLogsView.vue`、列表组件：消费窄列表并使用 50 行窗口。
- `backend/src/scripts/regression/public-api-log-list-lightweight-regression.ts`、`frontend/src/scripts/regression/public-api-log-page-window-regression.ts`：HTTP/查询和分页行为测试。
- `docs/functions/接口契约与权限矩阵.md`、`docs/functions/安全与日志策略.md`、审计报告：同步当前事实和剩余 backlog。
