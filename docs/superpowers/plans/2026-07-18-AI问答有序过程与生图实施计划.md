# AI 问答有序过程与生图实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 AI 问答的即时消息、过程顺序、终态工具栏和代码高亮，并打通直接 `gpt-image-2`、普通 GPT 托管生图与持久化图片资产。

**Architecture:** 后端以纯 `assistant timeline` 状态机作为有序内容块唯一来源；Chat/Responses/Images 三种上游入口都包装为同一站内 SSE 和消息终态。图片结果先增量写临时对象，再通过资产引用关系与助手消息终态事务提交；前端以块级 reducer 和双消息乐观投影渲染同一顺序，并将过程块展开状态独立于消息内容保存。

**Tech Stack:** Node.js + TypeScript、Vue 3 + TypeScript、SQLite/PostgreSQL chat schema、SSE、`sharp`、highlight.js、KaTeX、Mermaid、Codex 内置浏览器。
