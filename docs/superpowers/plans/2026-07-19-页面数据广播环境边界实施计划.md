# 页面数据广播环境边界实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 阻止页面数据默认标签页协调器在 Node.js/SSR 环境误启用 BroadcastChannel，同时保留真实浏览器和显式注入 channel factory 的现有行为，并安全提交当前本地改动。

**Architecture:** 只在 `BrowserPageDataTabCoordinator` 的默认 channel factory 选择处增加真实浏览器环境判断。显式传入 `channelFactory` 时仍优先使用注入值，因此现有多标签页协议测试和浏览器行为不变；Node.js 默认退化为无通道的单实例协调。

**Tech Stack:** Vue 3、TypeScript、Node.js 22、pnpm、BroadcastChannel
