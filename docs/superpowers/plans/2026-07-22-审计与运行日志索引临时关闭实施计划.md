# 审计与运行日志索引临时关闭 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用两个默认启用的部署开关临时停止原始审计和运行日志搜索索引的新写入，保留正常日志文件与全部使用记录业务，并在生产验证后清理对应历史数据。

**Architecture:** `runtimeConfig.auditLog.enabled` 和 `runtimeConfig.log.indexEnabled` 是唯一配置事实源。审计在 capture/queue/transport/consumer 边界短路；运行日志只在文件 importer 和索引维护调度边界短路，Pino 文件输出与 grep 保持工作。生产按 temporary-first 发布，最后独立清理审计三介质和五张运行日志索引表。

**Tech Stack:** Node.js 22、TypeScript、Express、Pino、PostgreSQL、Redis Streams、PowerShell 7、macOS launchd、Nginx。
