# 开发环境安全启动策略实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让非生产环境不因安全策略阻止启动，同时保留生产环境的安全 fail-fast 和所有功能性配置校验。

**Architecture:** 将启动校验分成安全策略校验与功能性配置校验。安全策略在非生产环境只记录告警或允许继续，在生产环境继续抛错；功能性配置无论环境都继续 fail-fast。开发自动登录的监听地址限制属于安全启动策略，生产环境仍禁止。

**Tech Stack:** Node.js、TypeScript、tsx 回归脚本、Vue/Vite 开发配置、Markdown 运行文档。
