# 页面数据确认接口 Go 迁移实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `POST /__aisys__/api/data-changes/confirm` 迁移到 Go，同时保持 Node v2 page-data、鉴权、错误和 Redis 快路径契约。

**Architecture:** HTTP handler 只负责严格 JSON、认证角色和状态码；`app` adapter 负责把认证主体转换为现有 Redis scope 并调用 `PageDataChangeConfirmer`。router 把 POST 放在 read auth / read rate-limit 链，避免 session touch；publisher 与 Redis Lua 协议保持不变。

**Tech Stack:** Go 1.26、chi、encoding/json、management Cookie auth、go-redis v9、现有 page-data Lua。
