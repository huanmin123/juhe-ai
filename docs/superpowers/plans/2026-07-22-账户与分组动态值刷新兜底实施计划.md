# 账户与分组动态值刷新兜底 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复账户与分组列表刷新后动态值缺失，在列表直接值可用时零额外请求，否则以有界批量快照兜底，并保持 Redis 失败时的可信降级语义。

**Architecture:** 静态列表继续走现有分页与页面缓存；前端在每次列表成功装载后判断动态字段是否完整，仅对缺失 ID 分批请求状态快照。Node 分组快照通过一次成员关系批量读取和一次 Redis 并发批量读取计算真实值，并返回显式可用性标记；前端只在同作用域内保留上一份可信动态值。

**Tech Stack:** Vue 3、TypeScript、Express、Node.js、PostgreSQL/SQLite adapter、Redis runtime state、pnpm regression scripts。
