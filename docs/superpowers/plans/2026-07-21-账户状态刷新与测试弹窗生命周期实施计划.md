# 账户状态刷新与测试弹窗生命周期实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 取消账户列表状态快照自动刷新，把测试任务轮询改为 3s、会话心跳改为 5s，关闭测试弹窗时统一取消后端测试，并让测试默认模型/请求形态直接来自账户列表字段（含 Go 列表契约补齐）。

**Architecture:** 前端账户列表移除状态快照轮询生命周期，仅保留完整列表加载与用户主动刷新。测试弹窗的轮询/心跳常量下调，关闭入口统一走取消链路。Go 管理账户列表在现有行查询中补齐 `health_check_model` / `health_check_endpoint_mode` 投影到 JSON，Node 只做防回退断言。

**Tech Stack:** Vue 3 + TypeScript 前端回归脚本、Node/TypeScript 账户列表契约、Go management account list + sqlc + PostgreSQL adapter。

**Design:** `docs/superpowers/specs/2026-07-21-账户状态刷新与测试弹窗生命周期设计.md`

- 不删除后端状态快照接口。
- 不读取生产密钥到文档；真实模型测试仅在用户要求且确有必要时使用。
