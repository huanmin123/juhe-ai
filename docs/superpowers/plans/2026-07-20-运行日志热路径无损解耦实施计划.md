# 运行日志热路径无损解耦实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将运行日志索引从业务进程和 Redis producer 热路径迁移到 ingest-worker 的文件游标消费，并在不丢原始日志的前提下消除 1500ms 客户端假超时与重连放大。

**Architecture:** Pino 只把完整 JSON Lines 顺序追加到按进程角色隔离的日志文件。ingest-worker 以受控目录扫描发现当前和轮转文件，按持久 `file_identity + offset` 读取完整行，批量写入当前数据库并在提交成功后推进游标；业务进程不再解析日志或连接运行日志 Redis Stream。运行日志索引运行态改为文件 backlog/cursor 指标。

**Tech Stack:** Node.js 22、TypeScript、Pino、Node fs stream、SQLite/PostgreSQL repository、pnpm、tsx 回归脚本、真实 PostgreSQL/Redis smoke。
