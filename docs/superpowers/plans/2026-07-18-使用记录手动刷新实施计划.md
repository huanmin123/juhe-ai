# 使用记录手动刷新 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 移除“我的使用记录”和“使用记录管理”的前端 IndexedDB 列表缓存与 15 秒自动确认，保留所有显式加载入口和后端查询优化。

**Architecture:** `UsageRecordsView.vue` 继续使用 `useResponsivePagedList` 管理筛选、分页、移动端刷新和请求竞态，但数据获取直接调用 scoped `usageRecordsApi.list`。后端首屏热缓存、分页 repository 和 `usage.records` 数据域保持不变；源码回归固定前端不得重新接入页面数据确认器。

**Tech Stack:** Vue 3、TypeScript、Ant Design Vue、Node.js 22、pnpm、tsx 源码回归
