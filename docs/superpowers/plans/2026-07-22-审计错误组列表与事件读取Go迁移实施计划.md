# 审计错误组列表与事件读取 Go 迁移 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在保持 Node 审计 writer、payload、hot search、runtime、worker 和保留治理 owner 不变的前提下，把管理员错误组列表与错误组事件列表迁移为 Go opt-in 只读路径，并以 Go 原生的 context、PostgreSQL store 和有界 progressive pagination 实现。

**Architecture:** 扩展现有 `managementauditlogs` 纵切面。错误组列表增加独立 store port 和 PostgreSQL 摘要查询；错误组事件不复制查询，而是在 service 层强制路由 `errorGroupId` 后复用现有审计列表。HTTP 使用三个显式 handler（日志列表/详情、错误组列表、错误组事件）共享鉴权与 120 秒 deadline，router 静态路径先于 `/{id}` 注册。任何确认的 Node 缺陷先写 RED 测试和差异记录，再在 Go 修复，不机械复制 Node 运行时胶水。

**Tech Stack:** Go 1.26、chi、pgx v5、PostgreSQL 18、Goose、testcontainers-go、Node.js 22/TypeScript 对照回归、PowerShell 7、Git。

Service 输入与执行骨架固定为：

```go
type ErrorGroupListInput struct {
	Path, Model, SystemAccountID string
	APIKeyID, GroupID, AccountID string
	StatusCode, Page, PageSize   int
	PageSizeProvided             bool
}

type ErrorGroupListResult struct {
	Items    []ErrorGroup `json:"items"`
	Total    int          `json:"total"`
	HasMore  bool         `json:"hasMore"`
	Page     int          `json:"page"`
	PageSize int          `json:"pageSize"`
}

func (s *Service) ListErrorGroups(ctx context.Context, input ErrorGroupListInput) (ErrorGroupListResult, error) {
	if s.store == nil {
		return ErrorGroupListResult{}, fmt.Errorf("management audit log reader is required")
	}
	page, pageSize := normalizeListWindow(input.Page, input.PageSize, input.PageSizeProvided)
	result, err := s.store.ListManagementAuditErrorGroups(ctx, port.ManagementAuditErrorGroupListInput{
		Path: normalizePath(input.Path), Model: trim(input.Model), StatusCode: normalizeStatusCode(input.StatusCode),
		SystemAccountID: trim(input.SystemAccountID), APIKeyID: trim(input.APIKeyID),
		GroupID: trim(input.GroupID), AccountID: trim(input.AccountID),
		Limit: pageSize, Offset: (page - 1) * pageSize,
	})
	if err != nil {
		return ErrorGroupListResult{}, err
	}
	items := make([]ErrorGroup, 0, len(result.Items))
	for _, row := range result.Items {
		items = append(items, errorGroup(row))
	}
	total := (page-1)*pageSize + len(items)
	if result.HasMore {
		total++
	}
	return ErrorGroupListResult{Items: items, Total: total, HasMore: result.HasMore, Page: page, PageSize: pageSize}, nil
}
```
