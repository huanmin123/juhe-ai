# 全系统日志治理实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (recommended) or superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Node、Go、worker、DB service 和运行时日志基础设施中建立统一、默认开启、逐阶段、异步且有界的日志体系，同时完整保留失败现场证据。

**Architecture:** 运行时日志、原始审计、操作日志和公开 API 日志继续保持独立的保留周期与权限语义，但共享事件、链路、耗时和失败契约。Node 使用有界发布器与独立写线程，Go 使用有界 `slog.Handler` 通道与写入 goroutine。过载时普通 info 事件允许按规则丢弃并记录统计，不可预知失败使用预留容量和主日志兜底，且不得阻塞业务请求。

**Tech Stack:** Node.js 22, TypeScript, Pino, worker_threads, Express, Go, `log/slog`, PostgreSQL, Redis Streams, SQLite cursor index, pnpm, Go test.
