# 下拉接口轻量化与账户测试模型按需加载实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将账户测试模型选择改为默认当前账户检查模型、候选模型按需加载，并把全站选择器接口收敛为轻量 DTO。

**Architecture:** 账户列表行提供默认检查模型和请求形态；后端把账户测试拆成轻量模型数组与单模型能力两个 HTTP 投影；前端测试弹窗只在选择器展开时加载列表，切换模型时按 ID 获取请求形态。其他 `*/options` 接口沿用现有路由但改为独立最小查询或最小 DTO，详情和能力继续由专用接口提供。

**Tech Stack:** Node.js/TypeScript/Express、SQLite/PG repository、Vue 3、Ant Design Vue、pnpm 回归脚本。
