# 响应检查策略 Go 迁移 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以 TDD 为管理端响应检查策略提供 Go opt-in CRUD，并保持 Node 契约、共享 schema、事务后失效和有界操作日志语义。

**Architecture:** 业务校验和事务 orchestration 位于独立 module，PostgreSQL store 复用现有 pool 访问 Node 共享表，HTTP 层负责 admin-only、strict JSON、mutation guard 和 operation log，router/app 只在 handler opt-in 时注册。

**Tech Stack:** Go 1.26、chi、pgx、现有 Redis gateway invalidator、现有 Asynq operation-log enqueue。
