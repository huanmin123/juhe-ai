# 运行日志索引保留清理实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不切换 Node writer/生产 owner 的前提下，提供事务安全、可取消、可独立组装的 Go runtime log index retention 能力。

**Architecture:** service 固定 cutoff 并编排两个有界批处理循环，默认以 `GoExclusiveIndexCleanupOwner=false` fail-closed，只有 Node cleanup 子 owner 已停止才允许索引删除；PostgreSQL store 用 try-advisory 去重、`SKIP LOCKED` 选删和 `NOWAIT` summary 行互斥组成短事务，不使用 facet 表锁；锁竞争整批回滚并记为 deferred，cursor 使用独立稳定小批删除；app worker 只负责连接、调度和日志。

**Tech Stack:** Go 1.26、pgx v5、PostgreSQL、标准库 context/time/slog/testing。
