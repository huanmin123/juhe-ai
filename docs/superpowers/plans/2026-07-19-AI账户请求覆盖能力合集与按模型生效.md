# AI 账户请求覆盖能力合集与按模型生效实施计划

> 执行要求：在隔离 worktree 的 `codex/account-request-overrides-union-20260719` 分支按测试先行顺序实施；每个 RED 必须确认失败原因是旧契约，每个 GREEN 必须重新运行原命令。

**目标：** 让服务等级和思考级别按已选模型能力合集配置，并在最终模型精确支持时逐字段覆盖；GPT API Key 与 OAuth 使用同一 Flex 规则，不支持或能力未知时保留客户端字段。

**架构：** 前端 helper 负责 provider 能力边界、已选模型能力合集、可用/失效选项和禁用提示；账户保存/导入服务只校验覆盖值至少被一个已知已选模型支持；provider driver 在模型映射和协议转换结束后计算逐字段有效覆盖。语法错误、provider 无 wire 映射和 bridge 无法安全转换仍使用既有明确错误，最终模型不支持账户覆盖则跳过该字段。

**技术栈：** Vue 3、TypeScript、Ant Design Vue、Node.js、provider driver、tsx 回归脚本、pnpm。
