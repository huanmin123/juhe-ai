# Go 持久化记录异步派发与有界致命输出实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Go 管理操作日志和公开接口日志的外部队列访问移出 HTTP 响应路径，并保证所有命令的 fatal 输出遇到永久阻塞 writer 时仍能有界返回。

**Architecture:** 新增独立的泛型 `recorddispatch.Dispatcher[T]`，用固定 worker、非阻塞提交、关联上下文快照和有界 shutdown 承载 best-effort 记录任务。HTTP 层通过窄 submitter 接口提交 operation/public input，应用装配层拥有 dispatcher 与 Asynq client 的生命周期；fatal 输出保留现有编码与脱敏，只把最终 writer 调用改成最多等待 250 ms。

**Tech Stack:** Go 1.26、context、泛型、channel、sync/atomic、Chi HTTP、Asynq/Redis、标准库测试与 race detector。

- [ ] **Step 1: 写失败测试，固定非阻塞提交、上下文和关闭契约**

在 `dispatcher_test.go` 中建立阻塞 handler，并覆盖：

1. `Submit` 在 handler 阻塞时 100ms 内返回 true。
2. worker 收到的 `logging.LogContext` 保留 TraceID/RequestID。
3. 容量为 1 且 worker 阻塞时，第三次提交立即返回 false 且 Dropped 增加。
4. handler 返回错误时 Failed 增加。
5. Shutdown 后 Submit 返回 false。
6. handler 忽略 context 永久阻塞时，Shutdown 返回 context.DeadlineExceeded。

核心断言示例：

```go
func TestDispatcherSubmitDoesNotWaitForHandler(t *testing.T) {
        release := make(chan struct{})
        started := make(chan logging.LogContext, 1)
        dispatcher := New(Options[string]{
                Capacity: 1,
                Workers:  1,
                Timeout:  time.Second,
                Handle: func(ctx context.Context, value string) error {
                        started <- logging.LogContextFrom(ctx)
                        <-release
                        return nil
                },
        })
        ctx := logging.WithLogContext(context.Background(), logging.LogContext{
                TraceID: "trace-1", RequestID: "request-1",
        })
        startedAt := time.Now()
        if !dispatcher.Submit(ctx, "record-1") {
                t.Fatal("Submit() = false, want true")
        }
        if elapsed := time.Since(startedAt); elapsed > 100*time.Millisecond {
                t.Fatalf("Submit blocked for %s", elapsed)
        }
        got := <-started
        if got.TraceID != "trace-1" || got.RequestID != "request-1" {
                t.Fatalf("log context = %+v", got)
        }
        close(release)
        shutdownCtx, cancel := context.WithTimeout(context.Background(), time.Second)
        defer cancel()
        if err := dispatcher.Shutdown(shutdownCtx); err != nil {
                t.Fatalf("Shutdown() error = %v", err)
        }
}
```

- [ ] **Step 3: 实现最小 dispatcher**

`dispatcher.go` 公开契约：

```go
package recorddispatch

type Options[T any] struct {
        Capacity int
        Workers  int
        Timeout  time.Duration
        Handle   func(context.Context, T) error
}

type Stats struct {
        Accepted  uint64
        Completed uint64
        Failed    uint64
        Dropped   uint64
        Pending   int64
}

type Dispatcher[T any] struct {
        options   Options[T]
        queue     chan job[T]
        acceptMu  sync.RWMutex
        accepting bool
        stopOnce  sync.Once
        done      chan struct{}
        workers   sync.WaitGroup
        accepted  atomic.Uint64
        completed atomic.Uint64
        failed    atomic.Uint64
        dropped   atomic.Uint64
        pending   atomic.Int64
}

type job[T any] struct {
        context logging.LogContext
        value   T
}
```

行为要求：

- `Submit` 在 `acceptMu.RLock` 内检查 accepting，并使用非阻塞 channel 发送。
- 成功时 accepted/pending +1；失败时 dropped +1。
- worker 用 `logging.WithLogContext(context.Background(), job.context)` 恢复关联，再为每个任务建立 `context.WithTimeout`。
- `Shutdown` 在写锁内将 accepting 设为 false，只关闭一次 queue，等待 WaitGroup 或调用方 context。

```go
const fatalWriteTimeout = 250 * time.Millisecond

func WriteFatal(writer io.Writer, err error) {
        if writer == nil {
                return
        }
        message := ""
        if err != nil {
                message = sanitizeFatalMessage(err.Error())
        }
        encoded := marshalBoundedFatal(message)
        done := make(chan struct{}, 1)
        go func() {
                defer func() {
                        _ = recover()
                        done <- struct{}{}
                }()
                _, _ = writer.Write(encoded)
        }()
        timer := time.NewTimer(fatalWriteTimeout)
        defer timer.Stop()
        select {
        case <-done:
        case <-timer.C:
        }
}
```
