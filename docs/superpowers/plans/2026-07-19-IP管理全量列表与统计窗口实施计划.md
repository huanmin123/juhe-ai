# IP 管理全量列表与统计窗口实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** IP 管理列表始终覆盖全部已注册 IP，状态与搜索筛选作用于全量 IP，时间范围只决定每行展示的统计数据。

**Architecture:** `client_ip_registry` 继续作为 IP 清单事实源，Node SQLite/PostgreSQL 与 Go PostgreSQL 列表查询都从注册表出发，按所选 `start_date/end_date` 左连接 `client_ip_usage_range_windows`。缺少当前范围统计行时保留 IP，并通过现有映射逻辑把统计字段归零；策略状态仍通过注册表 IP hash 查询 active policy。前端继续提交统计范围，不新增接口或页面状态。

**Tech Stack:** Node.js 22/24、TypeScript、SQLite/PostgreSQL、Go、sqlc、Vue 3、项目回归脚本。
