# 产品与品牌边界

> 面向产品界面和前端实现。
> 本文记录项目级前端产品、品牌和配置边界；通用页面结构、样式、表格、表单和交互规范仍参考 [样式规范.md](样式规范.md)。
> 前端架构入口见 [README.md](README.md)。

## 1. 设计定位

- 前端是轻量管理后台，不通过配置系统承载页面设计稿。
- 页面结构、入口跳转、登录页角标、副标题和装饰样式属于前端设计，应该写在前端代码和设计文档中。
- 配置只承载确实需要管理员在运行时调整的内容，不把页面文案和视觉风格泛化成配置项。

## 2. 全局品牌边界

全局展示配置只允许包含：

- `系统名称`：用于左侧菜单标题、浏览器标签页，以及登录页主标题的名称部分。
- `系统图标路径`：用于应用图标、左侧菜单图标和登录页品牌图标。

不作为全局配置的内容：

- 登录页标题完整文案。
- 登录页角标。
- 登录页副标题。
- 登录页视觉样式和入口跳转逻辑。
- 页面布局和装饰效果。

## 3. 登录页设计规则

- 登录页主标题固定为“系统名称 + 管理平台”。例如系统名称为“聚合 AI”时，标题展示为“聚合 AI 管理平台”。
- 登录页角标固定为“统一接入平台”。
- 登录页副标题固定为“统一接入、统一调度、统一可观测。”
- 登录页风格、背景、动效和信息卡片由前端设计决定，不提供后台配置项。
- 如果后续要调整登录页文案或视觉，应修改本文和前端实现，而不是新增全局配置字段。

## 4. 应用壳视觉一致性

- 应用壳（侧栏、顶栏、页头、内容底色）与登录页共享「纸墨澄明」视觉语言：暖纸底、墨色文字、青灰点缀、笔刷线装饰。
- 主题令牌的权威定义在 [样式规范.md](样式规范.md)；本文件只定边界：应用壳视觉属于前端设计，不提供后台配置项；系统名称与系统图标在侧栏/页头的展示语义不变。
- 默认品牌图标（`frontend/public/brand-icon.svg`，侧栏品牌区与浏览器 favicon 共用）与登录页同源：白 sparkle 图案置于墨→青渐变（`--juhe-primary-grad`，#22282b→#53696b）圆底之上，渐变底自包含于 SVG 资源内；侧栏品牌区直接展示该资源，不叠加额外底块。全局设置覆盖 `appIcon` 的机制与语义不变。
- 登录页既有的固定文案规则（标题、角标、副标题）不变。

## 5. 中文体验

- 页面文案、提示、空态、悬浮提示、组件内置文案都必须保持中文。
- Ant Design Vue 必须通过全局 `a-config-provider` 使用中文 locale，避免默认英文文案暴露到页面。
