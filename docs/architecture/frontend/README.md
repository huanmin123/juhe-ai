## 2. 前端范围

- 前端是 `juhe-ai` 的轻量管理后台，主要承载统计概览、供应商、AI 账户、分组、API Key、代理、模型检测、统一授权、团队 / 用户消耗明细、我的用量 / 用量统计管理、AI 性能监控、使用记录、操作日志、审计日志、日志搜索、公告管理、系统账户、表监控、IP管理和系统设置等能力。
- 前端负责信息展示、表单录入、状态反馈和操作入口，不在页面层伪造后端事实或复杂调度判断。
- 产品默认优先完成轻量闭环，避免提前引入重型前端状态、复杂设计系统或过度抽象。

## 3. 菜单与权限入口

- 管理员本身也是用户，因此管理员拥有用户模式和管理模式两种前端入口；左侧菜单只展示当前模式的菜单，模式切换放在头部用户下拉中。
- 管理员首次进入默认使用用户模式；管理员主动切换后，前端按当前登录系统账户在浏览器本地记录菜单模式偏好，下次进入根路径或登录后继续使用上次模式。普通用户始终只显示用户模式，不显示切换项。
- 凡是普通用户和管理员都能使用的业务能力，菜单入口必须拆成用户侧和管理侧两套：用户侧使用 `我的 ...` 菜单和 `viewScope: 'self'`，管理侧使用管理菜单、`viewScope: 'admin'` 和 `roles: ['admin']`。
- 允许用户侧和管理侧复用同一个 Vue 页面或子组件，但查询范围、系统账户筛选、系统账户列、管理接口调用和操作文案必须由 `viewScope` 区分，不能只按 `isAdmin` 角色判断。
- 同一个页面同时支持用户侧和管理侧接口时，优先通过 scoped domain API / composable 统一选择 `api.*` 或 `api.my*`；页面只负责构造筛选参数、展示范围和交互文案，避免直接散落接口分叉。
- 普通用户可见的表单、筛选、抽屉和弹窗如果需要跨模块辅助数据，必须使用用户侧接口或明确允许登录用户访问的轻量辅助接口，例如 `/__aisys__/api/my-accounts/options`、`/__aisys__/api/my-groups/options`、`/__aisys__/api/my-authorization-options/*`、`/__aisys__/api/providers/:code/models` 和 `/__aisys__/api/proxies/options`。新增这类调用时，同步补 `pnpm test:scope` 里的普通用户可访问断言。
- 不要因为路由前缀带 `my-*` 就默认它可在用户侧展示；复用路由中仍保留管理员能力的接口必须由前端隐藏入口，并由 `pnpm test:scope` 固定为普通用户 403。当前典型例子是账户批量导入和系统性能指标。
- 管理员进入用户模式的 `我的 ...` 页面时，应按当前登录用户查询自己的数据；只有切到管理模式并进入管理菜单时，才允许查看全部系统账户、展示系统账户筛选或调用管理员管理列表接口。
- 纯管理员功能可以只保留管理菜单，例如供应商、代理、系统账户、系统设置、公告管理、表监控、IP管理、日志搜索和审计日志。
- 管理侧菜单应按用户心智分组：AI 管理承载供应商、账号、分组、API Key 和用量链路；统一授权管理承载授权、团队和授权消耗；日志管理承载运行、审计和操作；系统运维承载系统账户、公告、表监控、IP管理、流式拦截策略和系统设置。

## 4. 页面状态缓存

- 菜单路由页面可以通过 Vue `KeepAlive` 保留当前会话内的页面实例现场，例如筛选输入、分页、排序、抽屉打开状态和滚动位置。
- 页面缓存必须以路由路径作为区分维度，避免 `/my-*` 用户侧页面和管理侧页面复用同一 Vue 文件时互相串状态。
- 需要刷新后仍恢复的列表查询习惯，使用项目内轻量页面状态缓存显式保存；缓存范围只包含筛选、分页、排序等可序列化查询状态。
- 页面状态缓存按当前登录系统账户和路由路径隔离；管理员用户模式和管理模式必须分开记录，普通用户不能读取或写入管理模式状态。
- 不允许把接口结果、敏感字段、API Key 明文、上游凭据、OAuth token、代理密码、审计 payload、编辑弹窗表单草稿或批量选中行写入页面状态缓存。
- 页面首次加载应先恢复有效缓存，再发起查询；缓存字段无效、结构不符合当前页面状态模型或本地存储不可用时，回落到页面默认状态。
- 页面“重置筛选”必须同时清理内存状态和本地页面状态缓存。
- 普通列表筛选默认不写入路由 query；只有外部跳转、一次性动作或需要分享的状态才使用 query，并且 query 优先于本地缓存。一次性 query 筛选不能写回页面状态缓存，query 清空后必须恢复缓存或默认筛选，避免 KeepAlive 页面残留外部跳转条件。

## 5. 技术边界

- 技术栈：`Vue 3`、`TypeScript`、`Vue Router`、`Ant Design Vue`、`axios`、`dayjs`、`Vite`。
- 入口：`frontend/src/main.ts`。
- 应用布局：`frontend/src/layouts/`。
- 页面视图：`frontend/src/views/`。
- API 请求：`frontend/src/api/`。
- 类型定义：`frontend/src/types/`。
- 全局样式：`frontend/src/styles/global.css`。
- 当前默认不引入复杂全局状态；确有跨页面共享状态需求时，再单独评估。
