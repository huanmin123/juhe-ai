# 开发运行说明

> 面向 AI 与维护者。
> 本文件只说明如何把项目跑起来以及运行时注意事项；测试步骤、接口样例和烟测细节请放到 [开发测试与验证说明](测试与验证说明.md)。

## 1. 运行前提

- 先完成 [开发环境安装说明](安装指南.md)，确保依赖已安装。
- 后端和前端都读取项目内 `.env` 文件，不默认依赖系统环境变量。
- Node.js 需要满足项目要求，并支持 `node:sqlite`。
- 默认端口 `3000` 和 `5173` 不应被其他进程占用。
- 复用已有数据库时，`backend/.env` 里的 `JUHE_AI_SECRET` 必须保持稳定。

## 2. 启动项目

在项目根目录同时启动前后端：

```powershell
pnpm dev
```

只启动后端：

```powershell
pnpm --filter juhe-ai-backend dev
```

后端开发模式需要同时关注两个运行单元：

- Web/API/网关主进程：监听管理 API、前端静态资源和 `/v1` 网关入口。
- background worker 进程：承载统计聚合、系统采样、OAuth 快照刷新、日志索引维护和审计批量落库等后台任务。

`pnpm --filter juhe-ai-backend dev` 会先启动 Web/API/网关主进程，再由主进程 fork 并看护独立 background worker；排查后台任务时应确认日志里的 worker PID 和主进程 PID 不同。

只启动前端：

```powershell
pnpm --filter juhe-ai-frontend dev
```

## 3. 默认访问地址

- 前端管理后台：`http://127.0.0.1:5173`
- 后端 API：`http://127.0.0.1:3000`
- OpenAI 兼容中转入口：`http://127.0.0.1:3000/v1`

开发模式下，前端会把 `/api` 和 `/v1` 转发到 `frontend/.env` 中的 `VITE_JUHE_AI_BACKEND_TARGET`。

## 4. 运行注意事项

- 本地运行优先保持 `JUHE_AI_HOST=127.0.0.1`；需要局域网访问时再改成 `0.0.0.0`。
- 分离部署或公网访问时，再按实际地址设置 `VITE_JUHE_AI_GATEWAY_BASE_URL`。
- SQLite 默认数据目录是 `backend/data/`，移动项目目录时需要一起保留。
- OAuth token 换取、刷新和账号测试优先使用账号绑定代理；`JUHE_AI_OAUTH_PROXY_URL` 只是兜底代理。
- 后端普通运行日志默认写入 `backend/logs/juhe-ai.log`，同时输出到终端；每条请求日志都会带 `traceId`，响应头也会返回 `x-trace-id`。
- 后台定时任务不应在 Web/API 主进程事件循环里执行；如果统计、OAuth 快照、系统采样或审计清理日志显示在主进程 PID 下，需要先修正后台 worker 隔离再继续压测。
- 普通日志默认 `100MB` 滚动，保留 `14` 天、最多 `30` 个历史文件；可通过 `JUHE_AI_LOG_LEVEL`、`JUHE_AI_LOG_DIR`、`JUHE_AI_LOG_MAX_FILE_MB`、`JUHE_AI_LOG_RETENTION_DAYS`、`JUHE_AI_LOG_MAX_FILES` 调整。
- 管理后台“日志搜索”的索引查询模式只检索最近 3 天写入 SQLite 索引的普通运行日志；超过 3 天的日志即使日志文件仍保留也不会被索引查询搜到。
- 管理后台“日志搜索”的 `grep 模式` 会直接搜索后端日志目录中当前保留的全部 `.log` 文件；所有部署平台都必须安装 `ripgrep` 并确认 `rg --version` 可执行，Windows 可用 `winget install BurntSushi.ripgrep.MSVC`、`scoop install ripgrep` 或 `choco install ripgrep`，macOS 可用 `brew install ripgrep`，Debian / Ubuntu 可用 `sudo apt install ripgrep`。
- 前端面向中文用户，页面应通过全局 `a-config-provider` 使用中文 locale，避免 Ant Design Vue 默认英文文案出现在界面。
- 启动后先看终端日志里的监听地址和报错信息，不要把具体接口测试矩阵写进本文件。

## 5. 运行后下一步

- 只确认项目能打开时，访问前端管理后台并检查页面能正常加载即可。
- 需要代码检查、接口检查、网关联通、账号测试或烟测时，参考 [开发测试与验证说明](测试与验证说明.md)。
