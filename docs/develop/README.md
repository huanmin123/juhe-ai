## 适用边界

- 安装说明回答“拿到项目后需要什么环境、怎么准备、怎么让项目跑起来”。
- 运行说明回答“项目怎么启动、默认访问地址是什么、运行前后要注意什么”。
- 测试说明回答“怎么做代码级检查、接口检查、网关联通、账号测试和烟测”。
- 后端测试分层规则回答“单元测试 / 业务测试 / 压测的边界、单元测试硬规则、覆盖率 ≥95% 硬门槛与覆盖率墙处置阶梯、测试进程纪律（硬性：一次 go test 只允许一个测试进程，守卫脚本 `scripts/test-process-isolation-regression.mjs`）”，开发与测试必须遵守。
- 前端测试分层规则回答“前端逻辑域单测覆盖、前后端契约比对、tsx 回归脚本与真实后端 smoke 的分层和运行入口”，开发与测试必须遵守。
- Mockdata 说明回答“如何给本地 admin 生成可重复使用的完整演示 / 测试数据”。
- Go 迁移调整说明只回答“后端迁移到 Go 期间开发、构建和部署会如何变化”；正式切换前，当前运行命令仍以本目录现有手册为准。
