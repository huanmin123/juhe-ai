## 适用边界

- 安装说明回答“拿到项目后需要什么环境、怎么准备、怎么让项目跑起来”。
- 运行说明回答“项目怎么启动、默认访问地址是什么、运行前后要注意什么”。
- 测试说明回答“怎么做代码级检查、接口检查、网关联通、账号测试和烟测”。
- Mockdata 说明回答“如何给本地 admin 生成可重复使用的完整演示 / 测试数据”。
- Go 迁移调整说明只回答“后端迁移到 Go 期间开发、构建和部署会如何变化”；正式切换前，当前运行命令仍以本目录现有手册为准。
