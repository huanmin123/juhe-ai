- 更新时间：2026-05-17

## 重构目标

- 从存储大文件中先抽出资源授权相关纯辅助逻辑，降低后续拆分 `repositories.ts` 的耦合风险。
- 收敛统计、授权用量、使用记录和表监控页面重复的日期范围与 ECharts 生命周期代码。
- 从账号页面容器中抽出账号权限、菜单和调度动作可用性规则。
- 从账号页面容器中抽出账号派生选项、映射和默认分组选择逻辑。
- 从账号页面保存流程中抽出保存前校验、普通保存 payload 和 OAuth 创建公共 payload 构造。
- 保持接口、页面交互、统计口径和缓存状态行为不变。

## 重构前问题

- `backend/src/storage/repositories.ts` 同时包含账号、分组、授权、用量汇总等多类职责，资源授权 helper 与其他仓储逻辑混在同一文件内。
- 多个前端页面重复实现 `parseDateKey`、`formatDateKey`、日期范围归一化、最近窗口禁用日期和 ECharts 初始化 / 销毁 / resize 逻辑。
- 重复逻辑散落后，统计窗口边界、日期合法性判断和图表释放策略容易在后续页面改动中出现不一致。
- `frontend/src/views/accounts/AccountsView.vue` 在已组件化的基础上仍承载账号权限判断、菜单项拼装、授权提示和流量迁移目标判断，修改账号动作需要进入页面容器阅读较多无关状态。
- 账号页面还内联了测试模型选项、代理选项、账号与分组映射、绑定分组选项、流量迁移目标选项等派生数据构造逻辑，增加了页面容器噪音。
- 账号保存流程同时承担字段校验、凭据构造、payload 构造和 API 调用；其中字段校验与 payload 构造可以独立复用并隔离测试。

## 拆分设计

- `backend/src/storage/resource-authorization-helpers.ts`
  - 负责资源授权的基础查询、过期判断、使用汇总 scope 构造、授权来源脱敏和资源归属管理判断。
  - 不负责系统团队、授权写入、分组绑定同步和仓储对外 API。
- `frontend/src/shared/dateRange.ts`
  - 负责日期 key 校验 / 解析 / 格式化、默认日期范围、日期范围归一化和最近窗口禁用日期判断。
  - 不负责具体页面是否发送日期参数、页面缓存或接口参数组装。
- `frontend/src/composables/useEcharts.ts`
  - 负责 ECharts 实例初始化、销毁和批量 resize。
  - 不负责具体图表 option、页面激活状态或窗口监听注册。
- `frontend/src/views/accounts/accountRules.ts`
  - 负责账号权限判断、授权提示、账号菜单项拼装、OpenAI OAuth 管理判断和流量迁移目标可用性判断。
  - 不负责 API 请求、弹窗状态、表单保存、OAuth 授权和账号测试流程。
- `frontend/src/views/accounts/accountDerivedState.ts`
  - 负责账号页面的派生映射和选项构造，包括测试模型选项、代理选项、账号 / 分组索引、绑定分组选项、默认分组和流量迁移目标选项。
  - 不负责响应式状态、接口请求、分页、保存和弹窗开关。
- `frontend/src/views/accounts/accountSavePayload.ts`
  - 负责账号保存前校验、普通账号保存 payload、OpenAI OAuth 创建公共 payload 和凭据构造组合。
  - 不负责 API 调用、消息提示、弹窗关闭和列表刷新。
