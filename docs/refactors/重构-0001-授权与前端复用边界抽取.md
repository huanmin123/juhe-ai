- 从账号页面容器中抽出账号权限、菜单和调度动作可用性规则。
- 从账号页面容器中抽出账号派生选项、映射和默认分组选择逻辑。
- 从账号页面容器中抽出列表数据加载、筛选分页、移动端分页和页面状态缓存逻辑。
- 从账号页面容器中抽出批量测试、批量启用 / 停用和批量更新公共流程。
- 从账号页面容器中抽出单账号菜单动作、状态恢复、OAuth 令牌刷新和使用侧调度更新流程。
- 从账号页面容器中抽出流量迁移弹窗状态、目标账户选项和迁移保存流程。
- 从账号页面容器中抽出 OpenAI OAuth 重新授权弹窗状态、授权 URL 生成和重新授权保存流程。
- 从账号页面容器中抽出授权账户绑定分组弹窗状态、默认分组选取和保存流程。
- 从账号页面容器中抽出账号测试弹窗状态、测试模型加载、运行 / 停止和静默批量测试流程。
- 从账号页面容器中抽出账号编辑弹窗状态、表单派生项、创建 / 编辑保存和 OpenAI OAuth 创建流程。
- 从账号页面保存流程中抽出保存前校验、普通保存 payload 和 OAuth 创建公共 payload 构造。
- 从账号页面 OAuth 创建 / 重新授权流程中抽出 payload 构造、重新授权校验和授权 URL 读取。
- 从账号测试流程中抽出测试 payload、失败结果、提示文案和批量测试摘要构造。
- 从账号错误处理策略模块中抽出类型 / 选项、默认规则 / 预设、payload 编解码 / 校验和展示摘要 helper。
- 从 OpenAI 网关路由中抽出上游错误诊断、客户端可见错误审计解析、原始上游错误响应转发和请求级失败签名 helper。
- 从 OpenAI 网关路由中抽出代理失败 dispatch key、请求 abort 判断、临时不可调用重试等待和审计 metadata 构造 helper。
- 从 OpenAI 网关路由中抽出账号错误处理副作用、流式失败计数、Codex headers 持久化和流失败状态清理 helper。
- 从 OpenAI 网关路由中抽出上游完成记录、客户端取消记录和 OpenAI 成本估算入队逻辑，归入 usage records 边界。
- 从 OpenAI 网关路由中抽出非 2xx 上游响应处理，包括错误体读取、错误特征匹配、同账号重试、账号策略判断和 deferred failure。
- 从统计仓库中抽出窗口日期、窗口 key、小时桶、行分组和用量窗口聚合规则。
- 从统计仓库中抽出系统指标趋势聚合与 nullable 数值规范化逻辑。
- 从统计仓库中抽出 AI 性能概览、账号选项查询和默认统计运行时 helper。
- 从统计仓库中抽出配额小时窗口刷新和通用排行快照写入 SQL helper。
- 保持接口、页面交互、统计口径和缓存状态行为不变。

## 重构前问题

- `backend/src/storage/repositories.ts` 同时包含账号、分组、授权、用量汇总等多类职责，资源授权 helper 与其他仓储逻辑混在同一文件内。
- 多个前端页面重复实现 `parseDateKey`、`formatDateKey`、日期范围归一化、最近窗口禁用日期和 ECharts 初始化 / 销毁 / resize 逻辑。
- 重复逻辑散落后，统计窗口边界、日期合法性判断和图表释放策略容易在后续页面改动中出现不一致。
- `frontend/src/views/accounts/AccountsView.vue` 在已组件化的基础上仍承载账号权限判断、菜单项拼装、授权提示和流量迁移目标判断，修改账号动作需要进入页面容器阅读较多无关状态。
- 账号页面还内联了测试模型选项、代理选项、账号与分组映射、绑定分组选项、流量迁移目标选项等派生数据构造逻辑，增加了页面容器噪音。
- 账号页面还内联列表加载、筛选、排序、分页、移动端加载更多和页面状态缓存，导致页面容器既处理数据获取又处理弹窗动作。
- 账号页面批量测试、批量启用 / 停用和批量更新流程与单账号弹窗逻辑混在一起，导致选择状态、批量提示和接口更新逻辑不容易独立维护。
- 账号页面单账号菜单动作还内联了测试弹窗、恢复正常、启停用、OAuth 令牌刷新、超级优先、降级备用和流量迁移入口；这些流程依赖权限规则但不需要直接留在页面容器。
- 流量迁移弹窗把打开前校验、默认目标账户选择、目标选项计算、保存接口调用和成功提示全部放在页面容器中，和账号编辑、测试、列表状态混杂。
- 重新授权弹窗把 OAuth 授权 URL 生成、回调 URL / Refresh Token 校验、保存 API 分支和弹窗状态放在页面容器中，和账号创建 OAuth 流程互相穿插。
- 绑定分组弹窗把异常账户校验、默认分组选取、分组选项 / 提示计算和绑定接口调用留在页面容器中，和账号编辑默认分组逻辑重复靠近但职责不同。
- 账号测试弹窗把测试模型加载、AbortController、运行 / 停止、成功 / 失败提示、失败结果构造和批量静默测试请求都留在页面容器中，使页面底部沉积了较长的异步流程。
- 账号编辑弹窗还承载创建 / 编辑入口、默认表单、账户类型切换、分组选项、状态选项、OAuth 授权链接、保存提交和 OpenAI OAuth 创建分支，是账号页面容器中剩余最大的业务流程。
- 账号保存流程同时承担字段校验、凭据构造、payload 构造和 API 调用；其中字段校验与 payload 构造可以独立复用并隔离测试。
- OAuth 创建 / 重新授权流程里存在重复的手动授权 / Refresh Token 分支 payload 构造和校验文案。
- 账号测试流程里内联了测试请求 payload、失败结果对象、成功 / 失败消息和批量测试摘要，流程阅读时需要穿插理解展示文案。
- `frontend/src/views/accounts/accountErrorPolicy.ts` 同时包含表单类型、选项常量、默认规则、预设、历史 payload 读取、保存 payload 生成和校验，导致后续修改错误策略口径时很难只看相关边界。
- `frontend/src/views/accounts/AccountErrorPolicyCard.vue` 在交互逻辑外还内联动作标签、颜色和条件摘要展示规则，展示派生逻辑不便复用或单独确认。
- `backend/src/modules/gateway/openai-gateway.routes.ts` 除主请求编排外，还内联上游错误诊断、可见错误审计解析、原始错误响应转发和多账号失败签名规则，导致排查调度主流程时需要跨过较多解析细节。
- `backend/src/modules/gateway/openai-gateway.routes.ts` 尾部还混有代理失败去重、abort 判断、临时不可调用等待和 audit metadata 构造，虽然单个函数不大，但分散主流程关注点。
- `backend/src/modules/gateway/openai-gateway.routes.ts` 还直接承载账号错误处理入队、流式失败计数、流失败状态清理和 Codex headers 持久化副作用，主路由需要同时阅读调度流程和 DB service 副作用细节。
- `backend/src/modules/gateway/openai-gateway.routes.ts` 成功 / 失败响应收尾时还内联上游完成 usage 入队、客户端取消 usage 入队和成本估算字段拼装，和已有的失败记录模块职责重叠。
- `backend/src/modules/gateway/openai-gateway.routes.ts` 的 `fetchFirstAvailableUpstream` 内联非 2xx 响应处理，错误体读取、审计完成、失败 usage 记录、Codex headers 持久化、错误特征匹配、同账号重试和 deferred failure 混在调度循环中。
- `backend/src/storage/usage-stats.repository.ts` 同时承担统计窗口生成、窗口行分组、用量趋势聚合、模型 / 错误排行聚合和 SQLite 读写，统计口径纯逻辑不便单独复用或测试。
- 系统指标趋势聚合也内联在统计仓库底部，和窗口表写入 SQL 混在一起，后续排查指标口径时需要跨过较多仓储细节。
- AI 性能概览同时包含访问范围解析、默认账号选择、选中账号补齐、小时趋势查询、摘要读取和选项搜索，挤在通用统计仓库中会放大文件体量，也让 AI 性能口径难以独立维护。
- 配额小时窗口刷新和通用排行快照写入 SQL 是快照阶段的可复用基础动作，放在主仓库文件中会让阶段编排、窗口刷新和 SQL 模板互相穿插。

## 拆分设计

- `backend/src/storage/resource-authorization-helpers.ts`
  - 负责资源授权的基础查询、过期判断、使用汇总 scope 构造、授权来源脱敏和资源归属管理判断。
  - 不负责系统团队、授权写入、分组绑定同步和仓储对外 API。
- `frontend/src/shared/dateRange.ts`
  - 负责日期 key 校验 / 解析 / 格式化、默认日期范围、日期范围归一化和最近窗口禁用日期判断。
  - 不负责具体页面是否发送日期参数、页面缓存或接口参数组装。
- `frontend/src/composables/useEcharts.ts`
  - 负责 ECharts 实例初始化、销毁和批量 resize。
  - 不负责具体图表 option、页面激活状态或窗口监听注册。
- `frontend/src/views/accounts/accountRules.ts`
  - 负责账号权限判断、授权提示、账号菜单项拼装、OpenAI OAuth 管理判断和流量迁移目标可用性判断。
  - 不负责 API 请求、弹窗状态、表单保存、OAuth 授权和账号测试流程。
- `frontend/src/views/accounts/accountDerivedState.ts`
  - 负责账号页面的派生映射和选项构造，包括测试模型选项、代理选项、账号 / 分组索引、绑定分组选项、默认分组和流量迁移目标选项。
  - 不负责响应式状态、接口请求、分页、保存和弹窗开关。
- `frontend/src/views/accounts/useAccountListData.ts`
  - 负责账号列表、供应商 / 代理 / 分组选项、筛选、排序、分页、移动端加载更多和页面状态缓存。

- `frontend/src/views/accounts/useAccountBatchActions.ts`

  - 不负责列表加载、删除账户、绑定分组、重新授权、流量迁移、账号测试和编辑弹窗展示组件。

  - 不负责规则增删改、payload 生成和保存校验。

  - 不再承载具体实现。

  - 不负责账号准备、上游请求、并发释放和错误副作用入队。
- `backend/src/modules/gateway/openai-gateway-audit-metadata.ts`

  - 不负责审计生命周期、响应改写和特征匹配。
- `backend/src/modules/gateway/openai-gateway-account-effects.ts`
  - 负责账号错误处理副作用入队、流式失败计数副作用入队、流失败状态清理后的网关运行时缓存失效和 OpenAI Codex usage headers 持久化。
  - 不负责账号选择、上游请求、响应写回、审计生命周期和失败重试编排。
- `backend/src/modules/gateway/openai-gateway-usage-records.ts`
  - 负责网关失败记录、上游失败尝试记录、上游完成记录、客户端取消记录和 OpenAI token 成本估算字段拼装。
  - 不负责上游请求调度、响应体转发、审计生命周期和账号错误策略副作用。
- `backend/src/modules/gateway/openai-gateway-failure-dispatch.ts`
  - 负责非 2xx 上游响应处理、错误体捕获日志、上游错误特征匹配、账号错误策略判断、同账号临时重试、请求级失败确认和 deferred failure flush。
  - 不负责账号候选排序、上游请求发起、成功响应转发、并发槽生命周期和客户端响应写回。
- `backend/src/storage/usage-stats-window-helpers.ts`
  - 负责固定统计窗口日期、窗口 key、小时桶、趋势桶 key、按日期分组和排序工具。
  - 不负责数据库查询、窗口表写入和业务聚合指标。
- `backend/src/storage/usage-stats-window-aggregates.ts`
  - 负责用量概览窗口、趋势桶、模型排行和错误排行的内存聚合。
  - 不负责 SQLite 查询、事务、快照刷新阶段编排和接口响应映射。
- `backend/src/storage/usage-stats-metric-aggregates.ts`
  - 负责系统指标趋势桶聚合、sum / max 指标合并和 nullable 数值规范化。
