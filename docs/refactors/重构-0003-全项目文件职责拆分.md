# 重构-0003-全项目文件职责拆分

## 基本信息

- 编号：REFACTOR-0003
- 状态：进行中
- 创建时间：2026-06-13
- 关联模块：前端、后端、存储、网关
- 触发原因：前一轮已完成网关目录分层，但项目内仍存在大文件继续混合 API 聚合、页面格式化、表单模型、存储校验、业务写入和运行流程的问题，后续维护容易继续误把新逻辑塞回旧大文件。

## 重构目标

- 先完成 `backend/src` 与 `frontend/src` 代码文件级审计，按行数和职责混杂程度识别继续拆分对象。
- 保持现有外部导入入口和页面行为不变，优先抽离纯函数、格式化、参数序列化、表单模型和输入归一化。
- 对高风险流程只做边界移动，不混入业务语义变化。
- 每次拆分后立即跑对应 typecheck 和最小回归。
