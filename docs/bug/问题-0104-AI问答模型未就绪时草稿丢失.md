# BUG-0104 AI 问答模型未就绪时草稿丢失

## 基本信息

- 状态：已修复（前端回归）
- 严重程度：P1
- 模块：前端 / AI 问答 / 编辑器 / 模型加载
- 发现时间：2026-07-13
- 关联计划：PLAN-0103

## 现象与根因

模型列表仍在加载或为空时，发送按钮只检查输入内容；提交先清空编辑器再通知页面，而页面因没有模型直接返回，导致草稿静默丢失。

## 修复与验证

编辑器的 `canSubmit` 同时要求有内容、已选模型且模型加载完成；页面发送边界再做防御检查，无法启动时立即恢复快照并提示原因。回归同时固定按钮条件和页面恢复路径。

## 防复发

会先清空本地草稿的操作必须只在下游必需前置条件满足时启动，并在页面边界保留一次独立恢复保护。
