# BUG-0079 审计配置与大正文边界偏离

- 关联 bug：BUG-0072

## 问题概述

- 用户已确认成功审计热窗口、采样率和保留期允许为 0，但运行配置拒绝 0；三项全 0 无法关闭成功审计。
- server 只按裁剪后估算值检查 64MiB，上百 MiB raw Buffer 仍常驻；两个大问题正文经 base64 后又可能超过 4MiB transport 上限并丢失整条审计。
- 现行文档仍残留成功 7 天、问题 30 天和不可配置等旧口径。

## 根因与修复

- 配置实现没有同步会话最终交叉校验；server 的 resident bytes 与 retained bytes 混用；worker 无法二次缩小已有 summary。
- 允许成功三项 0，并固定采样率和成功保留期同时启停；hot-only 清理截止时间不越过热窗口。
- 增加 raw resident guard，超限只保留 overflow metadata；worker 动态缩小 summary head/tail，最终严格满足 4MiB。
- 行为回归实际验证 all-zero 成功不落库、失败仍落库，65MiB raw 不驻留正文，双 3MiB 正文不丢审计。
