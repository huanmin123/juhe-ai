# 问题-0279：master 既有测试回归——ipstats 时钟炸弹与设置键缺省注册表

- 编号：BUG-0279
- 状态：已修复（2026-10-03），待发布
- 发现：BUG-0269 修复批次的串行全量测试验证（gateway internal phase）。两个失败面均非该批次引入，属 master 既有缺陷。

## 现象与根因

### 1. `internal/gatewayruntimecache` 3 例必红

`seedGatewaySettingsKeys`（`sqlmodels_test.go`）遍历 `settings.SystemSettingKeys` 并对每个键 fatal 缺失的测试默认值。提交 `613f2c618`（上游身份管理模块）把 `upstreamClientVersionOverrides` 加进键清单，但未在该注册表补默认值——遍历到末键即 fatal，`TestWhSQLReadGatewayRuntimeGates` / `TestWMSQLMergeModeRoundTrip` 等三个测试无法到达自身断言。错误消息：`missing test default for system setting upstreamClientVersionOverrides`。

### 2. `internal/ipstats` 3 例定时转红（时钟炸弹）

`TestIPStatsDetailEndpointLocksIn` / `TestW11DDetailErrorArms` / `TestW11DDetailPaginationAndLookupArms` 硬编码 `startDate=2026-09-01 / endDate=2026-09-03`（种子与查询同对日期）。`normalizeRange`（`list.go:559`）把日期钳制到 `[today-(maxRangeDays-1), today]`，`maxRangeDays=31`：2026-10-01 当日 start 恰在窗沿（earliest=2026-09-01）仍绿；2026-10-02 起 start 越出下界被抬到 earliest，与种子窗口行（09-01..09-03）失配，`rangeReady` 恒 false、items=0；2026-10-04 起 end 同样越界被抬，范围彻底塌缩成单日。测试与其实现同一提交（`32bb54673`）落地时在窗内，从未防时钟。

## 修复

- `gatewayruntimecache/sqlmodels_test.go`：注册表补 `"upstreamClientVersionOverrides": "{}"`（校验器认可的合法空对象默认）。
- `ipstats/detail_test.go` + `w11d_edges_test.go`：新增 `detailRangeKeys()` 返回 `now-10d .. now-5d` 的相对日期键（窗口中段、两侧 ≥4 天余量，跨午夜执行不改变钳制结果），替换种子与查询的全部硬编码日期；range 回显断言改用同一对键。

## 验证

`go test ./internal/gatewayruntimecache/ ./internal/ipstats/ -count=1` 全绿；gateway internal 三阶段串行全量复跑无其他新增失败。
