# BUG-0081 AI 问答旧流误删新流停止句柄

## 基本信息

- 状态：已修复（回归验证）
- 严重程度：P1
- 模块：后端 / AI 问答 / SSE / 并发
- 发现时间：2026-07-13
- 关联计划：PLAN-0094

## 现象与根因

旧轮次完成数据库终态后、其路由 finally 执行前，同会话可能接受新轮次并覆盖内存中的 controller；旧 finally 无条件按会话 ID 删除 Map，会把新轮次停止句柄一并删除，随后 `/stop` 返回 404。

## 修复与验证

活动流清理改为同时匹配 `conversationId` 和 `turnId`，旧轮次只能删除自己的条目。`test:chat-active-stream` 覆盖旧轮次清理不影响新流、当前轮次仍可正常清理。

## 防复发

任何可被新任务覆盖的内存注册表，清理时都必须比较任务代次或唯一 ID，不能只按资源主键删除。
