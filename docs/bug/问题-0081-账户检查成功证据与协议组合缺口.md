# BUG-0081 账户检查成功证据与协议组合缺口

## 基本信息

- 编号：BUG-0081
- 状态：已修复（待生产验证）
- 严重程度：P1
- 发现时间：2026-07-14
- 发现方式：状态机复查
- 模块：AI 账户 / 健康检查 / 人工测试 / 协议
- 关联计划：PLAN-0084、PLAN-0096
- 关联 bug：BUG-0015

## 问题概述

- 任意 HTTP 2xx 且无显式 stream error 都会判成功，空正文、HTML、畸形 JSON 或只有 `[DONE]` 可激活待检查账户。
- 测试选项虽返回模型协议能力，前后端没有校验“所选模型 + endpoint mode”，切换模型可残留非法协议。

## 根因与修复

- 为八种 JSON / SSE mode 增加最小协议完成证据；invalid 200 对 active 周期检查计入账户失败，达到阈值后停调。
- Chat SSE 兼容“有效内容 chunk 后 DONE”，拒绝纯 DONE、角色空 chunk 和 DONE 在前的非法顺序。
- test-options 返回模型目录、账户能力和有效模型映射后的 mode 交集；提交和 worker 再校验，前端切模型清理旧 mode。
