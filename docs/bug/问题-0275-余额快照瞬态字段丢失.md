# 问题-0275：余额快照瞬态失败三字段丢失（前端提示永不出现）

- 编号：BUG-0275
- 状态：已修复（2026-10-03），待发布
- 发现：BUG-0269 后的全量排查（跨边界 DTO 审计）。生产 `juhe_stats.account_usage_snapshots` 121 行 snapshot_json 无一含该字段。

## 现象

余额查询处于瞬态失败时，前端两个提示分支永不触发：pending 状态的"暂时无法查询"回落成"待查询"；fresh 保留上次余额时"刷新暂时失败（N/3）"tooltip 不显示。读取侧（gateway `accountsbalance/list_snapshot.go` 白名单 + 前端 `accountBalanceQuery.ts:56-63,104-108`）早已在消费。

## 根因

shared `accountbalance.Snapshot`（`types.go:97-99`）的 `consecutiveTransientFailures` / `lastTransientErrorMessage` / `lastTransientFailureAt` 三字段在两个写入点被静默丢弃：

- `worker_balance_projection.go` `balanceSnapshotFromJ2` 未拷贝（J2 侧 `juhe_jobs.account_balance_snapshots.snapshot_json` 整行序列化 shared Snapshot，字段在 JSON 内，无独立列）；
- `worker_balance_detect.go` `balanceSnapshotPersist` 结构缺三键且 `buildSnapshotJSON` 未填。

## 修复

两个写入点补齐三字段：json tag 与 shared Snapshot 完全一致、全 omitempty（单 Key 零值省略，既有 JSON 形状逐字节不变）；detect 侧沿用"完整 J2 快照可用时才持久化"的既有模式，窄投影 `BalanceSnapshotWrite` 不含瞬态字段的契约保持。

## 测试

`TestBalanceProjectionMappingTransientFields`（pending 输入 → 投影 JSON 含正确键值，修复前必红）；`TestBalancePersistTransientFieldsPersisted`（SQLite 全链路落库断言）；键集精确回归 `TestBalanceProjectionMappingSingleKey` / `TestBalancePersistSingleKeyStaysNarrow`（禁键清单扩展，修复前后恒绿）。

## 残余项

存量 121 行历史数据缺三键：只修写入点，旧行在下次探测/投影周期 UPSERT 后自然带上，无回填需求。
