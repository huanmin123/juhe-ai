# BUG-0103 AI 问答置顶会话游标漏页

## 基本信息

- 状态：已修复（repository 与前端回归）
- 严重程度：P1
- 模块：前后端 / AI 问答 / 会话列表 / 游标
- 发现时间：2026-07-13
- 关联计划：PLAN-0103

## 现象与根因

列表按 `is_pinned DESC, last_message_at DESC, id DESC` 排序，但旧游标只携带时间和 ID。第一页末尾若是较旧的置顶会话，下一页会永久排除时间更新的非置顶会话；前端又只加载首批 50 条，第 51 条之后不可访问。

## 修复与验证

游标改为完整 `(is_pinned, last_message_at, id)` 三元组，前端保存服务端页尾游标并提供“加载更多”。repository 回归覆盖旧置顶会话之后仍返回较新的非置顶会话，前端回归固定 API 参数和加载入口。

## 防复发

Keyset pagination 的游标字段与方向必须完整复刻 `ORDER BY`；客户端不能把固定首屏上限当作完整数据集。
