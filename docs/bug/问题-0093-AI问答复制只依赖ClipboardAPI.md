# BUG-0093 AI 问答复制只依赖 Clipboard API

## 基本信息

- 状态：已修复（开发验证）
- 严重程度：P2
- 模块：前端 / AI 问答 / 剪贴板
- 发现时间：2026-07-13
- 关联计划：PLAN-0103

## 现象与触发条件

消息复制和代码块复制直接调用 `navigator.clipboard.writeText`。嵌入式浏览器、非安全上下文或剪贴板权限被拒绝时，复制稳定失败，即使浏览器仍支持选区复制。

## 根因

聊天组件重复实现了剪贴板写入，没有复用项目已有的选区回退边界，导致相同功能在不同页面行为不一致。

## 修复与验证

抽出无 UI 副作用的 `writeTextToClipboard`：先尝试 Clipboard API，失败后使用受控 textarea 选区和 `execCommand('copy')`，两条路径都失败才抛错。消息复制和代码复制统一调用该函数，回归锁定生命周期与回退接线。

## 防复发

新增复制入口必须复用共享剪贴板边界；受控浏览器同时禁用 Clipboard API 与选区复制属于环境权限限制，应展示明确失败提示而不是静默成功。
