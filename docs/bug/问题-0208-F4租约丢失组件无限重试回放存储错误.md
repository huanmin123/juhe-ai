# BUG-0208：F4 owner 租约丢失后组件无限重试回放存储错误（F3 同族缺陷）

- 编号：BUG-0208
- 状态：已修复（待发布）
- 发现：2026-09-28 早晨生产日志巡检，gateway `F4 operation-log-owner` 组件 `lease lost` 持续重试（consecutiveFailures 147+，30s 一次），追溯约 05:37 起进入死循环直至 07:14 发布重启才恢复

## 现象

- supervisor 日志循环：`sidecar component started`（F4 operation-log-owner）→ 立即 `failed; retrying, cause="F4 operation-log owner lease lost"`，30 秒一轮永不恢复；
- 死循环期间 F4 owner 缺位约 1.5 小时：retention 节拍停摆，producer 写入失去租约维护；
- 恢复只能靠进程重启（07:14 发布重启后 lease 行恢复每 30s 续租，当日 07:15/07:16 两次续租锁超时（55P03）均自愈）。

## 根因（BUG-0196 的 F4 同族）

`operationlog.LeaseKeeper` 未同步 BUG-0196（2026-09-27）给 F3 `auditlog.LeaseKeeper` 的语义修订：

1. **续租传输失败无放宽窗口**：租约续租（TTL/3 节拍）遇到 PG 锁超时/网络抖动时旧代码只记日志继续等，但 TTL（30s）内续租不成功租约即过期，DB 恢复后下一次续租 0 行更新 → 终态 `ErrOwnerLeaseLost`；
2. **组件重启不触库重取**：keeper 设计注释「恢复 = 进程重启」，supervisor 重启组件时复用**同一个**共享 keeper 对象，`RunOwner` 每次入口直接回放已存储的终态错误、不触碰数据库 → 每 30s 失败一次的无限循环；
3. **producer 冻结 fence 快照**：`NewProducer` 构造时缓存 `OwnerLease` 值。即使修复了重取，reacquire 轮换 fence_token 后 producer 仍持旧 fence 写入 → renew 0 行 → 每条操作日志被丢弃直到进程重启（F3 在 BUG-0196 后同样存在此缺口）。

## 修复

对齐 F3（auditlog）已验证的语义：

- `lease_keeper.go`：续租每次尝试独立 5s 有界上下文；传输类失败在 `2×TTL` 放宽窗口内按周期重试（连续失败计数、窗口超限才终态并保留原始错误）；0 行更新立即终态；新增 `reacquire(ctx)`——supervisor 重启 `RunOwner` 入口先触库 `AcquireOwnerLease`（新 fence token）、重建一次性状态与续租循环；`fatal` 日志 nil logger 兜底；`stopCh` nil 守卫（裸构造 keeper 不再 panic，F3 同码同修）。
- `retention.go`：`RunOwner` 入口调用 `keeper.reacquire`；行被他人持有时 fail-closed 返回错误（不服务无 fence 写入）。
- `producer.go`（operationlog 与 auditlog 同改）：`NewProducer` 参数从 `OwnerLease` 快照改为 `LeaseSource` 接口（keeper 实现），每条记录写入前实时读当前 lease——reacquire 轮换 fence 后写入自动跟随新 token。
- 装配点（`main.go` F3 producer、`compose.go` F4 producer）改为直接传 keeper。

## 验收

- fake store 定向覆盖（镜像 F3 `owner_renew_grace_test`）：单次传输失败存活、超放宽窗口放弃（错误含「放宽窗口」与原始错误）、0 行立即终态、supervisor 重启重取新 fence token 不回放旧错误。
- 真实 SQLite 回归：rival 接管 → 终态 → 行空闲后重启 RunOwner 重取成功（fence 递增、取消优雅 nil）；producer 跨 fence 轮换写入持续落库（旧实现第二条即丢）。
- `operationlog`、`auditlog`、`cmd/juhe-ai-jobs` 相关包测试全绿。
- 发布后生产观察：`docker logs juhe-ai-go-gateway` 中 `F4 operation-log-owner` 不再出现 started→immediately failed 循环；lease 行 `lease_until` 持续推进。
