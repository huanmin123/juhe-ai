## 问题概述

- 现象：①生产服务器 IP 103.36.63.105、root 用户名、出海代理 IP（59.110.140.235、39.107.67.243）硬编码在 git 追踪的 deploy.sh、compose.yml 三段 extra_hosts、Caddyfile 注释、docs/deploy 系列与 docs/bug 历史文档中，违反项目"实例事实进 .local"边界；②Dockerfile.runtime 无 USER 指令，gateway/jobs/maintenance 三常驻容器以 root 运行且挂载宿主机目录。
- 期望：git 追踪文件零实例事实；容器以非特权用户运行。
- 影响范围：泄漏增量主要为 root 用户名、同机拓扑、出海代理地址（可被定向打击/绕过）；root 容器需先有 RCE 才构成提权，属纵深防御缺口。公网域名 aijh.huanmin.top 与 compose 内网固定 IP（172.18.x）经裁决保留（前者是证书/路由契约键，后者非公网事实）。

## 根因分析

- 部署脚本与配置从单机形态搭建起直接写死实例值，.local 边界建立后未回填清理；镜像沿用开发习惯未做用户隔离。

## 修复方案

- **变量化**：deploy.sh 的 SERVER 改环境变量 `JUHE_AI_DEPLOY_SERVER` > 同目录 .env > 缺失 fail-fast；compose.yml 三段 extra_hosts 的代理 IP 改 `${JUHE_AI_PROXY_IP_A/B:?required}`（与 POSTGRES_PASSWORD 同模式，服务器 .env 缺失时 compose config 阶段报错）。
- **非 root**：Dockerfile.runtime 加固定 UID/GID 1000 的 app 用户、运行时可写目录 chown、`USER app`；二进制与前端 dist 保持 root 属主只读。caddy（绑 80/443）与 PG/Redis（镜像自管）不动。
- **文档泛化**：docker/ 与 docs/ 中三个公网 IP 零残留（git grep 验证），指向 .local 资产或服务器 .env；deploy 域 4 处活死链顺带修复。
- **runbook 同步**：.local 运维手册新增"BUG-0225 配套发布前置"三步（服务器 .env 加两代理 IP 变量、宿主机 data/app chown 1000:1000、本地 .env 建 JUHE_AI_DEPLOY_SERVER）。
- **已知残留**：根 AGENTS.md 3 处引用 .local 资产实际文件名（`国内单机-103.36.63.105.md`，文件名含 IP）——用户指令文件不擅改，待用户裁决是否泛化+重命名 .local 文件；git 历史中的 IP 需历史改写才能消除，须用户单独授权。

**服务器侧一次性前置（用户下次发布前必做，缺一发布即失败——设计内防呆；真实值见私有 runbook，不入公开文档）**：
1. 服务器 `/opt/juhe-ai/.env` 追加 `JUHE_AI_PROXY_IP_A=<代理IP-A>`、`JUHE_AI_PROXY_IP_B=<代理IP-B>`（真实值已写入私有 runbook 的 BUG-0225 配套前置；缺失则 compose config 报错）。
2. 服务器一次性 `chown -R 1000:1000 /opt/juhe-ai/data/app`（跳过则新容器以 app 身份无权写挂载目录，healthcheck 失败重启循环；回滚 `chown -R root:root`）。
3. 本地发布机 `docker/single-server/.env` 建 `JUHE_AI_DEPLOY_SERVER=<user>@<服务器IP>`（真实值见 .local 资产台账；否则 deploy.sh fail-fast）。
4. **上传变更后的三份配置文件**（deploy.sh 只上传 build/bin 二进制，不上传配置——BUG-0225 恰好只改了这三份）：`compose.yml`、`Caddyfile`、`Dockerfile.runtime` 需 tar/scp 同步到服务器 `/opt/juhe-ai/`（参照 README 手动流程第 2 步），否则服务器仍用旧配置 build，变量化与非 root 化静默不生效。
5. 本机无 docker CLI：Dockerfile 非 root 层与 compose `:?required` 为静态校验，首次服务器 `docker compose build` 即实际验证（COPY 路径已回正为 `build/frontend-dist`）。
