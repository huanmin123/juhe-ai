# BUG-0085 AI 问答上游响应伪有界读取

## 基本信息

- 状态：已修复（回归验证）
- 严重程度：P1
- 模块：后端 / AI 问答 / SSE / JSON / 内存边界
- 发现时间：2026-07-13
- 关联计划：PLAN-0094

## 现象与根因

Responses 解析器已经具备部分边界，但 Chat Completions 仍可在没有事件分隔符时持续累积 pending buffer，也没有事件总数上限。模型目录和上游错误的普通 JSON 响应则先执行 `response.text()`，再对字符串截断；这只能限制后续解析量，不能阻止完整响应先进入内存。

## 修复与验证

Chat Completions 与 Responses 统一限制单事件和 pending buffer 为 `64 KiB`、单轮最多 2048 个事件；正文继续受 `192 KiB` 上限约束。普通 JSON 改为流式 reader：模型目录最多 `4 MiB`，上游错误最多 `64 KiB`，超过上限立即取消读取并失败。`test:chat-sse-parser`、`test:chat-responses-sse` 和 `test:chat-bounded-json` 覆盖无分隔大块、事件洪泛、UTF-8 跨 chunk、正常 JSON、非 JSON 错误和超限取消。

## 防复发

任何“有界响应”必须在字节进入应用内存时执行上限；读取完整 body 后再 `slice` 不属于内存边界。新增上游协议时，SSE 与普通响应都必须补 pending、事件数、总正文和异常终态回归。
