# BUG-0092 AI 问答编辑原文未显示

## 基本信息

- 状态：已修复（真实模型验证）
- 严重程度：P1
- 模块：前端 / AI 问答 / Tiptap / UndoRedo
- 发现时间：2026-07-13
- 关联计划：PLAN-0103

## 现象与触发条件

最近纯文本成功轮次进入编辑态后，旧轮次会正确降低强调，但输入框仍为空，发送按钮禁用；取消编辑本身不修改后端。

## 根因

为隔离 UndoRedo 历史，代码直接调用 ProseMirror `view.updateState` 替换文档。底层 state 已改变，但该路径绕过 Tiptap 的内容同步通道，Vue 的 EditorContent 没有获得可靠更新。

## 修复与验证

统一编辑器文档边界先通过 Tiptap `commands.setContent` 同步视图，再立即用同一 JSON 文档重建无历史 EditorState。回归验证原文按字面 Markdown 回填、旧草稿不能被 Ctrl+Z 召回、边界内新输入仍可撤销。真实模型验证取消编辑保留 `2+2=4`，再次编辑为 `3+3` 后页面仍只有一对消息且结果为 `3+3=6`。

## 防复发

富文本编辑器不能只测纯 JSON 转换；涉及程序化回填时必须同时验证可见内容、发送门禁和 UndoRedo 边界。
