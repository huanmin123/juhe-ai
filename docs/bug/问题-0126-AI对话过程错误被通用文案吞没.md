# BUG-0126 AI 对话过程错误被通用文案吞没

## 基本信息

- 编号：BUG-0126
- 状态：已修复
- 严重程度：P1
- 发现时间：2026-07-24
- 发现方式：用户反馈与日志排查
- 模块：Node / Vue / AI 对话 / 内部工具 / SSE / 聊天存储
- 关联计划：PLAN-0169-20260724T220000000Z

## 问题概述

- 上游和内部工具已经返回具体错误，但生成终态只保留通用错误码，工具块只显示“失败”。
- 前端 SSE 校验器未接受 `tool.failed` 与 `tool.canceled`，实时失败事件会被丢弃。
- 刷新后聊天消息没有错误详情字段，用户无法携带错误和会话 ID 直接定位日志。

## 根因与修复

- 根因是安全边界被实现成“丢弃详情”，而不是“详情脱敏后公开”，且生成、工具、SSE、存储分别维护了不完整契约。
- 新增统一诊断消息提取和脱敏，保留真实错误文本但移除凭据、Token、Cookie、URL 和服务端路径。
- 工具失败事件携带 `errorCode/errorMessage`，前端接收失败/取消事件并默认展开失败详情。
- `chat_messages.error_message` 持久化错误详情，失败消息旁展示并可复制错误、会话 ID 与 Trace ID。
- 服务端仍用完整异常对象写日志，并补充 conversation/turn/trace/tool 定位字段。
