# BUG-0106 AI 问答默认文本块为空导致模型历史丢字

## 基本信息

- 状态：已修复（repository 与压缩回归）
- 严重程度：P1
- 模块：后端 / AI 问答 / 内容块 / 上下文
- 发现时间：2026-07-13
- 关联计划：PLAN-0104

## 现象与触发条件

调用方只提交 `content`、省略 `contentBlocks` 时，页面仍能通过 `content_text` 显示正文，但自动生成的 `input_text` 块保存为空字符串。模型上下文切换到按有序内容块重建后，该轮用户正文会变成空内容。

## 根因

`acceptChatTurn` 生成默认内容块时只知道块类型，不把已经校验过的 `userContent` 传给序列化函数。渲染历史和结构化模型历史长期使用不同事实源，旧页面路径掩盖了结构化数据缺失。

## 修复

- 默认 `input_text` 块直接保存当前 `userContent`。
- repository、checkpoint 和主动压缩回归同时验证正文、最近原文尾部和早期关键记忆。
- 模型历史不再用 `content_text` 静默修补一个已存在但为空的结构块；当前 schema 只保存正确结构。

## 防复发

任何可选结构化投影都必须在写入时由同一份已校验正文生成，不能依赖页面读取层兜底。验收不仅检查 UI 可见内容，还要检查模型请求、数据库内容块和压缩后上下文。
