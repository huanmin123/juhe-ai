- 关联 bug：无

## 问题概述

- 现象：切换菜单时偶发短暂卡顿，表监控、统计页面、统计列表和 AI 账户页面更明显。
- 期望：菜单切换先快速完成应用壳和页面框架响应，重表格和图表不阻塞导航首帧。
- 实际：首次进入重页面时，路由 chunk 下载、表格 DOM 创建和测量、图表初始化、页面派生计算可能挤在同一段主线程任务里。
- 影响范围：所有菜单路由，重页面集中在统计、账号、授权统计、用量、日志、审计和表监控。

## 复现步骤

1. 登录后台并在用户模式 / 管理模式下连续切换多个菜单。
2. 打开统计概览、AI 账户管理、用量统计、AI 性能监控、操作日志或表监控。
3. 观察首次进入或缓存被淘汰后重新进入时是否有短暂卡顿。

- 分支 / 版本：当前工作区
- 数据状态：菜单数量较多，部分页面有宽表格、图表和多接口加载。
- 浏览器 / 系统 / Node 版本：待联调环境补充。
- 是否稳定复现：用户体感可感知，未做 Performance trace 定量。

## 根因分析

- 表象：切换菜单时页面似乎“卡一下”，尤其是列表、统计图和表监控。
- 真实根因：多个重任务叠在导航关键路径，包括首次加载异步组件 chunk、Ant Design Vue 宽表格同步创建和测量 DOM、ECharts 初始化和 resize、AI 账户页行级派生数据反复数组查找，以及 KeepAlive 缓存上限偏小导致重页面被淘汰后反复冷启动。
- 补充根因：二次复查发现部分细节会影响长期运行，包括隐藏工具栏仍监听 resize、CodeMirror 延迟格式化任务未收口、页面状态缓存 / 提交锁 / 搜索防抖存在短 timer、账号测试请求切走页面后未主动 abort、公告轮询缺少防重入。
- 为什么会发生：页面数量增加后，原先单页局部可接受的同步工作在菜单切换场景叠加；同时隐藏页生命周期没有统一释放 observer / resize / timer / 实例，多缓存页面下会放大后续布局成本和内存占用。

## 修复方案

- 修改点：新增 `DeferredRender`；通用 `ResponsiveDataList` 延迟表格挂载并在 deactivated 释放 observer / resize；重菜单 `meta.heavy` 空闲分批预加载；统计和表监控图表按激活状态渲染并在隐藏时释放实例；AI 账户页常用派生关系改为 `Map/Set`；工具栏、代码查看器、页面状态缓存、提交锁、移动分页、搜索防抖、账号测试请求、公告轮询和路由预加载批次补齐生命周期收口。
- 行为影响：不改变接口、权限、分页、筛选和统计口径；页面内容会在导航后一到两帧内挂载重表格或图表。
- 发布异常处理：如具体页面激活后空白，优先修正该页面的延迟渲染生命周期；必要时针对当前页面关闭 `deferTableMount` 或重菜单标记，不恢复旧页面加载模型。

### 2026-10-06 真实浏览器验收（通过，缺陷关闭）

- 验收环境：隔离 Go gateway（端口 3391，`JUHE_AI_BUSINESS_DATABASE_PATH` 指向 `bug0009-verify` 独立 SQLite，maintenance `--ensure-schema/--seed` 初始化）直接托管前端生产构建 dist（非 vite dev，排除按需编译伪影）；开发自动登录 + 验证码关闭；管理模式菜单（29 项）经 `juhe-ai:menu-mode:sys_admin=admin` 启用。
- 验收路径与证据：
  - 重菜单切换体感：内置浏览器真实点击（受信任输入）连续切换 统计概览→AI性能监控→使用记录管理→AI性能监控→统计概览，页面内 `history.pushState` watcher + fetch/XHR 补丁计时。3 跳真实点击全程 46/57/65ms（含页面数据请求落地）；route push 到 URL 变化仅 19-23ms，路由收敛 92-170ms。页面标题、菜单选中态、页面数据均正确，首帧无可感知阻塞。
  - 页面缓存与状态恢复：AI性能监控回访仅发出主指标 1 个请求（首访为 usage-window + ai-performance 2 个），用量窗口筛选状态未被重置，证明 KeepAlive 生效、页面未冷启动。
  - 隐藏页不渲染/不轮询：统计概览页静置 6.6s 0 请求（无自动刷新）；切离统计页到使用记录页后静置 6.6s 0 请求（统计页定时器未在隐藏后延续）。
- 观察项（不构成缺陷）：回访统计概览时页面滚动位置回到顶部（KeepAlive 保留了数据与筛选状态，滚动复位属导航默认行为）；如需保留滚动位可后续单独优化，与本缺陷验收无关。
- 环境说明：验收后期内置浏览器（IAB）输入投递层出现会话级不稳定（点击事件不再送达页面，多标签页复现），改用页面内 `router.push`（与菜单点击共享同一路由处理链尾部）补齐剩余场景；已完成的 4 次真实点击导航数据不受影响。该现象仅存在于自动化宿主环境，非产品缺陷。
- 结论：两项未执行验证均已补齐并通过，BUG-0009 关闭。
