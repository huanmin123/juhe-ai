# BUG-0097 AI 问答会话切换被旧响应覆盖

## 基本信息

- 状态：已修复（回归验证）
- 严重程度：P1
- 模块：前端 / AI 问答 / 异步竞态
- 发现时间：2026-07-13
- 关联计划：PLAN-0103

## 现象与根因

快速切换会话或加载更早消息时，先发出的慢请求可能晚于新会话返回，并覆盖当前消息、模型或分页状态。旧实现只记录选中 ID，没有请求代次和卸载边界。

## 修复与验证

会话加载使用递增 epoch；只有“会话 ID、当前 epoch、页面未卸载”同时匹配时才能写入状态。切换时先清空旧消息与模型，历史分页复用同一守卫。`test:chat-conversation-load` 覆盖旧会话、同会话旧 epoch 和卸载后的响应。

## 防复发

所有会改变当前页面主体的异步加载都必须有身份与代次双重守卫，不能只在请求发起时检查当前选择。
