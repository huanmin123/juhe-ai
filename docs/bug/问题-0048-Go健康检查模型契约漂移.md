# BUG-0048 Go 健康检查模型契约漂移

## 基本信息

- 编号：BUG-0048
- 状态：已修复（待真实环境验证）
- 严重程度：P1
- 发现时间：2026-07-10
- 发现方式：当前 Node 工作树与已迁移 Go 切片对照
- 模块：后端 / Go / 供应商 / 公开接口 / AI 账户 / PostgreSQL
- 关联计划：[PLAN-0081 Node 转 Go 渐进减法迁移](../plans/计划-0081-Node转Go渐进减法迁移.md)
- 关联 bug：[BUG-0042](问题-0042-Go供应商默认测试模型覆盖协议档案.md)、[BUG-0043](问题-0043-Go公开账户支持模型更新未清理默认测试模型.md)
- 责任人：主 agent / 维护者

## 问题概述

- 现象：Node 已把供应商默认测试模型和账户默认测试模型统一改为“健康检查模型”，但 Go 已迁移的 Provider 与 W1b 公开账户仍使用旧字段、旧表、旧路由和“失效后静默清空”语义。
- 期望：
  - Provider API 使用 `defaultHealthCheckModel`、`systemDefaultHealthCheckModel` 和 `protocolProfiles[].defaultHealthCheckModel`。
  - 偏好写接口使用 `/providers/{code}/default-health-check-model`；普通用户写 `provider_default_health_check_models`，管理员写 `provider_system_default_health_check_models`。
  - 账户使用非空 `health_check_model`；创建时按“个人默认 > 管理员系统默认 > 协议档案默认”解析，并要求属于最终 `supportedModels`。
  - 公开账户请求和响应不暴露内部检查模型；更新不能移除当前检查模型。
- 实际：旧 Go 仍保存 `default_test_model`，更新模型集合时会把失效值清为 `NULL`，供应商接口仍返回旧 JSON 字段并写旧偏好表。
- 影响范围：已迁移的 W2 Provider 列表 / options / 默认偏好写入、自定义模型偏好清理，以及 W1b public account add / update / list 内部存储。

## 根因分析

- BUG-0042 和 BUG-0043 对齐的是更早的 Node 契约；2026-07-10 的 Node 工作树随后完成了检查模型与人工测试模型解耦。
- Go migration、sqlc、port、service、HTTP DTO 和 integration smoke 没有在同一批次重新审计，导致旧命名和旧可空语义继续存在。
- Provider 与账户共享协议档案字段和 SQLC schema 类型，若只改一侧会产生不可编译或 fresh schema 不一致的中间状态。

## 修复方案

- fresh schema 直接使用：
  - `provider_protocol_profiles.default_health_check_model`
  - `provider_protocol_profile_families.default_health_check_model`
  - `provider_default_health_check_models`
  - `provider_system_default_health_check_models`
  - `accounts.health_check_model text NOT NULL`
- Provider port/store/service/HTTP 全量改为健康检查模型命名，旧路由不保留兼容；自定义模型停用或删除时清理新偏好表。
- 默认检查模型 PUT 继续校验模型可见、active、文本生成，并补充尾随 JSON 拒绝。普通用户只能维护自己的个人默认；管理员维护全局系统默认，且不能选择个人模型。
- W1b 创建先解析目标用户个人偏好，再回退管理员系统默认和协议档案默认；检查模型为空或不属于最终支持模型时返回 `400`。
- W1b 更新验证现有检查模型仍属于最终支持模型；不再清空或修改该字段。
- W1b 内部 summary/store 读取检查模型，但公开请求拒绝提交，公开响应和日志快照不暴露。
- 不增加旧列、旧表、旧路由兼容或运行时迁移分支。

## 下次遇到

- 账户检查模型、供应商默认检查模型和人工测试选择必须作为三个不同边界审计，不能只做字段替换。

- 内部必填字段不等于公开 API 字段；公开维护接口继续保持最小契约和响应白名单。
