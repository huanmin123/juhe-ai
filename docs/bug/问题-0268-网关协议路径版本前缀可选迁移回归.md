# 问题-0268：网关协议路径版本前缀可选契约迁移回归（根形态 404）

- 编号：BUG-0268
- 状态：已修复并发布生产（2026-10-03 03:3x，gateway `dd4abaee653d412e3198c7a9896b602d`；生产实证根形态 404→401、非协议路径保持 404 隔离）
- 发现：用户生产报障——Codex 客户端按 `wire_api = "responses"` 请求 `{base_url}/responses`，base URL 配置为裸域名（不带 `/v1`）时全部 404"资源不存在"；`/v1/responses` 同一 Key 正常 200。

## 现象

- `POST /responses`（Codex 实际请求形态）→ 404 资源不存在
- `GET /v1/models` → 200（服务与 Key 正常）
- `POST /v1/responses` → 200（带前缀形态正常）

## 根因

Node→Go 迁移丢失"网关协议路径版本前缀可选"契约，属 BUG-0267 同族的链面接线断线，但断点在 HTTP 入口层：

- **Node 契约（三协议驱动全部按"剥可选前缀"匹配，而非要求前缀存在）**：
  - openai：`protocols/registry.ts` `isOpenAIProtocolRequestPath`，`path.replace(/^\/v1(?=\/|$)/, '')` 后匹配 `/models`、`/embeddings`、`/images*`、`/audio*` 与 contains `/chat/completions`、`/responses`；server.ts 把 `openAIGatewayRouter` 挂在**根路径**，`/responses` 与 `/v1/responses` 同权受理。
  - anthropic：`anthropic-v1/route-helpers.ts` `normalizedAnthropicPath` 用同一正则剥可选 `/v1`，`/messages`、`/messages/count_tokens`、`GET /models` 双形态受理。
  - gemini：`gemini-endpoint-modes.ts` `normalizedGeminiPath` 剥可选 `/v1beta`，`/models/{id}:<action>` 族与 `/interactions*` 双形态受理。
- **Go 实现**：`compose.go` 只 `kern.Register("/v1", chain)` + `kern.Register("/v1/", chain)`，无前缀根形态与 `/v1beta` 形态全部落入 kernel 404 JSON 兜底。链内判定本就基于 `chainStripGatewayVersionPrefix`（剥 `/v1/` 或 `/v1beta/`，chain_driver.go）与 `gatewaygemini.EndpointFamilyFromPath`（自剥 `/v1beta`）归一化，**链内天然兼容两种形态，唯独入口 mux 不放行**——判定在、归一化在、入口接线断。
- **文档裁决**：`docs/architecture/架构总览.md` 第 31 行契约原文"客户端入口按 OpenAI-compatible 形态暴露，支持根路径和 `/v1`"——文档一直正确，代码违约，按"先文档后代码"修正代码。

## 修复

`chain_gateway_root.go`（新增）+ `compose.go` 挂载段，入口按协议路径族清单放行根形态，**按族分流**（独立复审裁决：初审统一补 /v1 的方案对 gemini 族无效——链门 gemini 谓词锚定 `^/models|^/interactions` 且只剥 `/v1beta`，`/v1/models/x:generateContent` 过不了门）：

- **openai/anthropic/compat 族补规范 `/v1` 前缀**（`gatewayRootFormV1Adapter`）：`/responses → /v1/responses`、`/messages → /v1/messages` 等；链门 openai 谓词读原始 `RequestURI`（contains 语义，前缀无关）、anthropic 谓词剥可选 `/v1`，重写形态与原始形态双视图收敛。清单对齐 Node 路径族：`/responses*`、`/chat/completions`、`/models`、`/embeddings`、`/images*`、`/audio*`、`/messages*`（anthropic `/messages/count_tokens`）+ openai-compatible 非协议族 `/files*`、`/containers*`、`/vector_stores*`（后者经链内 `chainCompatFamilies` 分派器服务，不走协议门——chain_v1.go 门 fallback 的 Go 既有分层）。
- **gemini 族原样透传零重写**（`/models/{rest...}`、`/interactions*`、`/v1beta/{rest...}` 直接挂 chain）：`/v1beta` 前缀使 openai（`(?=\/|$)` 不匹配 `v1beta`）与 anthropic 两谓词都不中，gemini 谓词自剥 `/v1beta` 匹配——恰好精确还原 Node 三驱动优先级语义。不能补 `/v1`（gemini 谓词落空 404）、不能剥成裸形态（`GET /v1beta/models` 会被 anthropic 谓词 `GET /models` 先拦，返回形态与 Node 不一致）。
- `Path` 与 `RawPath` 同步改写，避免 `EscapedPath()` 在两者失配时重新编码丢掉段内原始转义；`RequestURI` 刻意保留客户端原始形态（`GatewayRequest.PathAndQuery()` 读它，等价 Node `req.originalUrl`）。
- method 不在 pattern 限定：ServeMux method 限定会先于 handler 产生 405，而 Node 对不可用组合回 404 JSON；转发后由链内守卫决定（与 `/v1` 同形态请求一致）。
- 非协议路径（扫描器噪音、管理面探测、`/v2/responses` 等）保持 kernel 404 JSON 兜底，不进链。

### 与 Node 的已知等价偏差

- **有意增强**：根形态 `/files*`、`/containers*`、`/vector_stores*` 在 Node 为 404（Node 两个 compat router 只注册 `/v1/...` 路径）；Go 放行并经链内有鉴权的 compat 面服务。
- Node contains 语义受理 `/foo/chat/completions` 等任意深度 contains 命中；Go 清单只受理根级子树，其余 404（fail-closed 收窄）。
- 根形态 `GET /models/{id}`（无 gemini action）在 Node 判定链落 404；Go 转发后由链内判定决定，与现行 `GET /v1/models/{id}` 行为一致（同构转发原则）。
- 审计/日志：`Path` 字段记统一后的规范路径（v1 族），`OriginalURL` 记客户端原始形态（RequestURI 透传）；Node 记原始形态——检索口径以两字段各自语义为准。
