# BUG-0117 旁路数据写入放大导致事件循环与后台任务停滞

## 基本信息

- 编号：BUG-0117
- 状态：修复中
- 严重程度：P0
- 发现时间：2026-07-21
- 模块：后端 / 网关 / ingest-worker / 审计 / 运行日志索引 / PostgreSQL
- 关联计划：PLAN-0149

## 问题概述

生产在高并发、大请求体和高频日志场景下出现主进程 RSS、external Buffer 与事件循环延迟显著升高，后台任务一度停止推进；服务重启后恢复。现场还观察到审计 payload 快速增长。普通运行日志另外由 ingest-worker 持续扫描、解析并写入数据库搜索索引。

## 证据与边界

已确认审计捕获、编码、传输和落库是主要放大因素之一；运行日志文件导入会持续产生解析和数据库写入。尚无隔离压测证明任一链路是唯一根因，因此本次结论限定为临时移除已证实的非核心旁路负载。

`usage_records` 是核心业务事实源，必须继续写入；统计、额度、成本和账户质量不能因止血被关闭。

## 修复方案

- 增加默认启用的原始审计部署总开关，关闭时所有新审计工作为 no-op。
- 增加默认启用的运行日志数据库索引开关，关闭时不启动文件 importer 或 facets 维护。
- 保留 Pino 文件输出、轮转、grep、历史查询和重新启用能力。
- temporary-first 发布并验证后，按用户授权清空生产审计和运行日志索引数据。
