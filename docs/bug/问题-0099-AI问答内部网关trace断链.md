# BUG-0099 AI 问答内部网关 trace 断链

## 基本信息

- 状态：已修复（Mock 验证）
- 严重程度：P1
- 模块：后端 / AI 问答 / 网关 / trace
- 发现时间：2026-07-13
- 关联计划：PLAN-0103

## 现象与根因

Chat 路由把外层请求 trace 写入聊天消息，但调用内部 `/v1/chat/completions` 或 `/v1/responses` 时没有传递 `x-trace-id`，导致网关使用记录和聊天消息看起来拥有同一业务请求，实际却无法按 trace 关联。

## 修复与验证

请求开始时只捕获一次 trace，并把同一值传给内部网关、完成/失败/取消落库和站内 SSE 终态。Mock AI 回归同时断言两种协议的上游 header 与消息 trace。

## 防复发

跨模块内部 HTTP 调用必须显式传播关联 ID；同一请求不得在不同阶段重复读取或生成新的 trace。
