# BUG-0082 AI 问答沉浸页移动端失去系统入口

## 基本信息

- 状态：已修复（浏览器验证）
- 严重程度：P1
- 模块：前端 / AI 问答 / 移动端 / 导航
- 发现时间：2026-07-13
- 关联计划：PLAN-0094

## 现象与根因

沉浸布局隐藏全局 Header，而移动端 Sidebar 只能由 Header 打开，导致窄屏聊天页没有离开当前页面、会话管理或退出登录的入口。原 390px 验收只检查了聊天抽屉和输入区，没有验证全局可导航性。

## 修复与验证

移动端沉浸布局保留单个紧凑系统菜单按钮，提供打开全局导航和现有用户操作；消息区/中等宽度会话工具栏为悬浮按钮预留安全空间。工作区同时使用 `100vh` fallback 与 `100dvh`，降低移动浏览器地址栏和软键盘遮挡。静态回归与浏览器窄屏点击验收覆盖入口和遮挡。

## 防复发

隐藏应用壳时必须逐项审计导航、账号操作和退出路径；视觉沉浸不能删除唯一功能入口。
