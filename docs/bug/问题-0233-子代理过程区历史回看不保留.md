# 问题-0233：子代理过程区历史回看不保留

- **状态**：已发布（2026-09-29 19:1x，gateway `b8caa211a` 补丁终版 + 前端 `35a0115f4`）
- **性质**：设计变更（原瞬态设计按用户期望改为持久化），非数据丢失 bug
- **发现**：2026-09-29，用户报障会话 `chat_conv_0e0a5107b56f577e13ee4d8ac3168d6d`「搜索完毕后子代理的内容丢了 是不是没保存啊」（附截图：搜索块展开后仅剩查询词与来源 URL，过程区消失）

## 现象

- 流式轮次内：搜索工具块展开显示「子代理过程区」（思考摘要 / 搜索动作 / 回答摘要头部）。
- 轮次完成或刷新后回看：展开搜索块只剩查询词与来源 URL，过程区内容全部消失。

## 取证

- 生产 `chat_messages.content_blocks_json`（该会话 assistant 消息）：`tool_call` item 仅 `{type, query, sources, sourceCount, executionOwner}`，无 `progress` 字段；reasoning 终态块完好。终态数据无丢失。
- 代码事实：`generation_runner.go` `terminalizeAssistantBlocks` 在落库前 `delete(cloned.Item, "progress")`；前端 `chatMessageProcess.ts` 投影仅在非终态读取 `item.progress`。
- 结论：过程内容为原契约 §10.3 的瞬态设计（「历史回看只有终态摘要与来源，过程区不落库」），非保存失败；与用户期望（回看保留过程内容）冲突，属行为变更。

## 修复（契约先行：`docs/functions/AI问答工具体系与主子模型设计.md` §6.2 数据面 + §10 交互同步更新）

- 后端 `generation_runner.go`：`terminalizeAssistantBlocks` 不再剥离 `item.progress`，终态落库保留最后一次 progress 快照（stage/reasoning/actions/answer 均为限长数据；整体内容块落库仍有 192KB 上限兜底）。
- 后端 `generation_tools.go`（**首版缺口补全，`b8caa211a`**）：progress 原本仅经 `updated` 事件瞬态下发、从未写入持久化 item——首版（`35a0115f4`）删除剥离点后生产实证落库仍无快照。补全：执行 orchestrator 记录最后一次快照，`completed` 事件与输出 `PublicResult` 携带（`reuse_exact` 缓存同享），投影层并入 item 后随消息落库。
- 前端 `chatMessageProcess.ts`：终态与历史回看同样读取 `item.progress` 重建过程区；`ChatToolEvent.vue` 终态下过程区标题用中性「子代理执行过程」（不再显示「…中」）。
- 兼容：存量旧消息无 progress 快照，维持原终态摘要展示，不受影响。
