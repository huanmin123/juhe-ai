# BUG-0371 百炼长转写缺异步头且目录模型与真实可用接口不匹配

## 基本信息

- 编号：BUG-0371
- 状态：已修复待发布
- 严重程度：P1（发布前阻断）
- 发现时间：2026-11-20
- 发现方式：真实上游协议矩阵（DashScope 新 Key + `/v1/audio/jobs`）
- 模块：后端 / 网关 / 长音频异步转写 / 通义百炼连接器
- 关联计划：无（真实上游协议矩阵批次已闭环）

## 问题概述

- 现象 A：qwen 长转写创建请求未携带 `X-DashScope-Async: enable`，真实上游 `paraformer-v2` 返回 403 `current user api does not support synchronous calls`。
- 现象 B：目录行 `qwen3-asr-flash` 被用于 `/api/v1/services/audio/asr/transcription` 的 `input.file_urls` 时，上游返回 400 `InvalidParameter: url error`；该模型不是该文件转写接口的可用模型。
- 期望：目录中可选模型与 adapter 的真实上游接口一致，创建受理后能轮询出转写结果并按秒计费。
- 实际：目录唯一 ASR 行无法被异步文件转写接口接受；真实可用模型 `paraformer-v2`（已实测）不在目录中。

## 复现步骤

1. 直连 `POST /api/v1/services/audio/asr/transcription`，`{"model":"paraformer-v2","input":{"file_urls":["https://dashscope.oss-cn-beijing.aliyuncs.com/audios/welcome.mp3"]}}`，不携带 `X-DashScope-Async`。
2. 上游 403 `current user api does not support synchronous calls`。
3. 改为 `model=qwen3-asr-flash`，携带或不携带异步头，均 400 `url error, please check url`。
4. 改为 `model=paraformer-v2` 且携带 `X-DashScope-Async: enable`，200 返回 `output.task_id`，轮询后 `SUCCEEDED` 并返回转写文本。

## 根因分析

- 早期契约误判该文件转写服务为“天然异步”，adapter 的 `ExtraHeaders` 恒 nil；真实上游把 `X-DashScope-Async: enable` 作为异步任务硬开关。
- 目录清理批移除了 `paraformer-v2` 行，但 qwen ASR adapter 仍按 paraformer 报文实现；替代行 `qwen3-asr-flash` 属于短音频/其他接口面，不接受 `file_urls` 公网 URL 输入。
- `qwen3-asr-flash-filetrans` 虽然接受异步提交，但对公网示例 URL 返回 `InvalidParameter.MalformedURL`，需要进一步确认其文件上传/签名 URL 流程，暂不能直接替换。

## 修复方案

- 已修：`gatewaymedia/qwen_asr.go` 创建请求携带 `X-DashScope-Async: enable`；单测与链上 mock 断言同步更新。
- 已修（目录校准，2026-11-20）：恢复 `paraformer-v2` 目录行（国内 0.00008 元/秒 ÷7.0 = `$1.142857e-05/秒`，含 `mediaPricing` 秒模板），并把 `qwen3-asr-flash` 标记 `catalogVisible=false`、在 `sourcePricingNote` 说明其不适用于当前文件转写接口；目录总量 215→216、qwen 16→17。种子已重生成，价格锚点与双端媒体计价门禁同步更新。
- 后续：`qwen3-asr-flash-filetrans` 的签名 URL/上传流程另行立项；在接入前不同步暴露该模型的 `audio_job_*` 能力。

## 下次遇到

- 先查什么：403 `does not support synchronous calls` 优先查 `X-DashScope-Async`；400 `url error` 优先查模型是否属于该接口面。
- 重点看什么：目录模型名必须与 adapter 的真实上游接口匹配，不能只看模型在厂商模型列表中存在。
- 如何避免误判：不要用“服务天然异步”推断不需要异步头；以真实上游状态码为准。
