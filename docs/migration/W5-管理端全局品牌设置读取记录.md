# W5 管理端全局品牌设置读取记录

> 本文记录 W5 `GET /__aisys__/api/settings/global` 的 Go opt-in 迁移切片。该切片只迁移管理端全局品牌设置读取，不代表 settings 模块、管理端写接口或生产流量已经接管。

## 基本信息

- 模块：管理端全局品牌设置读取
- 状态：Go 实现中
- 迁移波次：W5 供应商、账号、分组、API Key、策略路由、代理、设置
- 当前路径：`GET /__aisys__/api/settings/global`
- 当前 Go owner：`backend-go/internal/httpapi/management_settings.go`、`backend-go/internal/modules/publicsettings/`、`backend-go/internal/store/postgres/store.go`、`backend-go/internal/httpapi/router.go`、`backend-go/internal/app/server.go`
- 关联计划：`../plans/计划-0081-Node转Go渐进减法迁移.md`

## 当前契约

| 项 | 内容 |
| --- | --- |
| 启用条件 | 仅在 `JUHE_AI_MANAGEMENT_API_ENABLED=true` 时注册；默认管理 API 关闭，生产 server 不注册该路径 |
| 登录态 | 必须携带有效管理端 session；使用只读 session 鉴权，不更新 `system_sessions.last_seen_at` |
| 权限 | `admin` / `super_admin` 返回成功；普通 `user` 返回 `403 { "message": "需要管理员权限" }` |
| 限流 | 进入 system API IP read 两个 fixed-window：每分钟 `600`、每 10 秒 burst `120`；认证成功后进入系统账户 user read 每分钟 `300`；未认证请求不消耗 user read bucket |
| 存储 | 复用 W1a `publicsettings.Service`、`port.PublicSettingsReader` 和 `postgres.Store.PublicGlobalSettings`，只读取 `juhe_business.global_settings` 中 `appName` / `appIcon` |
| 成功响应 | 精确返回 `{ "data": { "appName": string, "appIcon": string } }`，不附加其他全局设置或系统设置字段 |
| 缓存 | 响应带 `Cache-Control: no-store` |
| 错误 | `appName` / `appIcon` 缺字段、非法存储值、reader 读取失败、依赖缺失或内部上下文异常统一返回通用 `500 { "message": "服务器内部错误" }`，不得泄露 PostgreSQL、配置、存储原值或内部错误文本 |

成功 DTO 固定为：

```json
{
  "data": {
    "appName": "聚合 AI",
    "appIcon": "/__aisys__/brand-icon.svg"
  }
}
```

## Go 实现边界

- `NewManagementGlobalSettingsHandler` 只负责管理角色检查、调用既有 `publicsettings.Service.Get`、精确 DTO envelope 和错误脱敏。
- router 把该 GET 注册为管理业务 read route，因此复用只读鉴权、IP read 限流、认证用户 read 限流和统一 `no-store` 中间件。
- app 只在完整管理 API opt-in 时构建 handler；session-only 窄开关不会注册该路径。
- 复用的 PostgreSQL reader 要求 `appName` / `appIcon` 都存在且是合法非空 JSON 字符串；缺字段或非法值不能回退默认品牌，必须由 HTTP 层收口为通用 `500`。
- 本切片不新增独立 settings store、缓存或 schema，不复制 W1a 的品牌设置读取逻辑。

## 明确排除

本切片不包含：

- `PATCH /__aisys__/api/settings/global`。
- `GET /__aisys__/api/settings`、`PATCH /__aisys__/api/settings` 或其他 settings GET / PATCH。
- 系统设置局部更新、恢复、缓存失效、操作日志或统计时区写入限制。
- 前端连接真实 Go 后端的系统设置页 smoke。
- 生产反向代理切流、生产单 owner 接管。
- Node settings route / service / repository / 测试命令删除。
