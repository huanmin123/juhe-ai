## 当前契约

### `POST /__aisys__/api/system-teams`

| 项 | 内容 |
| --- | --- |
| 路径 | `POST /__aisys__/api/system-teams` |
| 启用条件 | 仅在 `JUHE_AI_MANAGEMENT_API_ENABLED=true` 时注册；默认生产 server 不注册 |
| 登录态 | 走管理端写鉴权 `ManagementAPIAuthTouchMiddleware`，读取 `juhe_ai_session`、校验 session 未过期、系统账户 active，并按 60 秒最小间隔 touch 当前 session |
| 权限 | 允许 `super_admin` / `admin`；普通 `user` 返回 `403 { message: "需要管理员权限" }` |
| 请求体 | 严格 JSON object，只允许 `name`、`description`、`status`；未知字段、缺少团队名称、非字符串说明、非法状态和尾随 JSON 返回中文 400 |
| 字段规则 | `name` trim 后必填且最长 100 字符，全局唯一；`description` trim 后最长 200 字符，空白 / `null` 表示无说明；`status` 只允许 `active` / `disabled`，默认 `active` |
| PG 写入 | 只写 `juhe_business.system_teams` 的 `id/name/description/status/created_by/created_at/updated_at`；不读取 / 聚合 `system_team_members`、`resource_authorizations` 或 `authorization_sources` |
| 成功响应 | `201 { data: { id, name, description, status, memberCount, activeMemberCount, createdBy, createdAt, updatedAt } }`；新建团队的 `memberCount` / `activeMemberCount` 固定为 0 |
| 操作日志 | best-effort 入队 `operation-log:write`，`operationKey=system_teams.create`、`module=system_teams`、`action=create`、`mode=admin`、`resourceType=system_team`、`viewer=team_creator`；记录 `name/description/status`，不记录成员或授权来源 |
| 切片边界 | 这是 W4 团队创建的 Go opt-in 灰度能力；真实 PostgreSQL + Redis queue / operation-log worker integration、前端团队页 smoke、生产单 owner 切流和 Node `/system-teams` 删除仍未完成 |

## 本轮不迁移范围

- `GET /system-teams`、`GET /system-teams/{id}`、`PATCH /system-teams/{id}`、`POST /system-teams/{id}/members`、`DELETE /system-teams/{id}/members/{memberId}`。
- `POST /authorizations`、授权 grant 更新 / 归还 / 回收 / 到期、授权来源展开、最终用户授权重算和授权用量明细。
- 团队停用触发的团队来源失效、成员增删触发的最终授权同步、授权实例本地绑定和网关可用性校验。
- 前端团队页面连接真实 Go 后端的浏览器 smoke、生产反向代理切流和 Node route / repository 删除。

## Go 实现范围

- `managementsystemteams.Service.Create` 负责团队创建输入归一化、默认 `active` 状态、说明 trim / 长度限制、创建人上下文和重复团队名错误映射。
- `postgres.Store.CreateManagementSystemTeam` 通过 `w4_management_system_teams.sql` 写入 `system_teams`，捕获 `idx_system_teams_name_unique` 唯一约束并映射为团队名称冲突。
- `httpapi.NewManagementSystemTeamCreateHandlerWithOperationLog` 负责管理员权限、strict JSON、`systemAccountId` query 合法性检查、中文错误响应、201 envelope 和 operation log best-effort 入队。
- `router.go` 只在 `JUHE_AI_MANAGEMENT_API_ENABLED=true` 时注册 `POST /system-teams`，并把该写接口纳入 touch middleware fail-fast。
- `server.go` 在管理 API opt-in 时构建 `managementsystemteams.Service` 和团队创建 handler；默认关闭时不构建生产路由。

## 删除门禁

- `POST /system-teams` 进入 Go opt-in 不允许删除 Node `system-teams` route / repository。
- W4 至少需要团队 CRUD、成员增删、授权 grant、授权来源展开 / 归还 / 回收 / 到期、operation log、真实 PG/Redis/Asynq smoke、前端浏览器 smoke、生产单 owner 切流和回滚记录整体完成后，才可以评估 Node 删除。
- 团队创建本身不触发授权来源展开；任何把 `POST /system-teams` 当成统一授权生产接管证据的结论都是无效证据。
