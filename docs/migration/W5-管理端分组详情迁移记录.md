## 当前切片

本切片只包含：

- `GET /__aisys__/api/groups/{id}`
- `GET /__aisys__/api/my-groups/{id}`

两条路径只在 `JUHE_AI_MANAGEMENT_API_ENABLED=true` 且完整注入管理鉴权、PostgreSQL store 和 Redis state reader 时注册。默认生产 server 不挂载。

本切片不包含分组更新、删除、授权本地设置写入、统计 worker 接管、前端生产入口切换或 Node 路由删除。

## 权限与作用域

- `/groups/{id}` 只允许 `admin` / `super_admin`。
- 管理端未传 `systemAccountId` 或传 `all` 时按 owner 视图查找；传具体 ID 时返回该账户拥有或被授权可见的分组。
- `systemAccountId` 重复参数返回 `400 { "message": "Expected string, received array" }`，空值返回 `400 { "message": "系统账号 ID 不能为空" }`。
- `systemAccountId` 使用 ECMAScript `trim()` 空白集合；路径 `{id}` 保持原值查询，带前后空白的 ID 不会被隐式规范化命中。
- `/my-groups/{id}` 强制当前 session 账户作用域，忽略 query 中的 `systemAccountId`。
- 不可见或不存在统一返回 `404 { "message": "分组不存在" }`。
- 两条 GET 路由都使用只读鉴权，不更新 session `last_seen_at`，并经过 IP read limiter 与 authenticated user read limiter。
- 响应固定 `Cache-Control: no-store`；内部依赖错误统一脱敏为 `500 { "message": "服务器内部错误" }`。

## 响应边界

owner 详情返回：

- 分组基础字段、owner 字段、调度策略、权限和预聚合 usage/stat 摘要；
- 当前有效绑定账户的 `accountIds`，按绑定创建时间和账户 ID 稳定排序；
- `accountStats.total` 使用当前有效绑定数；
- `accountStats.currentConcurrency` 使用 Redis `account-concurrency-v2` 当前有效槽实时求和，覆盖预聚合值。

authorized 详情返回：

- owner 基础字段、授权 ID、状态、到期时间、额度限制、权限和完整授权来源；
- `accountIds=[]`，不暴露 owner 账户 ID；
- `systemAccountId/systemAccountName` 不返回；
- `isDefault=false`；
- `accountStats` 与 usage 使用后台 worker 预聚合结果，不以 Redis 实时值改写授权视图统计。

授权来源按状态 `active -> paused -> expired -> revoked -> returned -> other`，再按 `created_at ASC, id ASC` 返回；包含 manual / team 来源状态和团队名称，响应不回显撤销操作者等无前端依赖字段。

## 存储与性能边界

- 详情可见性使用 owner / authorized union，授权只接受 `active`、`paused`、`expired`，排除 `revoked` 和 `returned`。
- 账户 ID 查询只读取启用绑定、未删除账户和有效授权实例，不读取账户凭据。
- usage 与账户状态统计只读取 `juhe_stats` 预聚合表，不扫描 `usage_records` 明细，不在请求路径做 `SUM/GROUP BY`。
- Redis reader 使用 Node 当前根 namespace 的 `account-concurrency-v2:{accountId}:*` key；Lua 原子清理已过期 total/text/image 槽和 metadata 后再读取 `ZCARD`。
- 未显式设置 `JUHE_AI_REDIS_NAMESPACE` 时，Go 与 Node 都按 `JUHE_AI_SECRET` 派生 `env-<sha256 前 12 位>`，不做双读。
- 单次 Redis 读取最多接受 100 个账户 ID；去空白、去重并保持失败显式返回，不能把 Redis 故障伪装成零并发。
