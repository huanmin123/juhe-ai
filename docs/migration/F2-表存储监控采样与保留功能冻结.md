# F2 表存储监控采样与保留功能冻结

> 冻结日期：2026-08-09。本文记录 F2 完整功能接管后的当前事实、owner、配置和验收边界。

## 接管结论

F2 已由 Go 完整接管。常驻 `projects/jobs/cmd/juhe-ai-jobs` 内的 `projects/jobs/internal/tablemonitor` 是唯一的采样、快照写入和表监控历史保留 owner；这不是 opt-in、灰度、双写或 Node/Go owner switch。Node scheduler、stats writer 和 Node retention 已退出，Node 只保留表监控 HTTP 读接口。F2 独立持有 Store、schema 和 owner lease，并与 gateway 项目独立运行。

Go 直接异步并发采样，不引入 queue、Redis、Asynq、Node IPC、bridge 或 fallback。SQLite 和 PostgreSQL 均为正式运行模式；不得把主网关、账户管理或其他业务迁移到 Go。

## 存储与写入边界

- SQLite 源库按业务、数据集目录、usage catalog、stats 和 Codex Context shard 采样；输出写入 `JUHE_AI_TABLE_MONITOR_DATABASE_PATH` 指定的 F2 专用 SQLite 文件。Go 是该文件唯一 writer，Node 只读该文件；启动时强制并回读验证 `journal_mode=WAL` 与 `busy_timeout=5000`。输出文件不得与任何源库、shard 或 F1 `JUHE_AI_RUNTIME_LOG_DATABASE_PATH` 指向同一个物理文件，即使路径名称不同或通过 hard link/symlink 指向同一文件。
- PostgreSQL 源 schema 为 `juhe_business`、`juhe_dataset`、`juhe_usage`、`juhe_stats`、`juhe_codex_context`；快照和保留清理写入 `juhe_stats.database_storage_snapshots` 与 `juhe_stats.table_storage_snapshots`。源库采样与输出写入可以并发，但 Go 输出事务受 owner lease 和连接池约束。
- 采样结果包含数据库/表快照；不存在、不可读或不完整的源库必须返回原始错误，本轮失败，不返回伪造的零值或空快照。SQLite 不可用时不得回退 PostgreSQL，PostgreSQL 不可用时不得回退 SQLite。
- 表监控历史默认保留 30 天，保留清理由 Go F2 owner 在采样提交后按上限批量执行；Node 不再删除这两张表。页面的非业务数据硬清理仍是独立 HTTP 入口，不触发表监控采样，也不改变 F2 owner。

## 配置与启动

启动必须提供：

- `JUHE_AI_TABLE_MONITOR_INSTANCE_ID`：稳定且唯一的实例标识，用于 owner lease fencing。
- `JUHE_AI_TABLE_MONITOR_STORE=sqlite|postgres`（未设置时读取 `JUHE_AI_DATABASE_DRIVER`）。SQLite 需要 `JUHE_AI_TABLE_MONITOR_DATABASE_PATH`、F1 的 `JUHE_AI_RUNTIME_LOG_DATABASE_PATH`、四个源库路径和 `JUHE_AI_CODEX_CONTEXT_STATE_SHARD_ROOT`；PostgreSQL 需要 `JUHE_AI_POSTGRES_URL`。
- `JUHE_AI_TABLE_MONITOR_INTERVAL`、`JUHE_AI_TABLE_MONITOR_RUN_TIMEOUT`、`JUHE_AI_TABLE_MONITOR_RETENTION_DAYS`、`JUHE_AI_TABLE_MONITOR_MAX_TABLES`，默认分别为 `1m`、`45s`、`30`、`256`；owner lease 使用 `JUHE_AI_TABLE_MONITOR_OWNER_LEASE`，默认 `5m`。采样并发使用 `JUHE_AI_TABLE_MONITOR_MAX_CONCURRENT_SOURCES`，默认 `512`（范围 `1..5096`）；retention 使用 `JUHE_AI_TABLE_MONITOR_RETENTION_BATCH_SIZE`，默认 `512`（范围 `1..5096`），以及 `JUHE_AI_TABLE_MONITOR_RETENTION_MAX_BATCHES`，默认 `512`（范围 `1..5096`）。达到批次数上限后仍有过期数据时显式失败。同一事实库第二个 Go 实例拒绝启动，失去 lease 后采样和保留清理拒写；该 fencing 不是 Node/Go 开关，也不是队列或 fallback。

缺配置、路径复用、连接失败、schema 初始化失败、owner lease 丢失或采样写入失败都必须显式失败并保留错误；不得静默降级、切回 Node 或声明成功。

## 读取与接口

Node 保留 `/__aisys__/api/table-monitor/overview`、`/history` 和 `/database-history` 读取接口。SQLite 读取只打开 F2 专用输出文件；PostgreSQL 读取只从 `juhe_stats` 快照表读取。读取失败不得执行 DDL/DML 或回退到源库实时扫描。

## 验收状态

- 已确认：Go F2 命令和 `projects/jobs/internal/tablemonitor` 存在；SQLite 专用输出库、SQLite 单 writer、PostgreSQL `juhe_stats` 写入、直接异步采样、保留清理、配置校验和 Node 只读边界均已落地；Node 回归断言不再保留采样/保留 writer API。
- 已确认：SQLite 定向测试可作为本地验证证据，覆盖采样、快照写入和保留清理。
- 已验证：2026-08-09 开发 PostgreSQL/PgBouncer 可连通；共享开发库已有 F2 快照，smoke 按空库保护拒绝写入。经用户明确授权创建一次性空库后，强制 smoke 通过真实 adapter、lease takeover、relation-size 快照、五个 PostgreSQL schema 的 `RunOnce` 采样和 retention 清理，测试库已删除。
- 未验证：生产 listener、Docker 实启动、发布包生命周期和生产运行仍未通过本冻结记录验收，不能把隔离 smoke 等同生产部署证据。
