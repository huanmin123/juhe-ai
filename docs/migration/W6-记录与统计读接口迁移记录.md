# W6 记录与统计读接口迁移记录

## 当前范围

W6 当前 Go opt-in 范围包含两个互不扩大的只读切片：

- `GET /__aisys__/api/stats/usage-window`
- `GET /__aisys__/api/my-stats/usage-window`
- `GET /__aisys__/api/runtime-logs`
- `GET /__aisys__/api/runtime-logs/{id}`

两条路径读取 `juhe_business.system_settings` 中 `sys_admin / usageStatsTimezone`，返回统计时区当天向前包含当天的固定 31 天窗口：

```json
{
  "data": {
    "timezone": "Asia/Shanghai",
    "startDate": "2026-06-10",
    "endDate": "2026-07-10",
    "days": 31,
    "maxDays": 31
  }
}
```

运行日志列表只读取 Node 生产 writer 写入 `juhe_dataset.runtime_logs` 的轻量索引列，详情才按单个 ID 读取 `raw_json`。`GET /runtime-logs/facets`、`GET /runtime-logs/grep`、日志文件增量导入、索引写入、facet 生产和保留清理仍由 Node 负责，不属于本切片。

## 契约与边界

- 管理侧只允许 `admin` / `super_admin`；个人侧允许任意已认证系统账户。
- 两条路径都使用只读 session 鉴权，不更新 `system_sessions.last_seen_at`。
- 查询参数不参与窗口计算；个人侧不会接受 `systemAccountId` 改写全局统计窗口。
- 时区校验兼容 Node `Intl.DateTimeFormat` 的大小写不敏感 IANA 名称和必要历史别名，并显式拒绝 Go-only 的 `Local` / `Factory`；响应保留配置原文返回，服务内缓存已验证时区 60 秒，避免每次请求读取 PostgreSQL。
- 配置缺失、空字符串、非法 JSON 或非法 IANA 时区均返回通用 `500`，不静默回退 UTC。
- 请求路径只读取系统设置，不读取 `usage_records`、统计日表或 range window，不执行 `SUM`、`GROUP BY` 或前端聚合。
- 当前生产 router 默认关闭；只有显式设置 `JUHE_AI_MANAGEMENT_API_ENABLED=true` 才注册 Go 路径。

### 运行日志列表与详情

- 两条路径只允许 `admin` / `super_admin`，使用只读 session 鉴权，不更新 `system_sessions.last_seen_at`，并经过管理端用户读限流。
- 列表保持 Node 当前宽容 query 语义：`page/pageSize` 非整数时使用默认值，`pageSize` 固定 `1..100`，页码按最多 1000 条可见记录的窗口截断；读取 `pageSize + 1` 判断 `hasMore`，`total` 是 progressive upper bound，不执行 `COUNT(*)`。
- 支持 `traceId` 大小写敏感 C 排序前缀、精确 `level/event`、`startAt/endAt` 和只匹配 `message` 的字面 keyword；keyword 未提供有效时间边界时自动限定最近 6 小时，`%/_/\\` 不作为调用方通配符。
- PostgreSQL 列表 repository 只为实际存在的筛选条件生成白名单参数化谓词，不保留 `参数为空 OR 条件` 形式；默认列表、trace 前缀、level、event 和 keyword + 时间窗口都必须在 `force_generic_plan` 下保留可验证的索引路径。
- query 首值、十六进制 / 二进制 / 八进制 / 指数整数、ECMAScript `trim()` 空白、合法 RFC3339、year-only、year-month、纯日期、无秒本地时间、无冒号 offset 和反向时间范围按 Node 当前语义归一化；ANSIC 无时区文本按本机时区解释，不得用更宽的 Go `strings.TrimSpace` 把 `U+0085` 等非 ECMAScript 空白误删。
- 列表固定按 `time DESC, id DESC`，不选择或返回 `raw_json`；详情接受 Node writer 当前允许的任意单 path segment 自定义 ID，返回同一摘要字段和必需 `rawJson`，不存在返回 `404 { message: "运行日志不存在" }`；精确 `/facets`、`/grep` 不进入详情 service。
- 列表继续返回 Node 当前固定降级元数据：`retentionDays=null`、`retentionDaysSource="unavailable"`、`runtimeAvailable=false`、`workerSnapshotAvailable=false`、`runtimeLogIndexQueueAvailable=false`，并返回非负 `elapsedMs`。
- 请求上下文上限为 120 秒；HTTP 响应继承 `Cache-Control: no-store`，依赖错误只返回通用中文 500，不回显 PostgreSQL、Cookie 或内部错误。
- migration `000045` 在 fresh Goose schema 中完整保留 Node writer 继续运行所需的 `runtime_logs`、file cursor、facet 三张表及其索引，并为 level/event 列表补 `(筛选列, time DESC, id DESC)` 有界读取索引，避免稀有或不存在筛选值退化为大范围扫描；Go 本切片只读取 `runtime_logs`，不读取或接管 cursor / facet，不引入全文检索扩展，也不接管 writer。
- Node writer 写入前把合法 `time/createdAt` 统一为 `Date#toISOString()`，非法或缺失值复用同一个当前时间兜底，保证 PostgreSQL `text` 时间列的排序、范围筛选和 Go reader 结果稳定。
- Node writer 在写入前把 `raw_json` 限制为 128KB，Go 详情只读取单条受限 payload；列表不读 payload，不读取日志文件，不做全文件 `split`、扫描或请求内聚合。
- 增量反代必须精确区分列表、单 ID 详情和保留在 Node 的 `/facets`、`/grep`，禁止把整个 `/runtime-logs/*` 前缀提前交给 Go。

单元和路由测试必须覆盖跨 UTC 日期边界、固定 31 天、缺失 / 空 / 非法时区、管理员权限、个人路径、`Cache-Control: no-store` 和只读鉴权不 touch。运行日志还必须覆盖 1000 行窗口、lookahead / progressive total、所有筛选、6 小时 keyword 窗口、ECMAScript 空白、列表 payload 隔离、详情 / 404、固定降级元数据和依赖错误脱敏。

integration smoke 必须在健康 Docker/testcontainers 或独立 PostgreSQL 中先应用 fresh Goose `000001..000045`，不得由测试手工补 writer 表，再调用 Node 生产 `createRuntimeLogsBatchAsync` 写主表和 facet，并通过真实 Go store / service / router / session Cookie 读取；默认、trace 前缀、level、event 和 keyword + time SQL 必须直接复用生产查询构造结果，在 `plan_cache_mode=force_generic_plan` 下用 `EXPLAIN` 证明目标索引可用。普通模式 Docker 不可用时只能 `SKIP`，`JUHE_AI_REQUIRE_INTEGRATION=1` 必须非零失败，二者都不能记为真实依赖通过。

## 未完成与删除门禁

本切片不代表 W6 或统计模块已经接管。以下证据完成前不得删除 Node `statsRouter` 中的同名路径：

- 浏览器连接真实 Go 后端的管理侧 / 个人侧统计页面 smoke。
- 真实 PostgreSQL 环境下的配置读取和跨时区验证。
- Node 认证用户 read / write 固定窗口限流在 Go 管理 API 的横向迁移；当前 Go 只有 system API IP read 限流，不能把本切片视为完整抗滥用边界接管。
- 反向代理按路径保持单 owner，生产流量确认命中 Go。
- Node 两条 `usage-window` 路由删除及重复路由搜索证据。
- 运行日志 Node writer -> Go reader integration 与三类 EXPLAIN 必须在健康真实 PostgreSQL 环境实际通过；本机没有 Docker / PostgreSQL client 时的 `SKIP` 或严格失败只证明门禁有效。
- 运行日志列表 / 详情精确单 owner 切流、真实前端或请求脚本连接 Go URL / Cookie、延迟与错误率观测和回滚证据。
- Node `runtime-logs` 列表 / 详情删除及重复路由搜索证据；facets、grep、writer、文件导入、保留清理和相关表在对应切片迁移前继续保留。
- W6 其他使用记录、审计、原始审计、运行日志 facets / grep、统计窗口读取和 Go 系统指标契约迁移。
