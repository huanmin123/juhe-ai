## 当前契约

W2 覆盖后台管理页面需要的只读 options / catalog / 列表辅助接口，并额外拆分低风险删除 / 小写入 / operation log 读路径灰度切片。当前 Node 管理端路径统一挂在 `/__aisys__/api`，先经过 `requireAuth`；管理端完整列表和写操作再额外经过 `requireAdmin`，个人端路径走 `my-*` 作用域。

代理管理列表固定 `GET /__aisys__/api/proxies`：

| 项 | 当前契约 |
| --- | --- |
| 登录态 | 必须登录；未登录返回 `401 { message: "请先登录" }`，会话过期返回 `401 { message: "登录会话已过期" }` |
| 权限 | 必须是 `admin` / `super_admin`；普通用户返回 `403 { message: "需要管理员权限" }` |
| 查询参数 | `page` 默认 1，`pageSize` 默认 20 且范围 1-200，`keyword` 只按代理名称前缀搜索；非法整数按未传处理，不支持 `sort/order/enabled/type/host` |
| 成功响应 | `200 { data: { items, total, hasMore, page, pageSize } }` |
| 列表字段 | `items[]` 只返回 `id/name/description?/type/host/port/username?/enabled/testStatus/latencyMs?/outboundIp?/outboundRegion?/lastTestMessage?/lastTestedAt?` |
| 排序 / 分页 | 排序为 `updated_at DESC, id DESC`；使用 `pageSize+1` 判断 `hasMore`，`total` 是当前窗口上界，不做全表 `COUNT(*)` |

| 登录态 | 必须登录；使用只读 session 鉴权，不 touch session |
| 权限 | 只允许 `admin` / `super_admin`；普通用户返回 `403 { message: "需要管理员权限" }` |
| 限流与缓存 | 经过鉴权前 IP read limiter 和鉴权后用户 read limiter；响应 `Cache-Control: no-store` |
| 成功响应 | `200 { data: [{ value, label }, ...] }`；精确返回 API Key、策略路由、分组和账号四类资源的 4 个读 scope 与 12 个写 scope，顺序与 Node 一致 |
| 数据边界 | 纯静态目录，不读取 PostgreSQL / Redis / Asynq；`scopes` 与 `api-docs` 使用独立 handler，本接口不读取或拼装富文档快照 |

外部来源接入文档目录固定 `GET /__aisys__/api/external-integration-sources/api-docs`：

| 项 | 当前契约 |
| --- | --- |
| 登录态 / 权限 | 与 `scopes` 相同：只读 session 不 touch，只允许 `admin` / `super_admin` |
| 限流与缓存 | 经过鉴权前 IP read limiter 和鉴权后用户 read limiter；响应 `Cache-Control: no-store` |
| 成功响应 | `200 { data: { basePath: "/__aipublic__", authType: "Bearer", items: [...] } }`；固定 16 项 `id/method/path/scope`，并保留 `name/summary/status/headers/query/requestBody/responseFields/responseExample` 富文档字段 |
| 数据边界 | Node 结构化目录是编写事实源，生成器提交确定性 JSON 快照，Go 通过 `embed` 只读提供；生产请求不调用 Node，不读取 PostgreSQL / Redis / Asynq，也不注册来源列表 / 详情、token 或写接口 |
