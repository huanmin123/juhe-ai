## 当前契约

W2 覆盖后台管理页面需要的只读 options / catalog / 列表辅助接口。当前 Node 管理端路径统一挂在 `/__aisys__/api`，先经过 `requireAuth`；管理端完整列表和写操作再额外经过 `requireAdmin`，个人端路径走 `my-*` 作用域。

第一块固定 `GET /__aisys__/api/proxies/options`：

| 项 | 当前契约 |
| --- | --- |
| 登录态 | 必须登录；未登录返回 `401 { message: "请先登录" }`，会话过期返回 `401 { message: "登录会话已过期" }` |
| 权限 | 普通登录用户可访问；不要求 admin；完整 `/proxies` 列表和写操作仍要求 admin |
| 初始密码 | 普通用户 `must_change_password=true` 返回 `403 { message: "请先修改初始密码", code: "must_change_password" }`；admin / super_admin 走 Node 当前 effective 口径，不因该字段阻断只读 options |
| 查询参数 | `keyword` 可选，按代理名称前缀搜索；`limit` 可选，默认 50，范围 1-50；非法整数按未传处理 |
| 成功响应 | `200 { data: [{ id, name, type, enabled }] }` |
| 数据边界 | 只返回启用代理；排序为 `name ASC, updated_at DESC, id ASC`；不返回 host、port、username、password、测试状态或系统账户信息 |
| 缓存 | 系统 API 统一 `Cache-Control: no-store` |

| 项 | 当前契约 |

## W2 范围澄清

W2 不是“所有后台接口”，只迁移只读辅助接口。后续分块建议：

1. `GET /__aisys__/api/proxies/options`（已补 Go 实现，未生产接管）
2. `GET /__aisys__/api/system-accounts/options`（已补 Go admin-only 轻量只读实现，未生产接管；系统账户完整列表 / 写接口 / 登录仍属 W3）
3. `GET /__aisys__/api/authorization-options/grantee-accounts`、`/my-authorization-options/grantee-accounts`、`/authorization-options/grantee-groups` 和 `/my-authorization-options/grantee-groups`（已补 Go 轻量只读实现，未生产接管；grantee teams、授权来源 / grant / 写接口未迁移）
4. `GET /__aisys__/api/providers/options`（已补 Go 实现，未生产接管）
5. `GET /__aisys__/api/route-strategies/options` 和 `GET /__aisys__/api/my-route-strategies/options`（已补 Go 实现，未生产接管）
6. `GET /__aisys__/api/providers/models/options` 和 `GET /__aisys__/api/providers/:code/models`（已补 Go 实现，未生产接管）
7. `GET /__aisys__/api/groups/options` 和 `/my-groups/options`（已补 Go owner + 授权组只读 union 实现，未生产接管；授权来源 / grant / 写接口未迁移）
8. `GET /__aisys__/api/groups/account-options` 和 `/my-groups/account-options`（已补 Go owner + 授权组只读 union 实现，授权组 `accountIds=[]`，未生产接管；授权来源 / grant / 写接口未迁移）
9. `GET /__aisys__/api/accounts/options` 和 `/my-accounts/options`（已补 Go owner + 授权账户只读 union 实现，未生产接管；owner `tagIds` 过滤和名称包含搜索已迁移；授权来源 / grant / 写接口和标签写接口未迁移）
10. `GET /__aisys__/api/accounts/tags` 和 `/my-accounts/tags`（已补 Go owner-only 只读实现，未生产接管；标签写接口未迁移）

清单里旧称的 `API Key options` 实际应理解为 API Key 表单依赖的 `route-strategies/options`；当前前端没有独立 `api-keys/options` 接口。`providers/models/options` 和 `providers/:code/models` 这次只迁只读 catalog，不包含 `POST/PATCH/DELETE /providers/:code/models` 和 `PUT /providers/:code/default-test-model`。
