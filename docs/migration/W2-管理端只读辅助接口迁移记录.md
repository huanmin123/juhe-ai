## 当前契约

W2 覆盖后台管理页面需要的只读 options / catalog / 列表辅助接口，并额外拆分低风险删除 / 小写入 / operation log 读路径灰度切片。当前 Node 管理端路径统一挂在 `/__aisys__/api`，先经过 `requireAuth`；管理端完整列表和写操作再额外经过 `requireAdmin`，个人端路径走 `my-*` 作用域。

代理管理列表固定 `GET /__aisys__/api/proxies`：

| 项 | 当前契约 |
| --- | --- |
| 登录态 | 必须登录；未登录返回 `401 { message: "请先登录" }`，会话过期返回 `401 { message: "登录会话已过期" }` |
| 权限 | 必须是 `admin` / `super_admin`；普通用户返回 `403 { message: "需要管理员权限" }` |
| 查询参数 | `page` 默认 1，`pageSize` 默认 20 且范围 1-200，`keyword` 只按代理名称前缀搜索；非法整数按未传处理，不支持 `sort/order/enabled/type/host` |
| 成功响应 | `200 { data: { items, total, hasMore, page, pageSize } }` |
| 列表字段 | `items[]` 只返回 `id/name/description?/type/host/port/username?/enabled/testStatus/latencyMs?/outboundIp?/outboundRegion?/lastTestMessage?/lastTestedAt?` |
| 排序 / 分页 | 排序为 `updated_at DESC, id DESC`；使用 `pageSize+1` 判断 `hasMore`，`total` 是当前窗口上界，不做全表 `COUNT(*)` |
| 数据边界 | 管理列表包含启用和停用代理；不读取或返回 `password_encrypted`、解密密码、`proxyUrl`、`system_account_id`、`created_at` 或 `updated_at`；不执行代理检测或网络请求 |
| 缓存 | 系统 API 统一 `Cache-Control: no-store` |

## W2 范围澄清

W2 不是“所有后台接口”，当前以只读辅助接口为主，额外包含账号标签未绑定删除、独立标签 PATCH、默认测试模型偏好写入和 operation log 读路径等已拆分切片。后续分块建议：

1. `GET /__aisys__/api/proxies` 和 `GET /__aisys__/api/proxies/options`（已补 Go 管理列表读和下拉实现，未生产接管；代理创建 / 更新 / 删除 / 检测仍未迁移）
