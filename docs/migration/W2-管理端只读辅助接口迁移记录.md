W2 覆盖后台管理页面需要的只读 options / catalog / 列表辅助接口。当前 Node 管理端路径统一挂在 `/__aisys__/api`，先经过 `requireAuth`；管理端完整列表和写操作再额外经过 `requireAdmin`，个人端路径走 `my-*` 作用域。

## W2 范围澄清

W2 不是“所有后台接口”，只迁移只读辅助接口。后续分块建议：

1. `GET /__aisys__/api/proxies/options`（已补 Go 实现，未生产接管）
2. `GET /__aisys__/api/providers/options`（已补 Go 实现，未生产接管）
3. `GET /__aisys__/api/route-strategies/options` 和 `GET /__aisys__/api/my-route-strategies/options`（已补 Go 实现，未生产接管）
4. `GET /__aisys__/api/providers/models/options` 和 `GET /__aisys__/api/providers/:code/models`（已补 Go 实现，未生产接管）
5. `GET /__aisys__/api/groups/options` 和 `/my-groups/options`（已补 Go owner-only 实现，未生产接管；授权组 union 未迁移）
6. `GET /__aisys__/api/groups/account-options` 和 `/my-groups/account-options`（未迁移）
7. `GET /__aisys__/api/accounts/options` 和 `/my-accounts/options`（已补 Go owner-only 实现，未生产接管；授权账户 union、账号标签和名称包含搜索未迁移）

清单里旧称的 `API Key options` 实际应理解为 API Key 表单依赖的 `route-strategies/options`；当前前端没有独立 `api-keys/options` 接口。`providers/models/options` 和 `providers/:code/models` 这次只迁只读 catalog，不包含 `POST/PATCH/DELETE /providers/:code/models` 和 `PUT /providers/:code/default-test-model`。

## 当前 Go 实现

- 新增 `juhe_business.proxy_profiles` PostgreSQL migration，仅作为 W2 代理配置表，不引入 SQLite。
