## 当前契约

W2 覆盖后台管理页面需要的只读 options / catalog / 列表辅助接口。当前 Node 管理端路径统一挂在 `/__aisys__/api`，先经过 `requireAuth`；管理端完整列表和写操作再额外经过 `requireAdmin`，个人端路径走 `my-*` 作用域。

第一块固定 `GET /__aisys__/api/proxies/options`：

| 项 | 当前契约 |
| --- | --- |
| 登录态 | 必须登录；未登录返回 `401 { message: "请先登录" }`，会话过期返回 `401 { message: "登录会话已过期" }` |
| 权限 | 普通登录用户可访问；不要求 admin；完整 `/proxies` 列表和写操作仍要求 admin |
| 初始密码 | 普通用户 `must_change_password=true` 返回 `403 { message: "请先修改初始密码", code: "must_change_password" }`；admin / super_admin 走 Node 当前 effective 口径，不因该字段阻断只读 options |
| 查询参数 | `keyword` 可选，按代理名称前缀搜索；`limit` 可选，默认 50，范围 1-50；非法整数按未传处理 |
| 成功响应 | `200 { data: [{ id, name, type, enabled }] }` |
| 数据边界 | 只返回启用代理；排序为 `name ASC, updated_at DESC, id ASC`；不返回 host、port、username、password、测试状态或系统账户信息 |
| 缓存 | 系统 API 统一 `Cache-Control: no-store` |

第二块固定 `GET /__aisys__/api/providers/options`：

| 项 | 当前契约 |
| --- | --- |
| 登录态 | 必须登录；沿用 W2 Go `requireAuth` session 鉴权基线 |
| 权限 | 普通登录用户可访问；不要求 admin；查询参数 `systemAccountId` 只有 admin / super_admin 可指定，普通用户始终使用自己的系统账户作用域 |
| 查询参数 | `systemAccountId` 可选；空值和 `all` 按未指定处理 |
| 成功响应 | `200 { data: ProviderDefinition[] }`，字段包含 `id`、`code`、`name`、`parentCode`、`description`、`enabled`、`defaultProtocolProfileId`、`protocolCode`、`protocolVersion`、`baseUrl`、`defaultTestModel`、`defaultSupportedModels`、`accountTypes`、`capabilities`、`protocolProfiles` |
| 协议画像 | `protocolProfiles[]` 返回 `id`、`providerCode`、`name`、`description`、`enabled`、`protocolCode`、`protocolVersion`、`baseUrl`、`defaultTestModel`、`accountTypes`、`capabilities`、`endpointFamilies`；`endpointFamilies[]` 返回 `code`、`name`、`description` |
| 默认测试模型 | 如果存在 `provider_default_test_models` 当前系统账户偏好，则覆盖供应商顶层 `defaultTestModel`，并同步覆盖默认协议画像的 `defaultTestModel` |
| 数据边界 | 只返回启用供应商；返回供应商定义和协议画像，不返回模型目录、自定义模型列表、账号凭据或供应商完整后台 CRUD 字段 |
| 缓存 | 系统 API 统一 `Cache-Control: no-store` |

## W2 范围澄清

W2 不是“所有后台接口”，只迁移只读辅助接口。后续分块建议：

1. `GET /__aisys__/api/proxies/options`（已补 Go 实现，未生产接管）
2. `GET /__aisys__/api/providers/options`（已补 Go 实现，未生产接管）
3. `GET /__aisys__/api/providers/models/options`
4. `GET /__aisys__/api/providers/:code/models`
5. `GET /__aisys__/api/route-strategies/options` 和 `GET /__aisys__/api/my-route-strategies/options`
6. `GET /__aisys__/api/groups/options`、`/my-groups/options`、`/groups/account-options`、`/my-groups/account-options`
7. `GET /__aisys__/api/accounts/options` 和 `/my-accounts/options`

清单里旧称的 `API Key options` 实际应理解为 API Key 表单依赖的 `route-strategies/options`；当前前端没有独立 `api-keys/options` 接口。`providers/models/options` 和 `providers/:code/models` 涉及模型 catalog、自定义模型和供应商模型状态，复杂度高于 `providers/options`，不混入本次第二块。

## 当前 Go 实现

- 新增 `juhe_business.proxy_profiles` PostgreSQL migration，仅作为 W2 代理配置表，不引入 SQLite。
- 新增 `juhe_business.system_sessions` PostgreSQL migration，用于 Go 管理端 `requireAuth` 级 session 校验；登录、登出、验证码、改密和 session 创建仍属于 W3，不在本块迁移。
- 新增 `juhe_business.protocol_endpoint_families`、`juhe_business.provider_protocol_profile_families` 和 `juhe_business.provider_default_test_models` PostgreSQL migration，用于 `providers/options` 的协议能力、endpoint family 和系统账户默认测试模型偏好；同时把供应商 seed 对齐当前 Node 默认定义。
- 新增 sqlc 查询 `ListManagementProxyOptions`，在 PostgreSQL 中使用 `name COLLATE "C"` 前缀窗口和 `starts_with`，避免模糊扫描。
- 新增 sqlc 查询 `FindManagementSessionByTokenHash`，按 Node `hashSecret(token)=sha256(token)` 口径查 `system_sessions` 并 join `system_accounts`。
- 新增 sqlc 查询 `ListManagementProviderOptionProviders`、`ListManagementProviderOptionProfiles`、`ListManagementProviderOptionEndpointFamilies` 和 `ListManagementProviderDefaultTestModelPreferences`。
- 新增 `ManagementProxyOptionReader`、`ManagementProviderOptionReader` 和 `ManagementSessionReader` port，业务层不接触 pgx / sqlc 类型。
- 新增 `managementauth.Authenticator` 和 `NewManagementAPIAuthMiddleware`，覆盖缺 cookie、会话过期、禁用账号、普通用户初始密码拦截和 auth context 注入。
- 新增 `managementproxies.Service`，负责 trim、limit clamp 和响应字段白名单。
- 新增 `managementproviders.Service`，负责供应商定义 DTO 映射、协议画像嵌套映射、默认 profile 标记和 `systemAccountId` 作用域输入清洗。
- 新增 `NewManagementProxyOptionsHandler` 和 `NewManagementProviderOptionsHandler`，复用 `{ data: ... }` envelope，内部错误统一脱敏为 `服务器内部错误`。
- `router.go` 只有在 `JUHE_AI_MANAGEMENT_API_ENABLED=true` 且注入 `ManagementAPIAuthMiddleware` 时才注册当前已迁移 W2 后台只读路由；默认 `false` 时生产路由不接管。显式开启后只注册已注入 handler 的路径，当前包括 `/__aisys__/api/proxies/options` 和 `/__aisys__/api/providers/options`。

该实现只证明 Go 侧具备前两块只读接口的 schema、store、service、handler、`requireAuth` 级鉴权和显式灰度挂载基础，不代表 `/__aisys__/api/*` 管理端生产 owner 已切换。

## 接管门禁

W2 任意单个只读接口通过测试，都不能进入 `待删除 Node`。必须同时满足：

- Go 已实现 W2 所需的登录态、会话过期、普通用户初始密码修改拦截和后台 options 登录边界；W2 全范围接管前仍需补齐 admin / 普通用户 / `my-*` 作用域专项验证。
- W2 约定范围全部有契约测试、store 测试、API 测试和必要前端 smoke。
- 生产反向代理或入口已经按路径把 W2 owner 切到 Go，且同一路径不再由 Node 同时处理。
- Node 对应 route/service/test 命令已删除，并有 `rg` 删除证据。
- `docs/functions/`、`docs/migration/`、`docs/develop/` 和部署说明已同步。
