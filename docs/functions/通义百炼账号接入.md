# 通义百炼 账号接入

> 2026-10-04 M3 第五批接入（媒体设计 §9、《媒体上游协议契约与Mock上游规格》§10/§10.2）；对话批增补对话承接（qwen 对话模型面，DashScope OpenAI 兼容模式 `/compatible-mode/v1/chat/completions`）：本文记录通义百炼（qwen，阿里云 DashScope qwen 系对话 + 万相 wan 系视频生成 + paraformer 系长转写）供应商的接入结论、协议档案、能力边界、测试与计价口径。通义百炼**承接视频生成**（万相系 DashScope 异步任务）、**长音频转写**（paraformer 系录音文件识别异步任务，M3f 已实施）与**对话**（OpenAI 兼容模式，chat 端点模式 opt-in）；CosyVoice TTS（契约 §10.2）字段未回填，**不承接 TTS**。对话承接的协议档案/词表/出站 URL 归一由对话批交付；目录中的 qwen 对话模型行由模型目录批次承载（目录无 chat 行时模型门仍拦截，双保险语义不变）。

## 范围

本文记录通义百炼供应商的接入结论、账户创建类型、协议档案、网关请求边界、模型目录与计价口径。运行事实以当前 Go 实现（M3 第五批，2026-10-04 交付）为准；报文级契约的权威来源是《媒体上游协议契约与Mock上游规格》§10.1（置信度 B：端点、参数与 usage 字段族已于 2026-10-04 经百炼官方 legacy 万相文生视频/图生视频 API 参考核实），本文不重复报文字段全文。

官方接入面（契约 §10.1）：

- 阿里云百炼平台 `bailian.console.aliyun.com`（DashScope 模型服务，帮助文档 help.aliyun.com 模型 studio 域）。
- 对话：`POST /compatible-mode/v1/chat/completions`（DashScope OpenAI 兼容模式，qwen 系对话模型；OpenAI Chat 报文形态直传）。
- 视频生成：`POST /api/v1/services/aigc/video-generation/video-synthesis` + `GET /api/v1/tasks/{task_id}`（万相 wan2.1～2.6 系异步任务，task_id 有效期 24 小时；wan2.7 新版协议同为 `/api/v1/services/aigc/` 前缀，本批不采用 `/api/v1/videos` 形态）。
- 鉴权：对话面与媒体面同用 DASHSCOPE_API_KEY（`Authorization: Bearer <DASHSCOPE_API_KEY>`）；无 OAuth 接入面。
- **异步任务约定：创建请求必须携带 `X-DashScope-Async: enable` 头**——缺失时上游报 `current user api does not support synchronous calls`（网关创建链经 adapter `ExtraHeaders` 自动注入，客户端无感）。

## 凭据与 base_url

- 账户类型只有 `api_key`（百炼无 OAuth 面向 API 接入，媒体设计 §9）。
- 凭据字段：`api_key`（必填，百炼控制台获取 DASHSCOPE_API_KEY）、`base_url`（可选覆盖）。
- 默认 `base_url` 为 `https://dashscope.aliyuncs.com`（DashScope 官方裸根 origin，seed 档案值）。qwen 是双版本根特例：对话操作路径内嵌 `/compatible-mode/v1` 版本根（`/compatible-mode/v1/chat/completions`），媒体操作路径保持 `/api/v1/...` 全路径——两个版本根都由 registry 操作模板表达，运行时零分支；账户 base_url 填裸根 origin 直拼即得正确 URL。用户使用「仅镜像 openai 风格 `/v1` 路径的 qwen 代理」时，需手动把 base_url 填为该代理的版本根（如 `https://<proxy>/v1`）——该场景仅文档化说明，不做运行时适配。
- 出站 URL（qwen 双版本根特例）：媒体操作路径保持 DashScope 全路径（`/api/v1/services/aigc/video-generation/video-synthesis` 创建、`/api/v1/tasks/{id}` 轮询），对话操作路径内嵌 `/compatible-mode/v1` 版本根（`/compatible-mode/v1/chat/completions`）；两类操作路径都由 registry 操作模板数据表达，账户 base_url 为裸根 origin（官方默认 `https://dashscope.aliyuncs.com`）直拼即成，运行时无 `/api/v1` 或 `/compatible-mode/v1` 的尾缀去重、补插分支（旧 `chainQwenVideoUpstreamURL` / `chainQwenChatUpstreamURL` 服务根归一条款随版本根语义退役；旧错拼实证——openai `/v1` 强制补缀会把官方根错拼 `/v1/api/v1/...`——已随语义收敛消除）。

## 网关请求边界

### 视频（`POST /v1/videos` 统一面，M3 第五批已实施 adapter）

- 创建报文改写（`gatewaymedia/qwen_video.go`）：`model` 直传；`prompt` → `input.prompt`；`negative_prompt` → `input.negative_prompt`（官方原生字段——官方示例章节"使用反向提示词 支持模型：所有模型"，qwen 是 M3 首个 negative_prompt 生效的视频供应商）；`input_reference` → `input.img_url`（图生视频形态，同端点——官方支持公网 URL 与 Base64 data URL 两种形态，**均字符串直传**，网关零资源存储的裁决不涉及）；`size` WxH → `parameters.size` "W\*H" 星号形态（官方分隔符是星号；纯格式转换，档位合法性由上游裁决——wan2.2-t2v-plus 为 480P/1080P 全档，网关不硬编码词表）；`seconds` → `parameters.duration` 数值秒直传（模型级档位由上游裁决，契约 §2.4 规则 3：wan2.2-t2v-plus 固定 5 秒、wan2.5 取 5/10、wan2.6 取 [2,15]）；`seed` 整数直传；`prompt_extend` 等厂商个例经 `provider_options.qwen` deep-merge（嵌套对象递归合并）；`n`/`audio` 请求面无对应字段（`input.audio_url` 是 wan2.6/2.5 的输入素材字段、非生成开关，经 L3 传递）→ `params_ignored` 回显。
- **创建请求头自动注入 `X-DashScope-Async: enable`**（DashScope 异步任务约定，契约 §10.1）：adapter 经 `VideoCreateOutput.ExtraHeaders` 声明，链上 driver 出站构造时注入——这是 adapter 接口为厂商私有创建头扩的最小面（`ExtraHeaders map[string]string`，nil 时既有 provider 零行为差异）；任务面轮询仅需 Authorization，不注入。
- 受理凭据 = 创建响应 `output.task_id`（uuid 形态）。
- 轮询 `GET /api/v1/tasks/{task_id}`：`PENDING` → `queued`、`RUNNING` → `in_progress`、`SUCCEEDED` → `completed`（`output.video_url` 冻结进 `Artifact.ContentURL`）、`FAILED` → `failed`（错误摘要取顶层 `code`/`message`，缺席时以 status 原值兜底）；官方词表另有 `CANCELED`/`UNKNOWN`（轮询面未在契约 §2.6 回填归一）按归一规则归 `in_progress` 记 `RawStatus`（不猜测失败，同 volcengine `expired` 先例）。
- 产物下载：**`output.video_url` 绝对 URL 直连**（官方为 OSS 签名地址、约 24 小时时效，凭据内嵌于 URL——无账户认证，与 Veo uri / glm video_result.url / volcengine content.video_url 同族先例；`ContentFromArtifact=true`）。
- 取消：契约 §10.1 回填面无任务取消端点 → `SupportsCancel=false`，网关不发上游请求直接本地收敛 `cancelled`（沿 glm/minimax/volcengine 裁决；官方词表有 CANCELED 终态词但可调用的取消 API 未回填，回填后再升级）。
- Capabilities：`NegativePrompt=true`、`Audio=false`、`Seconds=true`、`InputReference=true`、`N=false`、`Seed=true`。

### 长转写（`POST /v1/audio/jobs` 统一面，M3f 已实施 adapter）

- 创建报文改写（`gatewaymedia/qwen_asr.go`，契约 §10.2）：`model` 直传；`input_url` → `input.file_urls` **单元素数组**（唯一输入形态——官方只收公网 URL 数组、网关零存储不暂存，**multipart 文件输入本地 400**，待有文件上传型上游再开）；`language` → `parameters.language_hints` 数组（单字符串映射单元素，值域由上游裁决）；`diarization_enabled`/`disfluency_removal_enabled`/`vocabulary_id` 等厂商个例经 `provider_options.qwen` deep-merge。
- **创建无 `X-DashScope-Async` 头**（该服务天然异步，与万相视频 §10.1 的关键差异——adapter `ExtraHeaders` 恒 nil）。
- 受理凭据 = 创建响应 `output.task_id`；轮询 `GET /api/v1/tasks/{task_id}`（与万相**同一 DashScope 任务接口**），状态归一同万相表（§2.6）：`SUCCEEDED` → `completed`（`output.results[].transcription_url` 冻结进 `Artifact.ContentURL`）、`FAILED` → `failed`（错误摘要优先 `output.message`，顶层 code/message 兜底）。
- 产物下载：**`transcription_url` 绝对 URL 直连**（转写结果 **JSON 文件**——内容含 `transcripts[].text`/句级时间戳/说话人，非音频字节；`content` 端点流式代理该 JSON，`ContentFromArtifact=true`）。
- 取消：契约 §10.2 回填面无任务取消端点 → `SupportsCancel=false`，网关不发上游请求直接本地收敛 `cancelled`（沿万相 §10.1 裁决）。
- 对外 job 对象 `object=audio_job`、job id 前缀 `audiojob_`；kind=`audio_transcription`（管理面媒体任务列表可按该 kind 过滤）。
- Capabilities：`SupportsLanguage=true`。

### 对话（`POST /v1/chat/completions` 统一面，对话批已实施 URL 归一）

- 客户端 OpenAI Chat 形态请求（含流式）直连 DashScope OpenAI 兼容模式 `/compatible-mode/v1/chat/completions`：报文零改写透传（模型映射时仅改写 `model` 与路径，responses→chat 桥改写后的路径一并命中），鉴权与媒体面同用 DASHSCOPE_API_KEY Bearer。
- 出站 URL 为版本根直拼：操作路径 `/compatible-mode/v1/chat/completions` 内嵌 DashScope OpenAI 兼容模式版本根，账户 base_url 裸根 origin 直拼即成；无服务根去重或 `/v1` 补缀分支（与媒体 `/api/v1` 全路径同属 registry 操作模板数据）。
- 账户侧承接条件：`supported_endpoint_modes` 显式含 `chat_json`/`chat_sse`（opt-in，不进默认集）+ `supportedModels` 声明对话模型（须落在目录——对话批时点目录 qwen 对话行由模型目录批次承载）。

### 保守面（待回填后扩展）

- **usage 双形态解析**：DashScope 的 `usage` 是 **JSON 字符串**形态（字符串内再嵌一层 JSON，契约 §10.1 钉住；官方文档示例亦展示对象形态）——adapter 双形态兼容解析，按 `video_duration`（wan2.5 及以下字段族）→ `output_video_duration` → `duration`（wan2.6 字段族）顺序取第一个正值填 `OutputVideoSeconds`；解析失败或无正值字段不报错不填秒（该路径才落 `usage_missing` 兜底）。
- **TTS 不承接**：CosyVoice（`/api/v1/services/aigc/text-generation/generation` 族）同为 DashScope 任务模式（§10.2），字段未回填，不实现 adapter；长转写（paraformer）已于 M3f 实施（见上节）。

### 账户 endpoint modes

- 词表（写侧 `normalizeQwenEndpointModesForWrite` + 读侧投影）：`chat_json`/`chat_sse`（对话批起）+ `video_create`/`video_get`/`video_content`/`video_cancel` 与 `audio_job_create`/`audio_job_get`/`audio_job_content`/`audio_job_cancel` 八值（无 `audio_speech`）——全部 opt-in；写侧对 responses/audio_speech 等未收录模式报错。
- 默认集 `video_get`（只读任务查询，零费用档——qwen 无 TTS 廉价探针面，视频/长转写/对话不做自动真实生成探针（按时长计费成本高，媒体设计 §11.9）；同 volcengine 默认集结构，chat 探针同为真实计费请求且档案默认健康检查模型仍为媒体模型）。`chat_json`/`chat_sse`/`video_create`/`audio_job_create` 均需显式开启，`/v1/chat/completions` 链按 chat 对、`/v1/videos`/`/v1/audio/jobs` 创建链分别按 `video_create`/`audio_job_create` 候选过滤。
- 前端（`accountProviderCapabilities.ts`）：qwen 档案的 endpoint modes 按 families 推导（`chat_completions` → chat 对、`video_generation` → video 四值、`audio_transcription` → audio_job 四值）；chat 可勾选但不进新账户默认集（chat 探针真实计费且档案默认健康检查模型为媒体模型，默认集与后端一致——火山为 video_get、百炼为 audio_job_get，媒体模式过滤后 opt-in）。
