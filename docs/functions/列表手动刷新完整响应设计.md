# 列表手动刷新完整响应设计

## 1. 目标

- AI 账户、分组、策略路由和 API Key 列表只在进入页面、翻页、筛选、排序、业务操作完成或用户点击刷新时请求数据。
- 每次列表请求一次性返回当前页渲染所需的完整事实，前端不得在列表成功后补发状态快照、计数快照或预览快照请求。
- 管理侧与“我的”用户侧复用同一契约，仅由访问作用域决定可见数据。

## 2. 范围

本设计覆盖审计确认存在列表补发链路的四个领域：

- AI 账户 / 我的 AI 账户。
- 分组 / 我的分组。
- 策略路由 / 我的策略路由。
- API Key / 我的 API Key。

账户测试任务轮询、测试会话心跳、聊天生成状态、模型检测终端时钟和后台 worker 运行态不属于列表动态刷新，不得按本设计删除。

本轮只调整 Node 后端与 Vue 前端。Go 迁移实现由后续迁移工作根据本轮 Git 事实对齐。

## 3. 接口契约

### 3.1 AI 账户列表

`GET /accounts` 与 `GET /my-accounts` 的每个当前页条目必须同时返回：

- 持久状态、可调度开关、到期、冷却、最近错误和最近健康检查事实。
- `effectiveAvailability` 与 `availabilityPresentation`，供页面展示“可调度”或真实阻断状态以及检查时间、原因和 traceId。
- 当前并发、今日用量、最近使用、API Key 运行摘要和已有余额快照。
- 当前页统一的 `generatedAt`。

当前并发没有占用或运行态读取失败时返回 `0`。页面不展示“未知”或“暂不可用”，也不把 `active` 简化成“正常”；状态标签以综合后的 `effectiveAvailability` 为准。

### 3.2 分组列表

`GET /groups` 与 `GET /my-groups` 的每个当前页条目必须在 `accountStats` 中返回当前并发和今日用量。当前并发无占用或读取失败时返回 `0`，页面始终显示数值。

### 3.3 策略路由列表

`GET /route-strategies` 与 `GET /my-route-strategies` 的每个当前页条目必须返回绑定分组数、API Key 数和绑定分组预览。真实无绑定或无 API Key 时返回 `0`，前端不再维护 pending/error 快照状态。

### 3.4 API Key 列表

`GET /api-keys` 与 `GET /my-api-keys` 的每个当前页条目必须直接返回累计用量摘要。无用量记录时返回完整零值摘要；前端不得在列表成功后调用独立 `/usage` 接口，也不维护用量 pending/error/retry 状态。

## 4. 后端实现边界

- 列表先确定当前页 ID，再按 ID 批量读取补充事实；禁止逐行查询。
- 同一数据源内尽量复用列表已有行，避免为了补字段重复读取账户或分组主记录。
- PostgreSQL、SQLite、Redis 和统计结果读取必须保持批量接口；可并行的批量读取并行执行。
- 列表响应只读取已有余额和统计结果，不触发上游余额刷新，也不扫描原始使用记录。
- 独立 `status-snapshot` / `list-snapshot` / API Key `usage` HTTP 路由及前端 API 在没有其他消费者后删除；内部批量装配函数可以保留，但名称和职责应体现列表水合而不是前端轮询。

## 5. 前端实现边界

- 页面只调用列表接口，列表返回后原子替换当前页。
- 点击刷新、翻页、筛选、排序、页面重新激活和业务写操作完成后可以重新调用列表接口。
- 不使用 `setInterval`、递归 `setTimeout`、watch 后补发快照或 fire-and-forget 列表水合请求。
- 不保留快照 pending/error map、请求代次、旧快照合并器或“加载中 / 暂不可用 / 未知”列表占位。

## 6. 性能与失败语义

- AI 账户、分组和策略路由默认页大小为 20，API Key 默认页大小为 50；所有补充读取必须按当前页有界执行。
- 账户和分组并发使用批量运行态读取；读取失败按 `0` 处理，列表仍返回持久状态事实。
- 统计、余额和计数只读预聚合或已有快照，不允许回扫大事实表。
- 列表需要记录完整接口耗时；验收同时检查 P95/P99，不能通过删除字段或返回假空数组提速。

## 7. 验收

- 四类列表的前端网络链路每次操作只有一个领域列表请求，不再出现列表后的状态、计数、预览或用量补发请求。
- AI 账户并发始终为 `当前值/上限`，无占用为 `0/上限`；状态正常可调用时显示“可调度”。
- 分组并发和今日用量始终为数值，真实零值显示 `0`。
- 策略路由绑定数、API Key 数和预览随列表响应返回。
- API Key 累计用量随列表响应返回，真实零值显示 `0`。
- 管理侧和用户侧权限边界、分页、筛选、排序及业务操作保持不变。
