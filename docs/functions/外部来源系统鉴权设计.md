# 外部来源系统鉴权设计

> 面向 `juhe-ai` 后端、允许来源系统后端和后续 AI 维护者。
> 当前 `/__aipublic__` 只提供受控资源维护接口：API Key、路由策略、分组、AI 账户的列表、新增、修改和删除。已移除来源鉴权 demo、IP 用量公开聚合、账号用量公开聚合、消耗排行和公益接入信息接口。

## 当前状态

- 已实现：外部来源系统表、来源 token 表、管理 API、系统运维 / 公开接口授权页面、来源鉴权中间件。
- 已实现：来源授权新增、编辑、删除、启停、到期时间、生产 token 生成、完整 token 单条复制、token 到期时间和来源授权级公开接口限频。
- 已实现：公开接口接入文档弹窗、接口名称搜索、接口 curl 复制和授权列表内置测试 Token；接入文档不返回明文测试 Token，测试 Token 只返回 mock 数据。
- 已实现：管理端来源列表、scope 目录和接入文档目录已具备 Go opt-in 只读实现；生产 owner 尚未切换，来源详情、Token 和全部写接口仍由 Node 负责。
- 已实现：API Key、路由策略、分组、AI 账户四类资源的公开 CRUD 接口。
- 已移除：`GET /__aipublic__/demo/source-auth`、`GET /__aipublic__/ip/usage`、`GET /__aipublic__/account/usage`、`GET /__aipublic__/consumption/ranking`、`GET /__aipublic__/access/info`。

## 目标

- 给受信任外部来源系统提供统一 Bearer token 鉴权。
- 让外部来源系统按最小 scope 调用受控资源维护接口。
- 把鉴权、限频、公开日志和具体业务资源接口解耦。

## 边界

`juhe-ai` 负责：

- 校验 `Authorization: Bearer <source_token>` 是否命中 active token。
- 校验来源系统、token 状态、过期时间、接口 scope 和来源授权限频。
- 返回统一 401 / 403 / 429 错误语义。
- 执行 API Key、路由策略、分组、AI 账户的受控 CRUD。

`juhe-ai` 不负责：

- 公益站公网入口展示、访问说明或接入信息。
- 公益站用户权限、用户与 IP 映射、排行榜快照。
- IP 维度或账号维度消耗聚合公开读取。
- 浏览器直接持有来源 token。

## 请求约定

公开接口只接受 Bearer 来源 token：

```http
Authorization: Bearer <source_token>
```

来源系统由 token 唯一定位。后台管理只维护来源名称；其他来源标识 header 不参与当前鉴权契约。

## 公开资源接口

```http
GET  /__aipublic__/api-key/list
POST /__aipublic__/api-key/add
POST /__aipublic__/api-key/update
POST /__aipublic__/api-key/del

GET  /__aipublic__/route-strategy/list
POST /__aipublic__/route-strategy/add
POST /__aipublic__/route-strategy/update
POST /__aipublic__/route-strategy/del

GET  /__aipublic__/group/list
POST /__aipublic__/group/add
POST /__aipublic__/group/update
POST /__aipublic__/group/del

GET  /__aipublic__/account/list
POST /__aipublic__/account/add
POST /__aipublic__/account/update
POST /__aipublic__/account/del
```

列表接口使用 query 参数；写接口使用 JSON body。所有接口都返回项目管理 API 风格的 `{ "data": ... }` 或统一错误结构。

## Scope

```text
juhe_ai_public:api_key_list:read
juhe_ai_public:api_key_add:write
juhe_ai_public:api_key_update:write
juhe_ai_public:api_key_delete:write

juhe_ai_public:route_strategy_list:read
juhe_ai_public:route_strategy_add:write
juhe_ai_public:route_strategy_update:write
juhe_ai_public:route_strategy_delete:write

juhe_ai_public:group_list:read
juhe_ai_public:group_add:write
juhe_ai_public:group_update:write
juhe_ai_public:group_delete:write

juhe_ai_public:account_list:read
juhe_ai_public:account_add:write
juhe_ai_public:account_update:write
juhe_ai_public:account_delete:write
```

scope 需要来源系统和 token 同时拥有。每个列表 / 新增 / 修改 / 删除接口都是独立资源 scope，不能用某个读权限代替写权限。

## 资源维护语义

- `targetUsername` 是业务目标用户参数，不再作为来源授权白名单。列表和新增接口需要它定位目标用户；修改和删除接口可选传入用于归属校验。
- 分组新增按 `targetUsername` 定位或自动创建目标用户。
- 路由策略新增按 `targetUsername` 定位已有目标用户，并绑定该用户可用分组。普通路由只能绑定一个分组；其他路由模式按策略路由配置维护分组绑定、权重、故障回退、轮询和混合智能路由规则。
- API Key 新增要求目标用户和路由策略已存在；新增响应只在本次返回明文 `key`，列表和修改不回显明文。
- AI 账户新增当前只支持 `type=api_key`，可自动创建目标用户和目标分组；新增 / 修改不返回上游凭据。
- 删除接口按本系统资源 ID 定位；找不到时按各资源既有幂等或 404 语义返回。
- 目标系统用户已停用时，公开资源的新增、列表、修改、删除都会拒绝。

## 存储设计

业务库两张低增长表：

```text
external_integration_sources
- id TEXT PRIMARY KEY
- name TEXT NOT NULL
- status TEXT NOT NULL DEFAULT 'active'
- scopes_json TEXT NOT NULL DEFAULT '[]'
- rate_limits_json TEXT NOT NULL DEFAULT '[]'
- expires_at TEXT
- notes TEXT
- last_used_at TEXT
- created_at TEXT NOT NULL
- updated_at TEXT NOT NULL

external_integration_source_tokens
- id TEXT PRIMARY KEY
- source_ref_id TEXT NOT NULL
- name TEXT NOT NULL
- token_hash TEXT UNIQUE NOT NULL
- token_secret_encrypted TEXT NOT NULL
- token_prefix TEXT NOT NULL
- token_suffix TEXT NOT NULL
- status TEXT NOT NULL DEFAULT 'active'
- scopes_json TEXT NOT NULL DEFAULT '[]'
- expires_at TEXT
- last_used_at TEXT
- created_at TEXT NOT NULL
- updated_at TEXT NOT NULL
- revoked_at TEXT
```

设计要点：

- token 明文只在创建响应返回；后台列表只展示安全标识，复制完整 token 必须按管理员权限读取单条 token。
- `token_hash` 使用带用途前缀的 SHA-256 摘要，`token_secret_encrypted` 加密保存完整 token。
- `token_hash` 全局唯一并走索引点查，不扫描表。
- `rate_limits_json` 保存来源授权级公开接口限频规则，空数组表示不限制。
- `last_used_at` 低频更新，避免高频公开接口每次都写业务库。
- 删除来源授权会同时删除该来源下 token 摘要，原 Bearer token 立即失效。

## 鉴权流程

1. 读取 `Authorization: Bearer <source_token>`。
2. 对 token 做摘要，按 `token_hash` 点查。
3. 通过 token 的 `source_ref_id` 关联来源系统。
4. 校验来源系统为 `active` 且未过期。
5. 校验 token 为 `active` 且未过期。
6. 校验来源授权和 token 都包含当前接口所需 scope。
7. 执行来源授权级限频；默认没有限频规则时直接通过。
8. 把来源上下文写入本次请求上下文，进入具体业务接口。

无论鉴权成功、鉴权失败、限频、参数错误还是公开前缀 404，本次 `/__aipublic__` 请求都会在响应结束后写入公开接口日志。请求 header 快照只捕获 `contentType` / `contentLength`，不捕获 `Authorization`、Cookie 或作为 Bearer 凭据传入的来源 token；query / body / response 快照在容量与结构预算内保留原值，不按字段名或字符串形态递归脱敏。

## 错误语义

| 场景 | HTTP | code | 说明 |
| --- | --- | --- | --- |
| 缺少 Bearer token | 401 | `external_source_token_missing` | 未携带来源授权 token。 |
| 来源系统或 token 不匹配 | 401 | `external_source_unauthorized` | 不暴露具体是来源不存在还是 token 错误。 |
| 来源系统停用 | 403 | `external_source_disabled` | token 有效但来源系统已停用。 |
| 来源系统过期 | 403 | `external_source_expired` | 来源系统已到期。 |
| token 不可用或过期 | 401 | `external_source_token_unavailable` | token 被撤销、停用或过期。 |
| scope 不足 | 403 | `external_source_scope_forbidden` | 来源系统没有调用目标接口的权限。 |
| 目标用户已停用 | 400 | - | 目标系统用户当前不可作为有效资源控制边界。 |
| 超过来源限频 | 429 | `external_source_rate_limited` | 当前来源系统超过配置的公开接口限频。 |

外部来源 token 不能访问后台登录态接口。携带来源 token 调用 `/__aisys__/api/accounts` 仍按未登录处理。

## 管理入口

系统管理员可在“系统运维 / 公开接口授权”里维护来源系统：

- 加载来源列表：`GET /__aisys__/api/external-integration-sources` 只允许 `admin` / `super_admin`，使用只读 session、两层 read limiter 和 `Cache-Control: no-store`。`page/pageSize/keyword/status` 保持 Node Express + Zod 契约，按 `updatedAt DESC, id DESC` 做最多 1000 行窗口的渐进分页；先分页来源，再只为当前页批量读取 Token 数量和主 Token。主 Token 优先 active，再按最新创建时间和 ID 选择；响应只包含 `tokenPrefix/tokenSuffix` 等安全摘要，不读取或返回 `token_hash`、`token_secret_encrypted` 或完整 Token。
- 加载接口资源授权目录：`GET /__aisys__/api/external-integration-sources/scopes` 只允许 `admin` / `super_admin`，返回当前 16 个公开 CRUD scope 的稳定 `{ value, label }` 列表；该请求使用只读 session，不刷新会话。
- 加载接入文档目录：`GET /__aisys__/api/external-integration-sources/api-docs` 只允许 `admin` / `super_admin`，返回 `basePath`、`authType` 和当前 16 个公开 CRUD 接口的完整请求 / 响应字段目录；该请求同样使用只读 session，不刷新会话。
- 查看接入文档：弹窗消费上述目录，支持搜索和复制 curl。
- 使用内置测试 Token：内置测试 Token 只进入 mock 数据分支，固定限频 `60s/10次`，可停用或重置，不支持编辑、删除或新增子 Token。
- 新增来源授权：填写名称、接口资源授权、到期时间和限频规则；保存后直接生成一个生产 token。
- 启用 / 停用来源系统：停用后该来源所有公开接口调用都会被拒绝。
- 删除来源授权：删除来源及其关联 token 摘要，原生产 token 立即失效。
- 生成、复制、启用、停用或撤销 token。

公开接口限频只作用于 `/__aipublic__` 前缀，不影响后台管理 API、网关 API 或健康检查。

接入文档的编写事实源仍是 Node 的 `external-public-api-catalog*` 结构化目录。Go 构建不依赖 Node 运行时，而是嵌入由该目录生成并提交的 JSON 快照；修改 Node 目录后必须重新生成并执行漂移回归，避免两端文档契约分叉。

Go 当前只在 `JUHE_AI_MANAGEMENT_API_ENABLED=true` 且依赖完整时挂载上述三个规范 GET。`POST /external-integration-sources`、来源详情、内置 Token 重置、Token 创建 / 查看明文 / 更新和来源更新 / 删除均未迁移；Go 对这些 Node owner 路径保持 404，不允许双写或据此删除 Node route。

## 维护脚本

生成来源系统和 token：

```powershell
pnpm --filter juhe-ai-backend external-source:demo-token
```

可选参数：

```powershell
pnpm --filter juhe-ai-backend external-source:demo-token -- --name "外部资源维护系统" --token-name "资源维护联调 token"
pnpm --filter juhe-ai-backend external-source:demo-token -- --scopes "juhe_ai_public:group_list:read,juhe_ai_public:route_strategy_list:read"
```

脚本输出 PowerShell 调用示例。生产 token 输出后应保存到调用方后端配置，不要写进前端包、浏览器请求或公开文档。

更新或检查 Go 嵌入的公开接口文档快照：

```powershell
pnpm --filter juhe-ai-backend generate:external-public-api-catalog
pnpm --filter juhe-ai-backend check:external-public-api-catalog
pnpm --filter juhe-ai-backend test:external-public-api-catalog-snapshot
```

## 后续接入

后续如果新增其他外部接口，仍复用同一鉴权中间件并新增独立 scope。新增能力默认只应围绕 API Key、路由策略、分组和 AI 账户控制面维护；统计聚合、公益展示、IP 归属和排行榜不重新放入公开接口。
