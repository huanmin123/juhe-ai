## 归属规则

- `docs/architecture/架构总览.md` 只保留产品目标、技术选型、模块边界和跨模块关系。
- 具体页面字段、接口清单、默认参数、运行策略、功能流程和存储细节统一写入本目录。
- 第一阶段 OpenAI 相关账号接入要求优先看 [OpenAI 一期计划](第一期OpenAI账号接入.md)，通用功能细节优先看 [核心功能设计](核心功能设计.md)。
- 新增或调整管理 API、网关接口、响应结构、错误语义、分页筛选或权限摘要时，优先更新 [接口契约与权限矩阵](接口契约与权限矩阵.md)。
- 新增或调整系统团队、授权对象、授权资源、授权统计或团队成员共享语义时，优先更新 [系统团队与统一授权设计](系统团队与统一授权设计.md)。
- 新增或调整敏感字段、请求快照、日志、凭据展示、数据保留或备份迁移规则时，优先更新 [安全与日志策略](安全与日志策略.md)。
- 新增或调整流式中断、客户端重试、下游错误事件或跨厂商客户端兼容策略时，优先更新 [流式中断与客户端重试调研](流式中断与客户端重试调研.md)。
