# 火山方舟 账号接入

> 2026-10-04 M3 第四批接入（媒体设计 §9、《媒体上游协议契约与Mock上游规格》§9）；同日 M6 批增补豆包 TTS（契约 §9.2 回填 B 级后实施）：本文记录火山方舟（volcengine，豆包 Seedance 视频生成 + 豆包 TTS 语音合成）供应商的接入结论、协议档案、能力边界、测试与计价口径。火山方舟是媒体专用供应商——承接**视频生成**（Seedance 系异步任务）与**语音合成**（openspeech `/api/v3/tts` 同步 TTS，语音应用双值凭据）；异步长转写（契约 §9.2）未回填不承接；**不承接聊天流量**（火山方舟聊天走独立 doubao 模型面，档案与目录均不声明对应能力）。

## 范围

本文记录火山方舟供应商的接入结论、账户创建类型、协议档案、网关请求边界、模型目录与计价口径。运行事实以当前 Go 实现（M3 第四批 + M6 TTS 批，2026-10-04 交付）为准；报文级契约的权威来源是《媒体上游协议契约与Mock上游规格》§9.1（视频，置信度 B：官方文档入口 + 多源确认；创建参数名 `resolution`/`ratio`/`duration`/`seed` 与 `content` 数组的 url/base64 双形态已于 2026-10-04 经官方 API 参考页核实）与 §9.2（TTS，置信度 B：多源交叉，2026-10-04 回填并实施），本文不重复报文字段全文。

官方接入面（契约 §9.1/§9.2）：

- 火山方舟平台 `www.volcengine.com`（Ark 大模型服务平台，文档 docs 82379 域）。
- 视频生成：`POST /api/v3/contents/generations/tasks` + `GET /api/v3/contents/generations/tasks/{id}`（豆包 Seedance 系，异步任务，任务记录保留 7 天）。
- 语音合成：`POST https://openspeech.bytedance.com/api/v3/tts`（豆包 TTS，**语音服务域**，与 ark 域无关）。
- 鉴权：视频面 API Key（`Authorization: Bearer <ARK_API_KEY>`）；语音面**分号特例** `Authorization: Bearer;<token>`（凭据为语音应用双值 appid+token，与 ark API Key 相互独立）；无 OAuth 接入面。

## 凭据与 base_url

- 账户类型只有 `api_key`（火山方舟无 OAuth 面向 API 接入，媒体设计 §9）。
- 凭据字段：`api_key`（必填）、`base_url`（可选覆盖）、`speech_appid`/`speech_token`（M6 起可选，**仅 volcengine 供应商放行**——语音应用双值，在火山控制台「语音技术」创建语音应用获取 appid 与 access token；两者配对提供，缺失任一即该账户无 `audio_speech` 能力，语音请求派发时显式失败，不静默回退）。
- 前端账户表单暂无这两个字段的编辑入口（无 volcengine 专表单）：经管理面 API 的 `credentials` 对象写入（创建或 credentialsPatch）；表单编辑保存不会删除既有键（凭据 diff 只携带表单可编辑键，见 `accountCredentials.ts`/`accountEditPatch.ts`）。
- 默认 `base_url` 为 `https://ark.cn-beijing.volces.com`（官方根，seed 档案值；**语音出站不经 base_url**——host 恒 `openspeech.bytedance.com` 语音服务域，是 URL 构造特例 `chainVolcengineSpeechUpstreamURL`；`JUHE_AI_GATEWAY_VOLCENGINE_SPEECH_BASE_URL` 仅为验收 E2E 的测试 seam，生产不设置）。
- 出站 URL 归一：volcengine 视频出站路径（`/api/v3/contents/generations/tasks` 族）自带 `/api/v3` 服务根，走专用归一 `chainVolcengineVideoUpstreamURL`（base 已含 `/api/v3` 时去重直拼）——**不走** `gatewayopenai.BuildUpstreamURL`（它对非 `/v1` 结尾的 base 强制补 `/v1`，会把官方根错拼 `/v1/api/v3/...`；同 glm `/api/paas/v4` 服务根的 `chainGlmVideoUpstreamURL` 先例）。账户 base_url 带或不带 `/api/v3` 尾缀均归一到同一 URL。

## 供应商与协议档案

```ts
type ProviderCode = 'volcengine'
```

显示名称 `火山方舟`。`volcengine` 是独立供应商（seed `pgSeedProviders`，M3 增），不复用 `openai` 聚合供应商；账号池、分组、模型价格与响应策略归属 `volcengine`。

唯一协议档案：

| 档案 | 供应商 | 协议 | 默认 Base URL | 账户创建类型 | Capabilities | Endpoint Families | 默认健康检查模型 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `profile_volcengine_openai_v1` | `volcengine` | `openai/v1` | `https://ark.cn-beijing.volces.com` | `api_key` | `video_generation` + `tts`（仅媒体） | `video_generation` + `tts` | `doubao-seedance-1-0-pro-250528` |

要点：

- **Capabilities 只声明媒体**（`video_generation` + M6 起补 `tts`，与 Endpoint Families 同名）：不声明 `chat`/`responses`/`passthrough`——火山方舟聊天走独立 doubao 模型面，档案不得让聊天流量路由进来；模型门双保险（目录无 chat 模型行）。
- 协议 `openai/v1` 是媒体 adapter 的报文承载协议（出站路径经专用 `/api/v3` 归一、语音经固定语音服务域），不是聊天透传声明。
- 内置分组：`grp_default_volcengine_sys_admin`（默认火山方舟分组，seed `pgSeedGroups`）。
- 复用 minimax 批新增的 openai 协议端点族 `openai_v1_video_generation`（code `video_generation`）与 `openai_v1_tts`（code `tts`，M6 起该档案挂载）——统一 `/v1/videos`、`/v1/audio/speech` 面承载的厂商原生媒体形态，**不新增 endpoint family 行**。

## 网关请求边界

### 视频（`POST /v1/videos` 统一面，M3 已实施 adapter）

- 创建报文改写（`gatewaymedia/volcengine_video.go`）：`model` 直传；`prompt` → `content[0] = {"type":"text"}`；`input_reference` → `content` 追加 `{"type":"image_url","image_url":{"url":...}}`——官方 url 支持公网 URL 与 Base64 data URL 两种形态，**均字符串直传**（与 minimax 仅 base64 不同：官方由上游自行拉取 URL，网关零资源存储的裁决不涉及）；`size` WxH → `resolution` + `ratio` 档位换算（`ratio` 约分后须精确命中官方词表 16:9/9:16/1:1/4:3/3:4/21:9，词表外本地 400 不近似贴合——契约 §2.4 规则 2；`resolution` 按短边取最近档：≥900 → 1080p、≥600 → 720p、其余 480p，档位与模型/ratio 的合法组合由上游裁决）；`seconds` → `duration` 数值秒直传（官方默认 5，档位合法性由上游裁决，契约 §2.4 规则 3）；`seed` 整数直传；`camera_fixed` 等厂商个例经 `provider_options.volcengine` deep-merge；`negative_prompt`/`audio`/`n` 请求面无对应字段（`generate_audio` 仅 seedance 2.0/1.5 pro 支持，M3 目录仅 1.0 pro 不声明）→ `params_ignored` 回显。
- 受理凭据 = 创建响应 `id`（`cgt-` 前缀任务号）。
- 轮询 `GET /api/v3/contents/generations/tasks/{id}`：`queued` → `queued`、`running` → `in_progress`、`succeeded` → `completed`（`content.video_url` 冻结进 `Artifact.ContentURL`）、`failed` → `failed`（错误摘要取 `error{code,message}`，缺席时以 status 原值兜底）；未知状态（官方回调面另有 `expired` 等词，轮询面未回填）归 `in_progress` 记 `RawStatus`（契约 §2.6 归一规则：不猜测失败）。
- 产物下载：**`content.video_url` 绝对 URL 直连**（无凭据，与 Veo uri / glm video_result.url / minimax file_download_url 同族先例；`ContentFromArtifact=true`）。
- 取消：契约 §9.1 回填面无任务取消端点 → `SupportsCancel=false`，网关不发上游请求直接本地收敛 `cancelled`（沿 glm/minimax 裁决；官方回调文档提及任务存在 `cancelled` 终态、仅排队中任务可取消，取消端点回填后再升级）。
- Capabilities：`NegativePrompt=false`、`Audio=false`、`Seconds=true`、`InputReference=true`、`N=false`、`Seed=true`。

### 语音合成（`POST /v1/audio/speech` 统一面，M6 已实施 adapter）

- 出站报文改写（`gatewaymedia/volcengine_tts.go`，注册 `speechAdapters` 的 `volcengine` 条目）：`input` → `req_params.text`、`voice` → `req_params.speaker`（音色按 speaker 配置，如 `BV700_streaming`）、`response_format` → `req_params.audio_params.format`（词表 `mp3`/`pcm`/`ogg_opus`/`wav`，缺省 mp3；词表外本地 400 零转码）、`speed` → `audio_params.speed_ratio`（厂商区间 **[0.2, 3.0]**，公共区间越界本地 400，契约 §2.4 规则 2）；`reqid` 网关生成（uuid v4）；`operation` 固定 `query`；`user.uid` = 账户 `speech_appid`（网关固定注入的调用方标识，非请求面参数）；厂商个例（emotion 等）经 `provider_options.volcengine` deep-merge。
- **`model` 占位语义（不编造取舍）**：V3 TTS 请求面**无 model 字段**——音色经 speaker、模型由语音应用的资源决定；统一面的 `model` 是必填占位（非空即过 IR 门），值**不透传上游**。官方无可查证模型 ID（`BV700_streaming` 等是 speaker 名），目录**不落官方 TTS 行**；账户需在模型目录注册一个自定义占位行（mode=audio、协议 `audio_speech`，零价或按需配价）并加入账户 `supportedModels`，网关模型门按该占位名派发。
- 鉴权特例：`Authorization: Bearer;<speech_token>`（**分号**分隔，火山语音服务域独有——凭据是语音应用 access token，不是 ark API Key，不能复用 openai 族 Bearer 空格形态）。
- URL 构造特例：出站 host 恒 `https://openspeech.bytedance.com`（语音服务域，与账户 base_url 无关）；路径 `/api/v3/tts`。
- 响应转换：`code == 3000` 成功、`data` 为 base64 音频（adapter 解码为二进制透传下游，content-type 按请求 format 推导）；`code != 3000` 整单失败上抛（同步面无任务受理语义，不猜测音频可用性）。
- 计量：上游无字符回报 → 网关按请求 `input` 字符自算 `TtsInputChars`（契约 §2.8）；目录占位行无字符价 → 成本 0 不虚计（官方字符价可查证后落价）。

### 保守面（待回填后扩展）

- **usage/时长不抽取**：官方创建文档明示查询 API 返回 `duration`（"视频时长与计费相关"）与 `usage` 字段，但字段全貌未回填契约（§9.1"字段名接入回填"）——M3 保守不填 `OutputVideoSeconds`，终态计费走契约 §2.8 兜底（0 计费 + `usage_missing` 标记）；字段回填后再启用秒计量与秒价。
- **异步长转写不承接**：豆包长转写（§9.2）文档页 JS 渲染不可抓取，未回填不实现 adapter。

### 账户 endpoint modes

- 词表（写侧 `normalizeVolcengineEndpointModesForWrite` + 读侧投影）：`video_create`/`video_get`/`video_content`/`video_cancel` 四值 + M6 起 `audio_speech`——全部 opt-in；写侧对 chat/responses 等模式报错。`audio_speech` 开启但凭据缺 `speech_appid`/`speech_token` 时，语音请求派发显式失败（能力缺失不静默回退）。
- 默认集 `video_get`（只读任务查询，零费用档——视频/语音均按量计费，不做自动真实生成探针（媒体设计 §11.9）；与 minimax 默认集含 `audio_speech` 的差异在于 minimax TTS 承担健康检查探针面而火山语音是独立计费服务面）。`video_create`/`audio_speech` 仍需显式开启，`/v1/videos` 创建链按 `video_create`、`/v1/audio/speech` 按 `audio_speech` 候选过滤。
- 前端（`accountProviderCapabilities.ts`）：volcengine 档案的 endpoint modes 按 families 推导（`video_generation` → video 四值；`tts` → `audio_speech`），不回退 chat 词表；新账户默认集过滤后为空。

## 计价口径（不编造）

- **doubao-seedance-1-0-pro-250528**：官方计费口径为人民币（发布会/新闻口径按 token：0.015 元/千 tokens；产品页口径按秒 × 分辨率档：1080P 约 0.73 元/秒的新闻转述），火山官网定价页无可查证官方精确 **USD** 秒价（检索所得均为人民币或第三方转述口径，不作数）；且轮询响应 `usage`/`duration` 字段未回填契约——网关计价引擎仅 USD 且无官方汇率折算链 → **不落 `VideoOutputCostPerSecond`**，终态计费走契约 §2.8 兜底（0 计费 + `usage_missing` 标记），同 glm cogvideox / minimax hailuo 先例。官方 USD 秒价或 usage/duration 回填口径可查证后再补。
- **豆包 TTS**：官方按字符计费、无可查证 USD 字符价 → 目录与静态层均不落字符价；网关按请求字符自算计量照落（`TtsInputChars`），成本 0 不虚计；官方字符价可查证后再补。
