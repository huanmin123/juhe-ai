## 范围

本文记录火山方舟供应商的接入结论、账户创建类型、协议档案、网关请求边界、模型目录与计价口径。运行事实以当前 Go 实现（M3 第四批 + M6 TTS 批 + 2026-10-17 TTS 迁移批）为准；报文级契约的权威来源是《媒体上游协议契约与Mock上游规格》§9.1（视频，置信度 B：官方文档入口 + 多源确认；创建参数名 `resolution`/`ratio`/`duration`/`seed` 与 `content` 数组的 url/base64 双形态已于 2026-10-04 经官方 API 参考页核实）与 §9.2（TTS，置信度 A：官方文档 + 2026-10-17 真实上游实测迁移回填），本文不重复报文字段全文。

官方接入面（契约 §9.1/§9.2）：

- 火山方舟平台 `www.volcengine.com`（Ark 大模型服务平台，文档 docs 82379 域）。
- 对话：`POST /api/v3/chat/completions`（Ark OpenAI 兼容端点，豆包 doubao 系对话模型；OpenAI Chat 报文形态直传）。
- 视频生成：`POST /api/v3/contents/generations/tasks` + `GET /api/v3/contents/generations/tasks/{id}`（豆包 Seedance 系，异步任务，任务记录保留 7 天）。
- 语音合成：`POST https://openspeech.bytedance.com/api/v3/tts/create`（豆包音频生成，**语音服务域**，与 ark 域无关；旧端点 `/api/v3/tts` 已 404 下线）。
- 鉴权：对话面与视频面同用 ark API Key（`Authorization: Bearer <ARK_API_KEY>`）；语音面 `X-Api-Key: <api-key>` 单头单值（新版语音控制台 API Key，与 ark API Key 相互独立；旧版语音应用 appid+token 双值与 `Authorization: Bearer;<token>` 分号形态随旧端点废弃）；无 OAuth 接入面。

## 凭据与 base_url

- 账户类型只有 `api_key`（火山方舟无 OAuth 面向 API 接入，媒体设计 §9）。
- 凭据字段：`api_key`（必填）、`base_url`（可选覆盖）、`speech_token`（M6 起可选，**仅 volcengine 供应商放行**——新版语音控制台 API Key 单值，2026-10-17 TTS 迁移批起语义为 `X-Api-Key` 出站凭据；缺失即该账户无 `audio_speech` 能力，语音请求派发时显式失败，不静默回退）。`speech_appid` 退役为可选遗留键（仅向后兼容保留，不再参与出站报文与鉴权）。
- 前端账户表单暂无这两个字段的编辑入口（无 volcengine 专表单）：经管理面 API 的 `credentials` 对象写入（创建或 credentialsPatch）；表单编辑保存不会删除既有键（凭据 diff 只携带表单可编辑键，见 `accountCredentials.ts`/`accountEditPatch.ts`）。
- 默认 `base_url` 为 `https://ark.cn-beijing.volces.com`（官方根，seed 档案值；**语音出站不经 base_url**——host 恒 `openspeech.bytedance.com` 语音服务域，是 URL 构造特例 `chainVolcengineSpeechUpstreamURL`；`JUHE_AI_GATEWAY_VOLCENGINE_SPEECH_BASE_URL` 仅为验收 E2E 的测试 seam，生产不设置）。
- 出站 URL 归一：volcengine 视频出站路径（`/api/v3/contents/generations/tasks` 族）自带 `/api/v3` 服务根，走专用归一 `chainVolcengineVideoUpstreamURL`（base 已含 `/api/v3` 时去重直拼；2026-10-17 迁移批起三形态放宽——官方根直拼插服务根、`/api/v3` 尾缀去重、`/api/plan/v3` 等**显式完整服务根**视为已带服务根直拼，不再二次拼接）——**不走** `gatewayopenai.BuildUpstreamURL`（它对非 `/v1` 结尾的 base 强制补 `/v1`，会把官方根错拼 `/v1/api/v3/...`；同 glm `/api/paas/v4` 服务根的 `chainGlmVideoUpstreamURL` 先例）。账户 base_url 带或不带 `/api/v3` 尾缀均归一到同一 URL。对话出站同构：chat 路径经 `chainVolcengineChatUpstreamURL` 按 `/api/v3` 服务根归一（显式路径模式同上三形态）；**图像出站同构**（2026-10-17 图像批）：images 路径经 `chainVolcengineImagesUpstreamURL` 归一到 `/api/v3/images/generations`（Agent Plan 账户 base_url 配 `/api/plan/v3` 时归一到 `/api/plan/v3/images/generations`，两形态均经真实上游实测）；**向量出站同构**（2026-10-17 方舟全能力实测批）：embeddings 路径经同一 `chainVolcengineChatUpstreamURL` 归一到 `/api/v3/embeddings`（修复前走 openai `/v1` 归一错拼 `/v1/embeddings` 上游 404 实证，钉值测试 `TestChainVolcengineEmbeddingsUpstreamURL`）；`chat`/`images`/`embeddings` 之外的路径维持 openai `/v1` 归一不变。

## 供应商与协议档案

```ts
type ProviderCode = 'volcengine'
```

显示名称 `火山方舟`。`volcengine` 是独立供应商（seed `pgSeedProviders`，M3 增），不复用 `openai` 聚合供应商；账号池、分组、模型价格与响应策略归属 `volcengine`。

唯一协议档案：

| 档案 | 供应商 | 协议 | 默认 Base URL | 账户创建类型 | Capabilities | Endpoint Families | 默认健康检查模型 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `profile_volcengine_openai_v1` | `volcengine` | `openai/v1` | `https://ark.cn-beijing.volces.com` | `api_key` | `chat` + `video_generation` + `tts` | `chat_completions` + `video_generation` + `tts` | `doubao-seedance-1-0-pro-250528` |

要点：

- **Capabilities 声明对话与媒体**（`chat` + `video_generation` + `tts`，与 Endpoint Families 同码；对话批补 `chat`/`chat_completions`——复用既有 `openai_v1_chat_completions` 族行，不新增 family 行）：不声明 `responses`/`passthrough`——方舟无原生 Responses 面，Responses 形态请求只能经 responses→chat 桥接（模型映射）进入；对话行进目录前模型门仍拦截（双保险语义保留）。
- 协议 `openai/v1` 是对话透传与媒体 adapter 的报文承载协议：对话面 OpenAI Chat 报文直传（出站路径经专用 `/api/v3` 服务根归一），语音经固定语音服务域。
- 内置分组：`grp_default_volcengine_sys_admin`（默认火山方舟分组，seed `pgSeedGroups`）。
- 复用既有端点族：`openai_v1_video_generation`（code `video_generation`）、`openai_v1_tts`（code `tts`，M6 起挂载）与 `openai_v1_chat_completions`（code `chat_completions`，对话批起挂载）——**不新增 endpoint family 行**。

## 网关请求边界

### 视频（`POST /v1/videos` 统一面，M3 已实施 adapter）

- 创建报文改写（`gatewaymedia/volcengine_video.go`）：`model` 直传；`prompt` → `content[0] = {"type":"text"}`；`input_reference` → `content` 追加 `{"type":"image_url","image_url":{"url":...}}`——官方 url 支持公网 URL 与 Base64 data URL 两种形态，**均字符串直传**（与 minimax 仅 base64 不同：官方由上游自行拉取 URL，网关零资源存储的裁决不涉及）；`size` WxH → `resolution` + `ratio` 档位换算（`ratio` 约分后须精确命中官方词表 16:9/9:16/1:1/4:3/3:4/21:9，词表外本地 400 不近似贴合——契约 §2.4 规则 2；`resolution` 按短边取最近档：≥900 → 1080p、≥600 → 720p、其余 480p，档位与模型/ratio 的合法组合由上游裁决）；`seconds` → `duration` 数值秒直传（官方默认 5，档位合法性由上游裁决，契约 §2.4 规则 3）；`seed` 整数直传；`camera_fixed` 等厂商个例经 `provider_options.volcengine` deep-merge；`negative_prompt`/`audio`/`n` 请求面无对应字段（`generate_audio` 仅 seedance 2.0/1.5 pro 支持，M3 目录仅 1.0 pro 不声明）→ `params_ignored` 回显。
- 受理凭据 = 创建响应 `id`（`cgt-` 前缀任务号）。
- 轮询 `GET /api/v3/contents/generations/tasks/{id}`：`queued` → `queued`、`running` → `in_progress`、`succeeded` → `completed`（`content.video_url` 冻结进 `Artifact.ContentURL`）、`failed` → `failed`（错误摘要取 `error{code,message}`，缺席时以 status 原值兜底）；未知状态（官方回调面另有 `expired` 等词，轮询面未回填）归 `in_progress` 记 `RawStatus`（契约 §2.6 归一规则：不猜测失败）。
- 产物下载：**`content.video_url` 绝对 URL 直连**（无凭据，与 Veo uri / glm video_result.url / minimax file_download_url 同族先例；`ContentFromArtifact=true`）。
- 取消：契约 §9.1 回填面无任务取消端点 → `SupportsCancel=false`，网关不发上游请求直接本地收敛 `cancelled`（沿 glm/minimax 裁决；官方回调文档提及任务存在 `cancelled` 终态、仅排队中任务可取消，取消端点回填后再升级）。
- Capabilities：`NegativePrompt=false`、`Audio=false`、`Seconds=true`、`InputReference=true`、`N=false`、`Seed=true`。
- **图生视频 i2v 实弹（2026-10-17 方舟全能力实测批）**：`input_reference` 传境内直链首帧图（ark-project TOS `images/view.jpeg`，直出 200）→ 创建受理 → 轮询 completed → `content.video_url` 签名 mp4 产物 + `outputVideoSeconds: 5` 计量 → $0.357 落库（与 t2v 同模型同时长同价）——`InputReference=true` 能力位的真实上游验证；产物可取回性同 t2v（上游签名直链时效内可下载）。

### 语音合成（`POST /v1/audio/speech` 统一面，M6 已实施 adapter；2026-10-17 迁移至 `/api/v3/tts/create` 面）

- **迁移事实（2026-10-17 真实上游实测）**：M6 依据的旧端点 `POST https://openspeech.bytedance.com/api/v3/tts` 已 404 下线（"Endpoint 'tts' does not exist"），旧版语音应用 appid+token 双值凭据与 `Authorization: Bearer;<token>` 分号形态一并废弃；现役面为豆包音频生成 `POST /api/v3/tts/create`（契约 §9.2，置信度 A：官方文档 + 实测）。
- 出站报文改写（`gatewaymedia/volcengine_tts.go`，注册 `speechAdapters` 的 `volcengine` 条目）：`model` **真实透传**（现役 `seed-audio-1.0`；统一面历史占位名 `doubao-tts` 由 adapter 归一映射为 `seed-audio-1.0`，兼容既有账户的占位目录行与 supportedModels 引用）；`input` → `text_prompt`；`voice` → `speaker`（音色按 speaker 配置，如 `zh_female_cancan_mars_bigtts`；上游可选，缺省默认音色——统一面 OpenAI 语义 voice 必填不变）；`response_format` → `audio_config.format`（**实测词表 `mp3`/`wav`/`ogg_opus`/`opus`**，缺省 mp3；opus 上游返回 OggS 容器、content-type 按 `audio/ogg`；pcm 实测上游挂起超时不采纳；词表外本地 400 零转码）；`speed` → `audio_config.speech_rate`（倍率形态；3.0 实测接受，上游对越界值静默接受不拒绝——网关维持声明区间 **[0.2, 3.0]** 预校验本地 400，契约 §2.4 规则 2）；厂商个例（`audio_config.loudness_rate` 等）经 `provider_options.volcengine` deep-merge。
- 鉴权：`X-Api-Key: <speech_token>` 单头单值（新版语音控制台 API Key，在火山控制台「语音技术」新版控制台创建；不是 ark API Key，不能复用 openai 族 Bearer 形态）。
- URL 构造特例：出站 host 恒 `https://openspeech.bytedance.com`（语音服务域，与账户 base_url 无关）；路径 `/api/v3/tts/create`。
- 响应转换：HTTP 200 `{"audio":"<base64>","duration":3.28,"original_duration":3.28,"url":"<签名 CDN 直链，约 2 小时时效>"}`——成功响应**无 code 字段**；`audio` base64 解码为二进制透传下游（content-type 按请求 format 推导）；`audio` 缺失/解码失败整单失败上抛（HTTP 非 200 的平铺 `{"code":45000010,"message":"..."}` 错误信封由链上层按状态码统一处理；同步面无任务受理语义，不猜测音频可用性）。
- **分派校验语义（2026-10-17 实测回填）**：volcengine 账户的 speech 请求若 L1 校验不过（`voice` 必填缺失等）→ 网关 400 `invalid_gateway_request` 透传校验消息，不落 openai 通用透传链（旧行为：静默落通用链把参数错误送上游 404 后伪装 503 upstream_retryable_error）。
- 计量（**2026-10-17 维度修正批**）：官方计费维度为生成原始时长（计费文档明文「按模型生成的原始时长计费，倍速不影响计费时长」，精确至秒）——网关取响应顶层 `duration` 秒落 `audio_input_seconds` 音频秒计量（费率 `audioInputUsdPerSecond` 按模型），**不再落字符口径** `TtsInputChars`（字符非官方计费维度）；duration 缺失/非正值 → 0 计量 + `usage_missing` 标记，不猜测（契约 §2.8）。单价已落值：后付费 1 元/分钟 ÷ 60 ÷ 7.0 → $0.00238095/秒（见「计价口径」）。
- **流式 TTS（豆包语音合成模型 2.0 / seed-tts-2.0，2026-10-18 桥接 V1a 已实施）**：`/v1/audio/speech` 统一面按 model 分派——`seed-tts-2.0` 走 `POST /api/v3/tts/unidirectional` HTTP chunked NDJSON 面（[火山流式语音桥接设计](火山流式语音桥接设计.md) V1a 全缓冲转换；V1b 字符级流式回流展望）。`X-Api-Key` 单头与 `speech_token` 同凭据（实测穿过鉴权层，零新凭据）；2.0 词表 mp3/pcm/ogg_opus/wav（无 opus、pcm 正式支持）；计量走**字符口径**（官方维度语音合成 2.0 按字符 3 元/万字符 ÷7.0，目录行 `ttsInputCostPerChar`——与 1.0 时长口径按 model 分流，见契约 §9.2）；错误行 55000000（音色未授权）→ 502 透传。**真实出音待 2.0 音色授权**（语音控制台开通）。Mock：`media_volcengine_tts_stream_ok` / `_stream_failed`（契约 §9.2）。
- **Agent Plan 语音面未承接（实测记录）**：Agent Plan 套餐语音模型（seed-tts-2.0 / volc.seedasr.sauc.duration）走 `wss|https://openspeech.bytedance.com/api/v3/plan/tts/*` 与 `/api/v3/plan/sauc/*` 专属路径族，鉴权为三头形态（`X-Api-App-Key` + `X-Api-Access-Key` + `X-Api-Resource-Id`）+ 独立凭据体系（实测 ark API Key 作 Bearer 或三头同值均 401 "grant not found"，通用面 `X-Api-Key` 亦不适用），且语音合成 2.0 以 WebSocket 流式为主——与本网关同步 TTS 面不同构。承接需专门批次，当前档案不声明、请求不路由。

### 语音识别（`POST /v1/audio/jobs` 统一面，2026-10-17 承接批已实施 adapter；上游为录音文件识别 2.0 异步两段）

- **上游面（契约 §9.2，置信度 A：官方文档 + 零计费探测 + 真实转写实测）**：host 恒 `https://openspeech.bytedance.com`（语音服务域，与账户 ark base_url 无关——同 TTS URL 构造特例）；`POST /api/v3/auc/bigmodel/submit` 提交 + `POST /api/v3/auc/bigmodel/query` 轮询；资源 `X-Api-Resource-Id: volc.seedasr.auc`（录音文件识别**2.0**；1.0 系 `volc.bigasr.*` 未开通——探测变体必须用 2.0）。**头驱动受理协议**：submit 成功响应 body 为空，成功标志在响应头 `X-Api-Status-Code: 20000000`；任务 ID = 网关自定义请求头 `X-Api-Request-Id`（query 用同一值）。终态返回 `{"audio_info":{"duration":<毫秒>},"result":{"text","utterances":[词级时间戳]}}`。
