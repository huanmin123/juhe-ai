## 2. 抓取方式矩阵（先查这里再动手）

**决策顺序**（2026-10-17 实战校准）：

1. **web_reader（内置）先试一次**：正文型文档（计费规则、口径说明）通常可直接取到。
2. **正文能取到但价格表是空白/表格骨架**（火山系 `docs.volcengine.com`、豆包语音计费页等 **JS 渲染页**的典型症状）→ **不要反复换 prompt 重试 web_reader，直接换浏览器渲染抓取**（ZCode browser-use：`goto` → `waitForLoadState domcontentloaded` → `waitForTimeout(6000-7000)` 等渲染 → `tab.playwright.evaluate(() => document.body.innerText…)` 读全文，`indexOf` 定位段落切片）。
   - 实战证据：火山方舟模型价格页 web_reader 只回导航骨架（seedance 表全空）；浏览器打开后 6 秒即拿到完整牌价表（seedance 全系 token 单价 + 每秒示例 + 1-0-pro 明文），一次成功。
   - 浏览器打开后注意 **302 跳转**（旧路径 → `docs.volcengine.com/docs/ark/model-pricing?lang=zh`），按跳转后的 tab 读取。
3. **web_reader 直接拿到完整表格**（deepseek、xai、anthropic docs 等静态渲染页）→ 直接用，注意留存原句。
4. 登录态/区域限制页面（如 OpenAI pricing 登录墙）→ 先试未登录镜像页；仍取不到 → **向用户求助**（人工开页面核对、提供截图或控制台价目），**不编造、不用第三方聚合站当权威**。
5. 所有取到的数字都要**二次定位**：在页面全文里 `indexOf` 关键词（如 `seedance`、`音频生成`）确认表格归属模型与分档，再摘录。

### 浏览器抓取操作卡（照抄可用）

```js
// 1) 打开并等待渲染（每次 js 调用都要先跑 bootstrap）
const tab = await browser.tabs.new();
await tab.goto("<价格页 URL>");
await tab.playwright.waitForLoadState({ state: "domcontentloaded" });
await tab.playwright.waitForTimeout(7000);
// 2) 定位段落（避免一次性输出超长全文）
const text = await tab.playwright.evaluate(() => {
  const body = document.body.innerText;
  const i = body.indexOf("<关键词，如 seedance>");
  return { total: body.length, hits: [/* 所有出现位置 */], snippet: body.slice(i - 300, i + 3000) };
});
nodeRepl.write(JSON.stringify(text));
```

注意：`tab.playwright.title()` 不存在——用 `browser.tabs.list()` 看标题/URL；每次 `js` 调用都是新内核，tab id 用 `browser.tabs.list()` 现查现用。

## 3. 落值与记录规范（不丢失信息）

1. **catalogdata/*.json 是唯一数据源**：gateway `go:embed` 运行时计价 + maintenance DB 种子（`TestGenerateSeedCatalog` 重生成）双通道同源。改价只改 JSON，然后 `n=1 go test ./projects/gateway/internal/pricing/ -run TestGenerateSeedCatalog -count=1` 重生成。
2. **`sourcePricingNote` 必须留全**（这是防"信息丢失"的主载体）：
   - 官方**原句**（人民币原句或 USD 明文，含分档全表摘要）；
   - 页面 URL + 抓取日期 + 抓取方式（"web_reader 明文"/"浏览器渲染抓取"）；
   - 口径裁决（如 ÷ 约定汇率 7.0、720p 主档声明、离线/在线口径）；
   - 换算算式（如 `1 元/分钟 ÷ 60 ÷ 7.0 → $0.00238095/秒`）。
3. **锚点测试钉价**：关键单价在 `catalogdata_volcengine_price_test.go`（volcengine）与 `catalogdata_price_anchors_test.go`（minimax/qwen/glm/deepseek/xai 五家 2026-10-17 批）锁值，防后续编辑静默丢失；目录总行数钉值在 maintenance `model_catalog_seed_test.go`（加行后同步）。国内÷7.0 回正行统一挂 CNY 换算四件套（sourcePricingCurrency=CNY、sourceExchangeRateToUsd=7、sourceExchangeRateDate=核对日）。
4. **文档同步**：价格口径变更同步《媒体上游协议契约与Mock上游规格》§2.8/对应厂商节 + 《火山方舟账号接入》等接入文档「计价口径」节。
5. **成本 0 不虚计**：抓不到明文单价的维度保持 NULL + 注记声明"待回填"，绝不编造；占位价（错维度假价）发现即撤。
