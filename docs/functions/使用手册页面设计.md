# 使用手册页面设计

> 状态：首版落地。
> 本文记录面向最终用户的静态使用手册页面、入口、角色内容边界和访问控制。

## 1. 目标

- 给普通用户和管理员提供分角色的使用手册，避免复杂功能只靠页面提示和对话解释。
- 让用户通过能力图和流程图理解网关请求从 API Key 到策略路由、分组、AI 账户和上游供应商的流转。
- 手册页面独立于后台管理路由，不进入左侧菜单，不嵌入当前系统页面内容区。
- 未登录用户不能通过外部链接直接访问手册内容。

## 2. 页面路径

静态页面位于 `frontend/public/help/`，构建后由系统前缀暴露：

| 路径 | 用途 |
| --- | --- |
| `/__aisys__/help/` | 手册分流入口，后端按当前登录角色跳到对应手册。 |
| `/__aisys__/help/user/` | 普通用户手册。 |
| `/__aisys__/help/admin/` | 管理员手册。 |

顶部帮助入口放在应用头部公告铃铛左侧。点击后打开新页面：

- 普通用户打开 `/__aisys__/help/user/`。
- 管理角色打开 `/__aisys__/help/admin/`。

## 3. 访问控制

帮助页虽然是静态 HTML，但不能直接公开给未登录用户。

- 后端在通用 `express.static` 之前拦截 `/__aisys__/help/*`。
- 拦截逻辑通过 DB service 的 `/__aisys__/api/auth/me` 校验当前 Cookie 登录态。
- 未登录、会话过期或无效会话访问帮助页时，返回 `302` 到 `/__aisys__/login?redirect=原始帮助路径`。
- 登录页识别 `/__aisys__/help/*` 静态路径，登录成功后使用浏览器跳转回原静态页面。
- 普通用户访问 `/__aisys__/help/admin/` 时，后端跳转到 `/__aisys__/help/user/`。
- 管理员可以访问普通用户手册，用于核对普通用户可见流程。

主 Web 进程不直接读取系统账户数据库，不导入 repository 校验会话；会话事实仍由 DB service 和现有 auth 接口确认。

## 4. 内容边界

普通用户手册只说明普通用户可见和可操作的内容：

- 快速使用：AI 账户、分组、策略路由、API Key 和客户端配置。
- 能力图示：先用图说明主链路、路由模式、高并发分组调度和错误处理决策，再用配置表解释字段。
- 配置地图：把用户问题映射到 API Key、策略路由、分组、AI 账户、错误策略和使用记录。
- 配置方案：按个人稳定使用、多人共用、高可用主备、权重分摊、轮询、智能分级、限流处理和模型别名等目标给出推荐组合。
- API Key：名称、策略路由、运行状态、过期时间、美元额度、时间计划、刷新密钥和客户端接入说明。
- 策略路由：普通、混合智能、权重、故障回退和轮询模式的适用场景、配置项、误区和调度偏好。
- 分组：分组名称、所属供应商、分组类型、状态、高并发配置和常见容量错误。
- AI 账户：供应商 / 接入类型、凭据、Base URL、支持模型、并发上限、优先级、标签、代理、到期时间和时间计划。
- 账户操作：编辑、测试、启停、恢复、超级优先、降级备用、迁移流量、OAuth 刷新 / 重新授权、克隆、删除、归还授权和批量操作。
- 模型与接口能力：支持模型、账号模型别名、接口能力限制和代理配置。
- 错误与响应策略：账号错误处理策略、响应检查策略、匹配字段、处理动作、恢复策略和取样来源。
- 授权资源、创建授权、授权状态操作、使用记录筛选、模型检测、请求流转图和排障清单。

管理员手册说明管理侧能力：

- 管理视角和用户模式 / 管理模式差异。
- 请求与后台流转，包括记录入队和统计窗口。
- 供应商、代理、AI 账户、分组、策略路由和 API Key 管理。
- 统一授权、系统账户、统计日志、审计和运维排障。

手册不得展示 API Key 明文、OAuth token、上游 API Key、代理密码、原始审计 payload 或任何用户私有数据。

面向用户的手册只写页面可见、可配置、可排障的内容。客户端画像、内部自动识别、内部协议桥接、缓存亲和、后台派生字段等没有页面配置入口的机制，不写入用户手册；确需排障时只在开发文档或管理员内部排障文档中说明。

## 5. 维护规则

- 调整路由层级、路由模式、分组语义、API Key 绑定关系或请求流转时，同步更新普通用户和管理员手册。
- 调整主链路、路由模式、高并发规则或错误处理流程时，同步更新普通用户手册里的图示和文字说明。
- 调整系统账户、授权、日志审计、统计聚合或运维入口时，同步更新管理员手册。
- 调整普通用户页面可见表单项、筛选项、操作菜单、状态标签、配置默认值或 tooltip 时，同步更新普通用户手册对应章节。
- 调整帮助页路径、登录态校验、角色跳转或顶部入口时，同步更新本文和 [接口契约与权限矩阵](接口契约与权限矩阵.md)。
- 手册是静态页面，第一版只使用 HTML、CSS 和少量无依赖 JS；后续如果引入文档框架，必须继续满足登录态保护和分角色内容边界。

## 6. 验证要点

- 未登录访问 `/__aisys__/help/user/` 会跳转到登录页。
- 未登录访问 `/__aisys__/help/admin/` 会跳转到登录页。
- 普通用户登录后访问管理员手册会跳转到普通用户手册。
- 管理员登录后访问 `/__aisys__/help/` 会跳转到管理员手册。
- 普通用户登录后访问 `/__aisys__/help/` 会跳转到普通用户手册。
- 登录页携带帮助页 `redirect` 时，登录成功后能回到对应静态手册。
