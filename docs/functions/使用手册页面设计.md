# 使用手册页面设计

> 状态：第三版已落地。
> 本文定义静态帮助页的访问边界、内容覆盖和维护验收，不替代正式协议或后台功能文档。

## 1. 目标与非目标

- 目标：让普通用户完成“分组 -> 账户 -> 检查激活 -> 策略 -> API Key -> 客户端”的最小链路；让管理员按管理链路找到全部管理页面、作用域和操作风险。
- 目标：每个核心配置字段写清楚“作用、显示条件、取值/空值语义、保存后的影响和排障入口”，而不是只写菜单用途。
- 目标：静态页保持为工作型文档，支持无依赖搜索、章节锚点、键盘焦点、手机目录和可操作的 SVG 路由/生命周期图。
- 非目标：不把 API Key 明文、OAuth token、上游凭据、代理密码、原始审计 payload 或完整账户导入协议放入帮助页。

## 2. 页面路径与访问控制

静态页面位于 `frontend/public/help/`，构建后由系统前缀暴露：

| 路径 | 用途 |
| --- | --- |
| `/__aisys__/help/` | 根据当前登录角色分流。 |
| `/__aisys__/help/user/` | 普通用户手册。 |
| `/__aisys__/help/admin/` | 管理员手册。 |

- 后端在通用静态资源之前校验 `/__aisys__/help/*` 登录态；未登录跳转到 `/__aisys__/login?redirect=原始帮助路径`。
- 普通用户访问管理员手册时跳转回用户手册；管理员可查看用户手册。
- 顶部帮助入口在新页面打开对应角色的手册。

## 3. 内容契约

### 普通用户手册

- 必须给出最小链路和所有真实用户路由的 `/__aisys__/` 深链：AI 问答、我的统计、AI 账户、分组、API Key、策略路由、模型检测、模型目录、授权、授权团队/用户消耗、团队、用量统计、AI 性能、AI 健康、使用记录和操作日志。
- 核心配置必须覆盖分组、AI 账户、策略路由和 API Key 的字段作用：供应商边界、个人/高并发、账户状态/并发/优先级、多 Key 权重、Base URL、支持模型、接口能力、模型别名、五种策略模式、额度和时间计划。
- AI 问答使用当前系统账户维护的专属对话 Key；不得将其写成普通客户端 API Key 的调用验证入口。
- 账户导入说明限定为操作步骤和语义：用户仅导入自己账户；管理员可按目标用户导入；仅接受 `juhe-ai-account-import v1` JSON；支持协议下载、AI 转换、解析预览、确认导入、自动建组和重复跳过；普通用户不能创建新代理；`active` 导入创建为 `pending_test`。完整字段协议只由《AI 账户导入协议》维护。
- 不说明没有页面配置入口的客户端画像、内部协议桥接和内部调度派生细节。

### 管理员手册

- 必须覆盖当前全部 28 个管理路由，并按管理链路、AI 管理、统一授权、日志与观测、系统运维、排障分组。
- 每项写明用途、前置条件或数据作用域、关键风险和 `/__aisys__/` 深链。
- 管理员核心配置必须补充账户生命周期、五种策略模式、响应检查策略、品牌/网关/限流/健康恢复/超时/保留期系统设置的分组说明；系统设置的默认值以实际表单和默认配置为准。
- 分组会保存供应商配置，并以该供应商作为账户过滤边界；复制策略需求应新建同配置策略再绑定 API Key，避免影响原策略流量。

## 4. UI 与可访问性

- 使用 `/__aisys__/brand-icon.svg`；用户页顶部固定显示“用户使用手册”，管理员页固定显示“管理员使用手册”。
- 顶部提供搜索、跳到正文、更新时间；桌面使用 sticky 目录，手机使用 `details` 目录。
- 搜索无第三方依赖，按全部关键词匹配章节并在输入框下展示结果；点击结果或按 `Enter` 平滑滚动定位首个结果，不隐藏页面正文；`Esc` 清空并关闭搜索焦点。章节同步目录的 `aria-current`。
- 关键焦点态可见；字段参考使用原生 `details`；表格/长 SVG 外层局部横向滚动；手机把流程和路由项目排列为单列，不隐藏 SVG 的文字替代。
- 流程图使用 `viewBox`、`title`、`desc`，步骤控件使用 `role="tab"` 和 `aria-selected`；方向键可切换节点，SVG 内部链接仍可打开对应配置页；交互状态由外部 `help.js` 绑定，禁止内联脚本和事件属性。

## 5. 维护与验证

- 调整用户或管理路由、权限范围、导入语义、链路或页面入口时，同步更新对应帮助页和本设计文档。
- 调整表单字段、默认值、枚举、调度规则、系统设置或状态语义时，先以 `frontend/src/views/` 的实际表单/默认配置和对应功能文档核对，再同步字段参考；不能复制过期 tooltip 的数字。
- 维护 `frontend/src/scripts/regression/help-content-regression.ts` 的用户 17 路由、管理 28 路由与帮助页链接覆盖；该回归同时固定字段级指南、SVG `title/desc`、流程键盘交互、导入语义、错误旧文案、品牌图标、搜索、跳转、辅助技术和移动目录契约。
- 执行 `pnpm.cmd --filter juhe-ai-frontend test:help-content`，并随前端改动执行类型检查和构建。
