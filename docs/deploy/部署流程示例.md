# 部署流程示例

## 示例目标

- 先按部署场景选择入口文档。
- 构建发布包。
- 再按目标平台选择平台文档。
- 部署到目标机器或家庭主机。
- 如果需要公网域名访问，配置 Caddy 自动 HTTPS。
- 使用平台服务管理器负责常驻；外部状态探针默认只告警。
- 如果上游 API 无法直连，配置 sing-box 并在后台绑定代理。
- capability v1 / legacy 上线前生成项目备份和业务备份，两类分别只保留最近 3 次；Redis、日志和非业务历史不备份。active contract 为 capability v2 时改用 sealed-producer coordinator：同一 snapshot 覆盖 public Goose ledger、business、stats 和存在的 rollback compat，compat pin set 不受普通三份轮换；当前示例不能直接执行 v2 备份或切换。
- 验证后台、系统 API 和网关入口。

## 步骤

1. 构建发布包：

```powershell
pnpm install
pnpm package:release:windows
```

2. 先按部署场景选择文档：

```text
服务器 / VPS / 云主机：docs/deploy/scenarios/服务器部署方案.md
家里电脑 / 家用主机 / 家庭宽带：docs/deploy/scenarios/家庭宽带反向代理方案.md
不确定：docs/deploy/scenarios/部署场景选择示例.md
```

3. 再按目标平台选择部署文档：

```text
Linux：docs/deploy/linux/Linux部署指南.md
Windows：docs/deploy/windows/Windows部署指南.md
macOS：docs/deploy/macos/macOS部署指南.md
Docker：docs/deploy/Docker部署指南.md
```

4. 如果需要公网 HTTPS，配置 Caddy：

```text
docs/deploy/https/Caddy自动HTTPS部署指南.md
```

关键配置：

```text
JUHE_AI_ALLOWED_ORIGINS=https://你的域名
JUHE_AI_COOKIE_SECURE=true
JUHE_AI_TRUST_PROXY=true
```

Docker 由宿主机 Caddy 反代时，额外设置：

```text
JUHE_AI_PUBLIC_BIND=127.0.0.1
JUHE_AI_PUBLIC_ORIGIN=https://你的域名
```

5. 配置常驻和状态检测：

```text
Linux 使用 systemd；macOS 使用 launchd；Windows 使用 Windows Service / NSSM；Docker 使用 restart policy。
外部探针默认只告警。
```

确有无人值守自动恢复需求时，再看 `docs/deploy/watchdog/状态检测与自动恢复指南.md`。关键规则：

```text
本机 health 连续失败 2-3 次才重启
重启后设置冷却
10 分钟内限制最大重启次数
公网 health 单独失败时先查 Caddy / DNS / WireGuard
发布、迁移和候选配置验证期间必须与自动重启互斥
```

6. 高性能模式上线备份 / 清理：

```text
project-时间戳：升级前当前运行 release、清单、校验值；目标迁移脚本仅作附加证据
business-时间戳：同一时刻的 juhe_business、恢复所需 env、schema / 清单、校验值
capability v1 / legacy 的项目备份和业务备份分别只保留最近 3 次；v2 使用 coordinator 和 compat pin set
不备份 dataset、usage、stats、Codex context、审计、日志或 Redis
停服务后确认 Redis Streams pending / lag = 0
确认后直接清 Redis cache / state / queue
```

7. 如果上游 API 需要代理访问，先部署 sing-box：

```text
docs/deploy/proxy/sing-box网络代理部署指南.md
```

8. 在 juhe-ai 后台“代理管理”新增代理，并绑定到 AI 账户：

```text
类型：socks5h
Host：按部署形态选择 127.0.0.1 / host.docker.internal / 代理机内网 IP
端口：7890
```

9. 验证：

```text
/__aisys__/health
/__aisys__/api/health
/__aisys__/
https://你的域名/__aisys__/
https://你的域名/v1
账号测试
代理测试
服务管理器与 supervisor 日志
```
