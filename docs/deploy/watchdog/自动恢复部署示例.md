# 自动恢复部署示例

> 本文是可选配置，不是生产默认基线。默认由平台服务管理器负责进程退出后的恢复，外部探针只告警。只有明确需要无人值守恢复、并已与发布流程建立互斥时，才采用下面的自动重启示例。

## 1. 判据

自动重启只看本机：

```text
http://127.0.0.1:3000/__aisys__/health
http://127.0.0.1:3000/__aisys__/api/health
```

两者同轮都失败才累计失败次数。公网域名失败但本机 health 正常时，先查 Caddy、DNS、证书、隧道和防火墙。

建议参数：

```text
检查间隔：15-30s
请求超时：5s
连续失败阈值：2-3
启动宽限期：60s
重启冷却：60s
窗口限频：10分钟最多3次
```

## 2. macOS launchd

可选 watchdog 连续失败后只终止当前 server，主服务 `launchd KeepAlive` 自动拉起。默认部署不要启用这个动作。

```bash
HEALTH_URL="${JUHE_AI_WATCHDOG_HEALTH_URL:-http://127.0.0.1:3000/__aisys__/health}"
API_HEALTH_URL="${JUHE_AI_WATCHDOG_API_HEALTH_URL:-http://127.0.0.1:3000/__aisys__/api/health}"
FAIL_THRESHOLD="${JUHE_AI_WATCHDOG_FAIL_THRESHOLD:-2}"
COOLDOWN_SECONDS="${JUHE_AI_WATCHDOG_COOLDOWN_SECONDS:-60}"
```

CPU 高但两个 health 正常时默认只记录，不杀进程。

## 3. Linux systemd

主服务：

```ini
[Service]
Type=simple
WorkingDirectory=/opt/juhe-ai-lite/current
ExecStart=/usr/bin/env bash /opt/juhe-ai-lite/bin/run.sh
Restart=always
RestartSec=5
StartLimitIntervalSec=600
StartLimitBurst=5
```

可选 watchdog 连续失败后执行：

```bash
systemctl restart juhe-ai
```

脚本自身仍要做窗口限频；超过阈值后只报警和记录日志。

## 4. Docker

Compose healthcheck 只能做基础标记，不保证自动重启：

```yaml
services:
  juhe-ai:
    restart: unless-stopped
    healthcheck:
      test:
        [
          "CMD",
          "node",
          "-e",
          "Promise.all([fetch('http://127.0.0.1:3000/__aisys__/health'),fetch('http://127.0.0.1:3000/__aisys__/api/health')]).then(([a,b])=>process.exit(a.ok&&b.ok?0:1)).catch(()=>process.exit(1))"
        ]
      interval: 30s
      timeout: 5s
      retries: 3
      start_period: 60s
```

可选外部 watchdog 达到阈值后只重启应用容器：

```bash
docker compose restart juhe-ai
docker compose --env-file .env.performance -f compose.performance.yml restart juhe-ai
```

不要因为 PostgreSQL、Redis 或上游模型 API 短暂失败就重启整组容器。

## 5. Windows PowerShell

```powershell
$healthUrl = "http://127.0.0.1:3000/__aisys__/health"
$apiHealthUrl = "http://127.0.0.1:3000/__aisys__/api/health"
$failThreshold = 3
$timeoutSec = 5
$intervalSec = 30
$startupGraceSec = 60
$cooldownSec = 60
$windowSec = 600
$maxRestartsInWindow = 3
$failCount = 0
$restartTimes = New-Object System.Collections.Generic.List[datetime]

Start-Sleep -Seconds $startupGraceSec

while ($true) {
  $healthOk = $false
  $apiHealthOk = $false

  try { $healthOk = (Invoke-WebRequest $healthUrl -TimeoutSec $timeoutSec).StatusCode -eq 200 } catch {}
  try { $apiHealthOk = (Invoke-WebRequest $apiHealthUrl -TimeoutSec $timeoutSec).StatusCode -eq 200 } catch {}

  if ($healthOk -or $apiHealthOk) {
    $failCount = 0
  } else {
    $failCount++
  }

  if ($failCount -ge $failThreshold) {
    $now = Get-Date
    $recent = @($restartTimes | Where-Object { ($now - $_).TotalSeconds -lt $windowSec })
    $restartTimes.Clear()
    foreach ($item in $recent) { $restartTimes.Add($item) }

    if ($restartTimes.Count -lt $maxRestartsInWindow) {
      Restart-Service JuheAI
      $restartTimes.Add($now)
      Start-Sleep -Seconds $cooldownSec
    }

    $failCount = 0
  }

  Start-Sleep -Seconds $intervalSec
}
```
