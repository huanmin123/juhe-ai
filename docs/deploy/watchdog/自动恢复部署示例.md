# 自动恢复部署示例（外部 watchdog 已退役）

旧版 macOS、Linux、Docker 和 Windows HTTP watchdog 示例不再是部署输入，禁止复制、安装或恢复。

当前平台只配置进程退出恢复：

- macOS：launchd `KeepAlive` 守护主进程。
- Linux：systemd `Restart=on-failure` 守护主进程。
- Windows：Windows Service / NSSM 守护主进程。
- Docker：容器 restart policy 守护主进程退出。

DB service 和 worker 均由主进程 supervisor 管理，不单独注册服务。公网 health 只做观察和发布门禁，不关联自动重启、切代理或回滚。完整边界见 [状态检测与自动恢复指南](状态检测与自动恢复指南.md)。
