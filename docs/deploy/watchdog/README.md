# 状态检测与自动恢复目录

> 面向家庭部署、服务器部署和长期运行节点。
> 这里说明如何检查 juhe-ai 运行状态、异常时自动恢复，以及如何避免故障时疯狂重启。

- [自动恢复部署示例](自动恢复部署示例.md)：macOS launchd、Linux systemd、Docker 和 Windows 的简化示例。

## 适用边界

- 家庭宽带、Mac mini、Windows 桌面机、NAS、小主机和云服务器都应该配置状态检测。
- 应用内部 supervisor 已负责 DB service / worker 子进程异常退出后的退避重启；外部 watchdog 只负责主服务不可用时重启主服务。
- watchdog 不能替代日志、备份、数据库完整性检查和上游代理测试。
- 自动恢复必须带连续失败阈值、启动宽限期、冷却时间和重启次数窗口，避免网络抖动或上游故障触发重启风暴。
