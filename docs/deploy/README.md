# 部署文档目录

> 面向 AI 与维护者。
> 这里集中放发布包构建、服务器部署、常驻运行、反向代理、备份迁移和排障相关文档。

## 文档索引

- [跨平台构建文档](构建指南.md)：构建环境检测、构建命令、产物说明、构建参数和构建后检查。
- [跨平台部署文档](部署指南.md)：部署兼容矩阵、解压配置、启动验证、常驻运行、Nginx 示例、备份迁移和常见排障。
- [Docker 部署指南](Docker部署指南.md)：单容器镜像构建、默认配置、启动、验证和清理。
- [高性能模式部署指南](高性能模式部署指南.md)：PostgreSQL、PgBouncer、Redis cache、Redis state、PostgreSQL 初始化、Docker / 非 Docker 中间件部署、凭据记录、设置、验证和备份。

## 适用边界

- 构建指南回答“如何从源码生成可部署发布包，以及构建后如何检查产物”。
- 部署指南回答“如何把发布包放到目标机器上运行，以及如何配置、验证、常驻和迁移”。
- Docker 部署指南回答“如何直接用 Docker 镜像和 Compose 运行项目”。
- 高性能模式部署指南回答“如何用 Docker 或非 Docker 方式部署 PostgreSQL + Redis 中间件、初始化 PostgreSQL schema / 默认数据、记录生产凭据，以及如何配置 performance 模式”。
- 影响本地开发启动或测试验证的内容应优先更新 `docs/develop/`，不要混入部署文档。
- 影响环境变量、数据目录、加密密钥或发布包结构时，需要同时确认构建指南和部署指南。
