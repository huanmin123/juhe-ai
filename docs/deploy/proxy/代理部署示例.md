# 代理部署示例

## 示例目标

- sing-box 在 juhe-ai 同一台 Linux 主机运行。
- 本地代理端口：`127.0.0.1:7890`。
- juhe-ai 使用发布包裸机部署。
- 需要让 OpenAI / Anthropic / Gemini 等上游请求走代理。

## 步骤

安装 sing-box 后，写入 `/etc/sing-box/config.json`，配置本机 mixed 入站：

```json
{
  "log": {
    "level": "info"
  },
  "inbounds": [
    {
      "type": "mixed",
      "tag": "mixed-in",
      "listen": "127.0.0.1",
      "listen_port": 7890
    }
  ],
  "outbounds": [
    {
      "type": "direct",
      "tag": "direct"
    }
  ],
  "route": {
    "final": "direct"
  }
}
```

把 `outbounds` 替换为你的真实可用出口后验证：

```bash
sing-box check -c /etc/sing-box/config.json
sudo systemctl restart sing-box
curl -x socks5h://127.0.0.1:7890 https://api.openai.com/v1/models -I
```

在 juhe-ai 后台“代理管理”新增：

```text
名称：本机 sing-box
类型：socks5h
Host：127.0.0.1
端口：7890
```

保存后点“测试代理”，再进入 AI 账户编辑页，把该代理绑定到需要访问上游的账号。
