# PLAN-20260810T000000000Z：第三方登录与个人委托授权

> **状态：Node + Vue 本地实现完成，待生产接入门禁。** 关联设计：[第三方登录与个人委托授权设计](../functions/第三方登录与个人委托授权设计.md)。本次不创建生产 Client、不开放公网端点，也不迁移 Go。

## 目标

将 juhe-ai 建设为 OAuth 2.1 / OIDC Provider：第三方应用可让已有 juhe-ai 账号的用户登录并显式授权；第三方获得从用户允许时刻起固定 UTC 168 小时硬到期、可撤销且可在 72 小时后受控轮换的 access token，只能调用该用户本人且 scope 允许的个人委托 API。V1 的到期时长不可配置，轮换不延长该时刻。

## 范围与非范围

- 范围：Node + Vue、授权码 + PKCE、OIDC、浏览器/本地回调、Device Flow、Client 管理，以及仅限个人信息、API Key、路由策略、分组、AI 账户和请求限制的个人委托 API。
- 非范围：第三方身份登录 juhe-ai、自动注册 juhe-ai 用户、复用 `/__aipublic__` source token、标准 OAuth `refresh_token`、延长 grant 硬到期的滑动续期、Implicit Flow、Password Grant、backend-go 同步。

## 前置决策

1. V1 scope 已限定为个人信息、API Key、路由策略、分组、AI 账户和只读请求限制；确认每个写 scope 的字段白名单。
2. 确认生产 `issuer`、HTTPS 域名和可信代理边界；签名密钥由平台每 7 天自动轮换，第三方按未知 `kid` 刷新 JWKS。
3. 确认 Client 仅管理员登记，还是未来开放经审核的自助登记。
4. 确认 API Key 创建/重置和上游凭据更新均不进入 V1 委托权限。

## 退出标准

- 所有 V1 调用方只能拿到授权码回调，不能在 URL 取得 token。
- `grant.expiresAt = approvalAt + 168h`，以 UTC 时间戳计算且 V1 固定不可配置；当前未替换 token 签发满 72 小时后可轮换为同一 grant 剩余时长的 successor。所有 access token 的 `expires_at` / `expires_in` 均不得越过 `grant.expiresAt`；到期必须重新走授权确认。
- Client 停用和用户停用均使 token 立即无效；用户授权到期后自动失效，不提供用户主动终止入口。
- 任何委托 API 都从 token 推导本人身份，不能由请求参数指定他人账户。
- V1 个人委托 API 只开放个人信息、API Key、路由策略、分组、AI 账户和只读用户请求次数限制；限制必须覆盖每分钟、每日、每周、每月四个窗口，并返回各窗口的已用次数、剩余次数、重置时间、`asOf` 与数据状态，不把未知值伪装为零。
- API Key 明文、上游凭据、会话、密码和管理员数据不在 V1 scope 或响应中出现。
