## 范围与验收

- [ ] 业务进程只做 Pino JSON Lines 文件追加，不做运行日志解析、清洗、哈希、索引或 Redis 投递。
- [ ] ingest-worker 是唯一运行日志索引 owner，按 `file_identity + offset` 追尾当前和轮转文件。
- [ ] 游标只在索引 batch 成功提交后推进，失败和重启可继续消费。
- [ ] 未消费轮转文件受到清理保护，消费慢只形成可追赶文件 backlog。
- [ ] 运行日志 Redis Stream producer、1500ms timeout 和 timeout destroy/reconnect 路径删除。
- [ ] 使用记录、审计、操作日志和公开接口日志的其他 Redis Stream 队列不受影响。
- [ ] 鉴权、权限、输入校验和 HTTP 安全边界不变。
- [ ] 文档写明高性能日志热路径禁止同步加工，且有静态门禁。
- [ ] 本地 typecheck/build、专项回归、压力回归和真实 PostgreSQL/Redis smoke 通过。
- [ ] 两名只读复核 Agent 独立复核并完成交叉质疑，高严重度问题闭合。
- [ ] 合并到 `master` 并推送，再反向合并到 `feature/20260706-go` 并推送；不部署。
