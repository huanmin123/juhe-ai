# Codex 压缩失败终态结构处理修复

- 计划 ID：PLAN-20260729T130300133Z
- 状态：本地修复完成，待统一上线/生产验证
- 目标：让 Codex Remote Compaction V2 的精确 `response.failed` 立即进入通用结构失败路径，且不再被 EOF 本地 compact mismatch 覆盖。
- 授权：仅本地代码、文档与验证；不访问生产、不部署、不提交。

## 范围与非目标

- 范围：`response-inspection-buffer` 的 Codex compact SSE 暂存状态机、其本地回归、响应检查与上下文压缩契约说明。
- 非目标：不改变成功 `response.completed` 的合法 response id 和恰好一个 compact item 校验；不根据供应商错误码、错误类型、文案或 payload 内容新增策略；不修改账号状态、部署或生产数据。

## 设计结论与执行

- Sol/high 只读设计结论：compact 状态机只认精确 `event.eventType === "response.failed" || event.eventName === "response.failed"`。命中时清空已暂存 compact/output，只交出当前失败事件给既有结构失败管线并标记终态；只有两个精确终态都未出现的 EOF 才生成本地 mismatch。
- 实现：以事件身份判断失败终态，不读取 `code`、`type`、`message`、`response.error` 或其他 payload；普通 `data.error` / `metadata.error` 继续是普通事件。
- 风险与回滚：风险限定为 Codex compact 预提交失败的收口变化。若发生兼容回归，回滚本计划涉及的状态机与回归/文档变更即可；无需数据迁移或生产操作。
