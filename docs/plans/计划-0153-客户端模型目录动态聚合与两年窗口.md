# PLAN-0153 客户端模型目录动态聚合与两年窗口

## 基本信息

- 编号：`PLAN-0153`
- 状态：已撤销（由 `PLAN-0152` 全量模型目录方案取代）
- 创建时间：2026-07-22
- 需求来源：用户反馈线上 `/models` 只返回 Gemini，要求覆盖全部启用供应商并按供应商保留最近两年模型；API Key 请求按其路由策略分组涉及的供应商聚合。
- 执行者：Codex
- 继任计划：`docs/plans/计划-0152-客户端模型目录动态聚合.md`

## 需求目标

- 修复 `/models` 被 Gemini 优先识别的问题。
- 公开模型目录覆盖全部启用供应商。
- API Key 模型目录只覆盖该 Key 路由策略全部启用分组涉及的供应商。
- 内置模型客户端输出应用滚动最近两年窗口，旧模型仍可用于计价与历史记录解析。
- 网关模型响应直接复用供应商级缓存，退出 `default/codex` 发布响应快照；AI Chat 快照保留。

## 范围边界

### 本次包含

- 网关模型接口协议识别。
- 公开和认证模型目录供应商范围。
- 客户端两年窗口、目录去重和隐藏模型过滤。

- `default/codex` 网关发布快照退出。
- Node 回归、类型检查、构建、文档和接口验证。

- 生产部署和线上切流。

## 验收标准

- `/models` 不带 Gemini 特征时返回 OpenAI 结构。
- 公开目录覆盖全部启用供应商的近期可见模型。
- API Key 目录不泄露未绑定供应商模型。
- 所有客户端可见内置模型都有可信发布时间，且不早于滚动两年 cutoff。
- 旧模型价格查询和历史成本解析不受影响。
- 网关不再依赖 `default/codex` 发布快照，AI Chat 快照正常。
- 定向回归、类型检查和构建通过；未执行项有明确原因。
