# 计划-20260916T182403345Z-全链路真实AI业务场景验收

> 状态：mock 矩阵已闭环（2026-09-17）；真号 / 真实客户端门仍待 `JUHE_AI_E2E_REAL=1` 复验。目标：上线前最低验收标准——前端管理流程 + 真实 AI 账户 + mock 故障注入 + 真实客户端，把"路由 → 分组 → 账户 → 网关链 → 用量/审计"完整串起来。

## 1. 验收目标与范围

**目标**：证明以下链路在真实组件组合下符合预期功能效果，未达标不上线。

1. **业务场景串流程**：管理面（前端 API 契约）完成 API Key → 路由策略 → 分组 → AI 账户 全套配置，真实客户端经 `/v1` 打通，管理面（usage-records / audit-logs / 账户快照）能完整归因验证。
2. **真实 AI 全链路**：真实生产账户（20 个，多 provider）真实出网调用；mock AI 注入故障，与真号混搭验证切号。
3. **机制全覆盖**：5 种路由模式、切号语义（同账户重试/跨账户切换/耗尽 503/流式已提交不拼接）、账户状态机（rate_limited 冷却、error_disabled、恢复）、普通/高并发分组、多 Key 池隔离、协议转换边界。

**非目标**：页面交互 UI 测试（维持既有约定）；压测/性能验收（另有专项）；生产写操作（生产侧全程只读）。

### 5.3 仍开放 / 不在本轮范围

- **R5 FINDING #4**（观察，非 skip）：speed-first 同请求切号未按 degrade 观察触发，实际经 latency-degradation 重排接管。
- **R6 / G3 / S / C / M**：未跑。真号与真实客户端需 `JUHE_AI_E2E_REAL=1` 与生产只读凭据，本轮未取生产 secret。
- **`AreHighConcurrencyAccountsBusyForLaneAsync` 恒 false**（`chain_ports.go`）：preparation 组排队分支（label `high_concurrency_group_queue`）不可达。G1 已走 dispatch 循环 queue，不阻断；属 Node 对齐后续项。
- **`NewServerRetryBudget(0)`**（`chain_v1.go`）：dispatch 循环 WaitBudgetMs=1，排队上限回落到策略默认 60s。Release 接通后 1.5s 即唤醒，G1 不再撞上限；预算语义仍宜后续接到 preflight 的 `NoAvailableAccountWaitTimeoutSeconds`。
- **桥流式对照 flaky**：`TestChainBridgeResponseStreamFirstEventReadableBeforeUpstreamEOF` 用挂钟毫秒生成 `resp_<base36>`，两次独立转换跨毫秒则逐字节失败。已在测试侧归一化挂钟 id 后再比较（`-count=10` 稳定）。
- **smoke fixture 缺口**（前序阶段登记，本轮未做）：external source PATCH/DELETE、token secret reveal、账户 test-options。
- **工作区其它修改不属于本计划**：`jobs/internal/cleanuprepo/*`、`w13*` 覆盖率测试、`accounts/patch.go`、`chat/sse_write.go` 等。未提交、未混入本计划验收结论。
