## 需求目标

基于 CLIProxyAPI 的只读审计，建立 juhe-ai 支持供应商认证方式的安全准入模型。目标不是直接复制订阅账号代理，而是在每种认证已获官方/条款依据后，完成独立账户能力闭环。

交付物包括：认证能力矩阵、长期设计、每种获准认证的账户类型与协议档案、凭据生命周期实现、前后端入口和完整验证记录。

## 方案概述

- 认证建模：每种认证独立声明账户类型、所属供应商、协议档案和上游认证方式。
- 安全：凭据继续应用层加密；OAuth 使用 loopback-only callback、PKCE、state、短会话、账户级刷新去重与日志脱敏。
- 调度：复用账户级失败分类、冷却、健康检测与有界重放，不引入跨分组透明重放。
- 准入：官方文档 / 书面许可、最小 scopes、真实账户 E2E 和撤销验证全部完成前不暴露 UI 入口。
