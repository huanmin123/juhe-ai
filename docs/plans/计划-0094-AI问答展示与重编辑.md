# PLAN-0094 AI 问答展示与重编辑实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为站内 AI 问答实现版本化系统提示、A 极简 Markdown 消息流、重复工具聚合和最近纯文本成功轮次重编辑。

**Architecture:** 系统提示由后端纯函数按实际工具能力生成，同一文本分别注入 Chat Completions `system` 与 Responses `instructions`，并进入上下文预算。最近轮次替换由聊天 repository 在单事务内校验、删除旧轮次并复用序号接受新轮次；前端只维护编辑草稿和视觉投影。工具事件继续完整持久化，前端按规范化动作聚合展示，不篡改真实调用次数。

**Tech Stack:** Node.js 22、TypeScript、SQLite/PostgreSQL database adapter、Express、Vue 3、Tiptap 3、Ant Design Vue、marked、DOMPurify、highlight.js、`@tanstack/vue-virtual`、Browser 插件。

```ts
export const chatSystemInstructionsVersion = 'chat-system-v1'

export function buildChatSystemInstructions(input: { toolsEnabled: boolean }): {
  version: string
  text: string
  hash: string
} {
  const blocks = [instructionPriority, responseDefaults, strictFormats, truthfulness]
  if (input.toolsEnabled) blocks.push(toolDiscipline)
  const text = blocks.join('\n\n')
  return { version: chatSystemInstructionsVersion, text, hash: createHash('sha256').update(text).digest('hex') }
}
```

```ts
export class ChatConflictError extends Error {
  constructor(public readonly code:
    | 'chat_message_in_progress'
    | 'chat_storage_quota_exceeded'
    | 'chat_replace_conflict') {
    super({
      chat_message_in_progress: '当前会话正在生成回答',
```

## 验收标准

- 默认回答遵循轻量 Markdown，用户明确严格格式时不被默认偏好覆盖。
- Chat 与 Responses 只注入一份语义一致、版本可追踪的系统提示。
- 用户和助手无头像、无角色名；用户右侧，助手左侧无边框正文。
- 重复联网搜索保留真实次数但只显示一个可读聚合块，普通用户看不到原始事件 JSON。
- 只有最近纯文本成功轮次可编辑；取消零副作用，重新发送事务替换，冲突保留草稿。
- 前后端回归、类型检查、构建、真实存储、真实模型和桌面/移动 UI 验收均有证据。

## 风险与注意事项

- Hosted Web Search 在上游执行，system prompt 只能降低重复概率，不能在本站执行层去重或追回成本。
- 第一版不编辑图片轮次，不新增图片持久化。
- 系统提示属于站内聊天客户端，不写入 API Key、路由策略、分组、AI 账户或通用网关默认请求。
- 当前开发只改隔离分支，不合并、不推送、不上线，待用户本地验收后再进入发布流程。
