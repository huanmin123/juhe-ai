## 风险边界

- 价格 schema 使用一次性离线迁移，不把旧列兼容或数据回填挂入运行时代码。
- 模型目录缓存必须有容量边界、TTL 和写路径失效；请求链路不得实时扫描模型表或明细 usage。
- 模型可信度 API 只读预聚合结果，检测和请求链路不得现场汇总 observation。
- 跨供应商字段只实现有明确语义的映射；无法证明等价的字段保留原协议或明确拒绝。
