# PLAN-20260726T063803063Z 用户个人信息页面

## 1. 基本信息

- 计划 ID：`PLAN-20260726T063803063Z`

- 执行者：AI / 维护者

## 2. 需求目标

- 新增所有登录用户可访问的 `/profile` 个人信息页面。
- 头像下拉统一为“个人信息、模式切换、退出登录”，移除名称和密码的双弹窗入口。
- 页面展示当前系统账户身份、角色、状态、图像生成权限、说明和关键时间。
- 在页面内完成用户名称 `displayName` 修改和登录密码修改。
- 将初始密码强制修改从应用壳弹窗迁移为可验证的个人信息路由流程。
- 保持 Node、Go、Vue 契约一致，不改变存储 schema。

## 11. 风险与注意事项

- `mustChangePassword` 的 profile 读取必须使用允许初始改密用户通过的认证入口，不能被普通管理中间件提前 403。
- 资料保存和详情加载必须隔离登录用户和请求 generation，避免退出 / 切换用户后的旧响应回写。
- redirect 只能回到站内路径，防止开放重定向。
- 密码字段不得进入缓存、日志、URL 或持久页面状态。
- 用户状态或权限被管理员变更时以后端最新详情和下一次认证检查为准，前端不伪造实时事实。
- 工作区当前已有其他未提交文档和脚本改动；实施时必须继续隔离并保留用户改动。
