## 3. 取证结论（实施依据）

1. `AccountFormSelector.vue` 在全部回归脚本与单测中**零直接引用**；事件名 `select-provider` / `select-type-choice` 无断言。仅重构其模板/交互（保留 props 与事件名）不破坏任何既有自动化。
2. 必须保全的源码锚点（均为 readFileSync + 正则 / sourceBetween 断言）：
   - `account-provider-definitions-lazy-loading-regression.ts:74-87`：`selectProvider`→`selectAccountType` 切片内必须含 `ensureProviderDefinition(providerCode, systemAccountId)` 与 `applyProviderDefinitionDefaultsAfterLoad(`；`openCreate` 不得预载 definition；`AccountsView.vue` 接线顺序 `providerDefinitions,…ensureProviderDefinition,…useAccountEditForm(…)。
   - `account-model-mapping-model-options-regression.ts:126-135`：`function selectProvider[…]?resetForm(providerCode, '')`；`selectProvider`→`selectAccountType` 切片不得含 `loadCurrentProviderModelOptions()`。
   - `account-edit-save-flow-regression.ts:74-92`：`selectAccountTypeChoice(`→`applyCachedDefaultGroup(` 等五切片不得预取 options/group/tag/model。
   - `account-default-group-selection-regression.ts:63-100`：`ensureDefaultGroupSelected`→`openCreate`、`cachedDefaultGroupForProvider`→`openEdit` 切片正则。
   - `account-name-suggestion-regression.ts:65-67`：modal open-watch 默认名逻辑位置。
   - `temporary-unavailable-probe-toggle-regression.ts:34-42`：第 3 步字符串与布局类名。
   - `accountMediaFormBlocks.test.ts:424-499`：AccountMediaForm 段 2/段 3 源码契约与 `<AccountMediaForm` 接线切片。
   - `account-provider-definitions-lazy-loading-regression.ts:47-48`：AccountTableCell `account.providerName || providerName(account.providerCode)` 表达式。
3. 图标资产已就位：品牌 path 与 `LoginView.vue:23-33` 同源（openai/claude/gemini/deepseek/kimi/qwen/doubao/glm）；minimax 取自 simple-icons（单色 currentColor）；xai 取自 x.ai 官网页头（横版 wordmark+mark，viewBox `40 0 2176 831`）。暂存于构建机临时目录，实施时内联进 `providerIcons.ts` 后即弃；**仓库与运行时均不引入外部网络请求或二进制资产**。
4. 主题为静态浅色（`global.css` 单一 `:root` 变量组），无深色适配项。
5. 命令：单测 `pnpm --filter juhe-ai-frontend test:unit`；类型 `pnpm --filter juhe-ai-frontend typecheck`；回归为 `frontend/package.json` 内逐条 `test:*`（tsx）；构建 `pnpm --filter juhe-ai-frontend build`。
