## 范围边界

### 本次包含

- 新增 Anthropic OAuth 授权链接生成与 code 换 token 服务。
- 新增 Anthropic OAuth 创建账户接口与前端账户表单交互。
- 让 Anthropic OAuth 账户支持三种创建方式：站内 OAuth 换码、Refresh Token 创建、直接录入 Access Token。
- 同步更新导入协议、长期设计文档和任务清单。
- 执行类型检查与最小专项回归。

### 本次不包含

- 不接入 Claude 订阅代理、cookie/session、TLS 指纹、浏览器劫持或 sidecar 依赖。
- 不改变当前 Anthropic 网关主转发方式；上游运行时仍使用 `Authorization: Bearer <access_token>`。

## 方案概述

- 后端新增独立 `anthropic-oauth` 模块，结构参考现有 `openai-oauth`，但只保留 Anthropic 需要的最小闭环：`auth-url`、`create-from-code`、`create-from-refresh-token`、`refresh-token` 与重新授权接口。
- 前端把 OAuth 表单抽成供应商可配置模式：OpenAI 继续支持手动回调 URL 与 Refresh Token；Anthropic 新增手动回调 URL、Refresh Token 与直接 Access Token 三种模式。
- 账户保存链路继续统一走 `accounts.type = 'oauth'`，具体校验按供应商协议档案决定。
