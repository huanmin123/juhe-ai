# PLAN-0153 路由级 Node 减法切流

## 基本信息

- 编号：PLAN-0153
- 状态：进行中（设计完成，实施待开始）
- 创建时间：2026-07-22
- 需求来源：Node -> Go 第一轮迁移加速后，按路由开始真正减少 Node 入口
- 执行者：Codex 多 Agent；主 Agent 负责共享文件、冲突、切流与删除裁决

## 需求目标

建立可执行的 method+path 单 owner、双 listener、真实 smoke、原子切流和回滚门禁；先选择低风险纯读路由进行 Pilot，稳定后删除对应 Node 精确入口。Node server、DB service、writer 和 worker 在各自 owner 未完成迁移前继续运行。

长期设计见 [路由级 Node 减法切流与回滚设计](../migration/路由级Node减法切流与回滚设计.md)。

## 范围边界

本计划包含：

- 路由级 owner manifest/validator/allowlist。
- Node/Go 双 loopback listener 的发布与 readiness。
- 从同一声明生成或校验 Caddy/Nginx method+path 配置。
- `GET /__aisys__/api/settings/public` Pilot。
- 首批管理纯读路由的逐条切换、观察、回滚与 Node 精确删除。

本计划不包含：

- 本设计提交直接修改 proxy、删除 Node 或执行生产切流。
- 停止 Node server、DB service、ingest/stats/ops/maintenance worker。
- `/__aipublic__`、gateway、Chat、OAuth writer 或 worker owner 切换。
- 用自动 fallback、双写或长期双实现替代回滚。

## 观察与停止条件

每条路由独立观察。以下任一发生立即回切 Node：Go readiness 非 ready、5xx 或 429 明显偏离基线、权限/脱敏差异、PG/Redis 饱和、Node writer/worker 新鲜度下降、owner 无法证明、相邻 route 被误切。不能依赖 proxy 自动 failover 掩盖问题。

## 验收标准

- route owner 声明是发布、Go allowlist、proxy 和 smoke 的共同事实源。
- Pilot 与第一批每条路由都有真实依赖、真实 listener、ingress owner、观察和回切证据。
- 对应 Node 精确入口已删除，未迁移 route、gateway、writer 和 worker 仍由 Node 单 owner。
- 所有 Go/Node 差异均有业务原因或缺陷修复记录；没有“为了等价而复制 Node 缺陷”。
