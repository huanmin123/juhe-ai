# PLAN-0174：AI 问答命令与生图操作收敛

## 目标

精简 AI 对话输入框的低价值命令，并把生成图片的下载和复制收敛到助手消息底部工具栏，消除图片下方重复状态/下载行和 `attachment://` Markdown 替代文字。

## 决策

- 移除 `/clear-input` 和 `/code`；清空草稿可由编辑器原生选中删除完成，代码块由 Markdown 输入规则或直接粘贴/输入完成，不为低频操作占用命令菜单。
- 命令菜单固定为“命令 + 描述”两列，禁止把命令中文名称另占一列。说明直接交代该动作的范围、效果与必要副作用，避免只重复命令名称。
- 生成图片仍在正文流内显示和灯箱预览，但完成态不再自带“已生成图片 + 下载”独立行。下载按钮属于对应助手消息的底部工具栏，和时间、复制操作保持同一层级。
- 点击含已完成生成图片的助手消息“复制”时，优先获取原图、转换为 PNG 后通过 Clipboard API 写入真实位图；不回退复制 `![...](attachment://...)` 文本。浏览器不支持图片剪贴板或读取失败时显示明确失败提示。
- `attachment://` 图片 Markdown 是内部资产引用，已由结构化 `output_image` 块渲染；Markdown 渲染器忽略它，避免把 alt/书签名称当成正文显示。

## 验收

- 命令菜单不再出现“清空输入”和“代码块”。
- 已完成生成图的下载位于助手消息底部工具栏，图片正文下不再出现下载行或 Markdown alt 文本。
- 复制生成图片时写入图像 ClipboardItem，而不是附件 Markdown 字符串。
- 用户自行进行页面联调；本次不启动本地服务或浏览器自动化。

## 完成记录

- 命令定义、选择处理分支及其回归约束已同步删除 `/clear-input`、`/code`，并将菜单改为“命令 + 描述”两列。
- 描述说明动作的作用与副作用，不再额外展示重复命令名称。
- 页面联调按用户要求自行执行；本次未启动本地服务、浏览器自动化或写入测试数据。
