## 1. 目标与边界

目标是防止 Node 机制在迁移接线时遗忘：把候选、代理、wire、限额、结果、CAS、调度、健康和手动入口逐项映射到 Go，并将 projector、owner handoff、manual bridge、batch/lease parity 的实现与外部门禁分开记录。矩阵中的“通过”仅代表 Node 事实、Go local-pass 或本地 shared golden；没有同一 fixture runtime 输出的条目必须标记 `cross-runtime-unverified`，包括持久化 CAS 行。

本计划不启用 Go owner、不停止 Node 整体服务、不做双写、不访问生产；Node J3a scheduler、executor、projector 和 business writer 已删除，Node 仅保留管理路由/loopback adapter。dev PG smoke 只作为 Go jobs/projector 与现役 Node 管理 CRUD 基础域证据。
