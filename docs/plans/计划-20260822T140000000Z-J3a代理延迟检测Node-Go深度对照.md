## 1. 目标与边界

目标是防止 Node 机制在迁移接线时遗忘：把候选、代理、wire、限额、结果、CAS、调度、健康和手动入口逐项映射到 Go，并把不能在当前范围实现的 projector、owner handoff、manual bridge 固化为后续门禁。

本计划不修改 Node，不启用 Go owner，不停止 Node scheduler，不做双写，不访问生产；dev PG smoke 只作为 jobs/reader 基础域证据。
