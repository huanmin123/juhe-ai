## 目标

- 统一使用美元作为系统结算币种，但保留各供应商独立的计费语义和规则。
- 将 Node 成本计算从通用万能公式调整为供应商策略委派。
- 让模型目录按供应商和模型实际字段生成展示分组，不再固定补齐无意义栏目。
- 只保留 GLM 4.5 及更新系列，避免为单一旧模型生成批量处理和美元换算列。

## 验收重点

- 相同的 `inputTokens` / `cacheReadTokens` 在不同供应商下可以由不同策略解释。
- Anthropic 5m / 1h 写入、Gemini 存储时费、xAI 长上下文和 GLM 单一 Token 价不会被压成同一缓存或输入输出模型。
- 所有最终金额均为 USD，非美元价格能够追溯源币种、汇率和日期。
- 页面不再为没有档位或思考能力的供应商显示“仅标准”“不支持”，也不为没有缓存附加费的模型单独生成空列。
- 使用记录历史成本继续读取请求发生时快照，不随目录或汇率变化。
