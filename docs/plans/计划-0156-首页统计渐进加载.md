## 验收标准

- 首屏只请求 summary，未进入视口的图表端点请求数为 0。
- 三个图表各自只读对应预聚合窗口，不读取 `usage_records`，不经组合 loader 再裁字段。
- 四端点 range 与权限 scope 一致，旧 generation 不会覆盖当前页面。
- 单个图表失败不阻塞 summary 或其他图表，重试不产生重复在途提交。
- SQLite worker、真实 PG smoke、前端行为与浏览器网络证据闭合。

## 风险与注意事项

- PostgreSQL 当前四查询并行不等于页面按需加载，不能据此跳过端点拆分。
- 四窗口可能刷新于不同时间，只保证相同归一化 range，不伪造跨端点事务快照。
- 旧 overview 只作兼容，禁止新调用；不能由新端点调用旧组合 loader 后裁字段。
- 当前工作树已有大量既有改动，禁止整理、回退或提交无关差异。
