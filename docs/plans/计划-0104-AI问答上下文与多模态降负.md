# PLAN-0104 AI 问答上下文与多模态降负

## 基本信息

- 编号：PLAN-0104
- 状态：已完成（含 Prompt Cache 真实命中验证）
- 创建时间：2026-07-13
- 需求来源：用户对长会话、图片 413、上下文计算和上下文窗口交互的生产验收反馈
- 负责人 / 执行者：Codex（隔离分支实现并执行完整自动化、真实模型与 UI 验收）
- 关联模块：AI 问答 / 上下文 / 图片资产 / Responses / Prompt Cache / 账户亲和 / usage / worker / 前端

## 需求目标

- 分离页面渲染历史和真实模型上下文。
- 删除用户上下文窗口选择，始终使用模型最大有效窗口并显示圆形进度。
- 使用主动压缩、结构化记忆和最近原文尾部支持持续长会话。
- 图片通过独立资产上传、缩放压缩和隐藏说明降低请求体与上下文负担。
- 保持供应商可复用的稳定前缀，使用 capability-aware opaque key 和现有网关软亲和降低重复输入成本，并以真实 usage 验证命中。
- 优先移植成熟开源算法，不引入完整 Agent 运行时。

## 范围边界

### 本次包含

- AI 问答独立模型上下文 checkpoint、主动压缩和图片隐藏说明。
- multipart 图片资产、服务端缩放压缩、token / 请求体双预算。
- 模型最大有效窗口和前端只读圆形上下文状态。
- 同一会话 API Key 下的内部压缩 / 图片说明调用、usage、审计和任务监控。
- capability-aware `prompt_cache_key`、Responses canonical prefix、现有网关账户软亲和和 cached / cache write usage 验收。

### 本次不包含

- 延长 7 天页面消息保留期或修改全局原始审计策略。
- 为普通外部客户端自动托管上下文。
- 对象存储、分布式 worker、向量数据库、知识库或跨会话长期记忆。
- 为旧 Data URL 请求、旧 schema 或旧 checkpoint 写运行时兼容分支。
- 在没有独立模型能力字段前自动插入 Anthropic `cache_control` breakpoint，或为 Gemini 创建 explicit cached content；未知 OpenAI-compatible 上游也不接收 OpenAI 专用 key。

## 已确认决策

- `chat_messages` 是 UI 事实源，不因压缩改写。
- 模型上下文使用版本化 checkpoint + suffix，成功后原子切换。
- 图片不再通过聊天 JSON 发送 Data URL；聊天请求只传 `assetId`。
- 图片首轮使用压缩图，后续默认使用隐藏结构化说明；需要重新识图时按资产 ID 再加载。
- token 与最终 JSON 字节分别预算。
- 上游真实 usage / input token count 优先，本地估算只兜底。
- 压缩和图片说明使用会话绑定 API Key 走普通网关，继续计费、审计和遵守路由边界，并以内部 purpose 区分用途。
- 软水位 70%、目标 45%、硬水位 85% 作为初始值，后续按真实数据调整。
- Responses 官方 compact 优先，Chat-only 使用本站结构化摘要 checkpoint。
- 压缩失败继续使用旧 checkpoint，不静默删除历史。
- Prompt Cache 与 checkpoint 分层：前者只优化上游重复前缀成本，后者管理本站有界记忆；key 相同不代表前缀必然命中。
- 首期只为能力明确的目标生成稳定 opaque key；普通追加轮次不改变 key，system/tool/checkpoint/image projection 等前缀变化由供应商自然形成新的冷缓存边界。
- key 复用现有网关 session affinity，但只做软排序；账户不可用时失败回退优先，不硬绑账户。
- Anthropic 显式 breakpoint 等待独立模型能力字段，Gemini 缓存由其供应商驱动另行承接；未知兼容上游不乱发供应商专用字段。
- 缓存是否命中只读取上游明确 usage，不硬编码统一十倍收益、最低 token、TTL 或价格比例。

## 风险与注意事项

- “无限对话”仅代表轮数不被固定历史窗口阻断，不代表模型逐字记住全部历史。
- 图片隐藏说明会损失像素级细节，重新识图入口不可删除。
- 不能把累计计费用量当 active context。
- 不能直接编辑官方 opaque compaction item。
- 不能用提高 body limit 代替资产上传和图片压缩。
- Prompt Cache 不保证固定倍率收益；供应商阈值、TTL、价格、区域和账户隔离都可能变化，必须以模型能力和真实 usage 为准。
- 图片 observation、结构化压缩和 checkpoint / 图片 projection 换代属于合理冷缓存边界；不能复用主会话 key 掩盖不同语义。
- 缓存账户亲和不能升级为硬绑定；成功率和既有失败回退优先。
- 不为旧 schema 写运行时兼容或双读双写；上线时按当前结构单独同步 AI 问答 schema。
