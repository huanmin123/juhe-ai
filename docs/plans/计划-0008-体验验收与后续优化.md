## 需求目标

## 方案概述

- 方案原则：先验收真实页面和已落地链路，再修低风险体验问题；新发现的业务边界、权限、性能或网关问题先报告确认。
- 数据变化：默认不新增核心业务表；如需要索引或查询字段，先记录证据和收益，再确认实施。
- 接口变化：默认不改变已完成的 `/api/my-*` 与管理侧接口边界；如需要服务端补方向筛选或更多分页能力，先列为候选项。
- 前端变化：优先修正文案、空态、移动端卡片一致性和已实现功能的页面验收问题。
- 后端变化：优先处理已确认的稳定性、性能和正式流程回归缺口；涉及 AI 调用必须使用登录、管理 API、分组、API Key、网关请求、用量 / 审计的完整链路。

| 优先级 | 事项 | 原因 | 处理方式 |
| --- | --- | --- | --- |

| P1 | `我的授权` 空态文案仍偏“新增授权”，入站筛选为空时容易误导 | PLAN-0007 已标记为空态待打磨，属于低风险文案修正 | 按方向筛选显示不同中文空态 |
| P1 | 管理端授权页移动筛选仍显示用户侧授权方向 | 桌面筛选已隐藏方向，移动筛选未按 `isManagementView` 隐藏，且管理端不会使用 direction 查询 | 移动端与桌面保持一致，移除无效筛选 |
| P1 | 系统设置页面提交隐藏代理刷新配置 | 表单模型会携带代理刷新间隔和批量大小，但页面没有可见配置项 | 当时补可见配置；后续改为固定后台参数并移出系统设置 |
| P1 | 开发环境 `/api-keys` 前端路由被 Vite `/api` 代理误转发 | 页面验收访问 `/api-keys` 返回后端 `{"message":"Not found"}`，说明 dev proxy 前缀误匹配 | 将 Vite 代理限定为真实 `/api` API 路径，不吞掉 `/api-keys` |
| P2 | 输出系统优化报告 | 用户明确要求“有价值”的优化报告 | 把已完成、值得继续做、需确认和暂不做分层 |
| P1 | `我的授权` 方向筛选后端化 | 用户已要求继续处理 PLAN-0008 下一批事项；用户侧授权列表数量增长后，前端拿全量再筛选存在性能隐患 | 给 `/api/my-authorizations` 增加 `direction` 查询参数，管理端保持不暴露方向筛选语义 |
| P1 | 使用记录详情复制入口和字段展示策略 | 排障时常需要复制 trace、账号、请求摘要、错误摘要；当前仅展示快照，复制成本高 | 增加常用字段和快照复制入口，保持普通用户只看自身记录，管理员全量查看 |
| P1 | 真实 OpenAI OAuth + 代理 smoke 纳入发布前固定清单 | 用户明确要求 AI 账号 / OpenAI / 代理 / 网关验证必须走正规产品流程 | 将登录、管理 API/UI、分组、绑定账户、本地 API Key、`/v1` 网关请求、用量 / 审计、清理写成发布前清单 |
| P1 | `pnpm test:proxy-negative` 纳入发布前固定清单 | 代理负向场景需要和真实 smoke 分开回归，避免停用代理、网关 503 和使用中代理删除问题复发 | 作为代理负向回归，和真实 smoke 并列进入发布前检查 |
| P2 | 普通用户账户表单补充代理帮助文案 | 普通用户能使用代理但看不到代理管理页，容易误解入口缺失 | 仅补文案说明“代理由管理员维护”，不开放代理管理菜单 |

## 优化报告

### 已完成且价值较高

| 方向 | 已完成内容 | 价值 |
| --- | --- | --- |
| 权限边界 | PLAN-0007 已完成用户侧 `/api/my-*` 与管理侧接口拆分，管理员在用户菜单仍按 self scope，管理菜单才看全量 | 避免管理员 / 普通用户混合菜单导致作用域串味 |

| 代理链路 | 代理全局可用、仅管理员管理；真实 OpenAI OAuth + 代理链路和停用代理负向链路已验证 | 避免配置代理后静默直连，也避免普通用户看不到代理管理却不能使用代理 |
| 性能基础 | 使用记录、AI 账户、API Key、账号用量统计已改服务端分页筛选 | 避免数据增长后前端全量加载和本地筛选拖慢页面 |
| 排障体验 | 使用记录详情抽屉、账户代理状态提示、停用代理账户测试错误提示已落地 | 出问题时更容易定位 trace、账号、代理和上游错误 |
| 本轮 UI 修复 | 管理端授权页不再显示用户侧 `我授权出去 / 授权给我` 语义；用户侧授权空态按方向表达 | 菜单和页面表达更贴合“管理员也是用户，但管理页是管理页”的边界 |
| 设置页风险 | 系统设置不再承载 `代理质量刷新` 配置 | 代理刷新策略固定在后台任务中，保存系统设置不会覆盖隐藏字段 |
| 授权筛选 | `/api/my-authorizations` 增加 `direction` 后端筛选，前端不再拉全量后本地按方向过滤 | 授权数据增长后仍能保持用户侧方向筛选的查询边界清晰 |
| 排障复制 | 使用记录详情抽屉补充 Trace ID、排障摘要、请求快照和响应快照复制入口 | 排查网关、账号、模型和上游错误时减少手工拼接信息 |
| 发布验证 | `docs/develop/测试与验证说明.md` 增加发布前固定验证清单，并将 `pnpm test:proxy-negative` 纳入代理负向回归 | 真实 OpenAI / 代理 / 网关链路有固定流程，不再依赖临时记忆 |
| 用户侧代理说明 | 用户侧账户表单补充“代理由管理员统一维护”的帮助文案，管理侧表单不显示该用户语义 | 对齐“代理全局可用，但只有管理员管理代理”的产品边界 |
