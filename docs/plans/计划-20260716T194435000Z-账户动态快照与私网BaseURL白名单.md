## 已确认范围

### AI 账户动态快照

- 正向状态统一显示“可调度”；运行态快照尚未到达或暂不可观测时保持账户静态状态，不暴露“运行态未知”中间态。
- 只刷新当前已加载的最多 100 个账户，不重新加载分页列表，不改变排序、选择或滚动位置；查询字符串上限为 8192 字符，以容纳 100 个真实账户 ID。
- 页面可见时按 `30 秒 +/- 1 秒`递归刷新，页面隐藏、卸载或主列表加载期间停止；旧响应不得覆盖新页面。
- 超级优先、降级备用、启停、重新检查和恢复操作使用更新接口返回值替换当前行，并保留并发、今日用量、最近使用时间、余额和质量动态快照；不得为这些单行操作重新加载整张列表。
- 同一轻量快照更新状态、实时并发、今日用量和最近使用时间。
- 今日用量只读后台已生成的预聚合窗口；禁止扫描使用记录明细。
- 不读取余额、模型、标签、凭据等无关资料。

### 待检查恢复

- 待检查账户保留“用户确认可用后直接恢复参与调度”的能力。
- 前端统一使用现有“恢复正常”操作，不再暴露独立的“人工恢复正常”入口。
- “重新检查”仍保持待检查状态，并由后台健康检查确认后恢复；不得与直接恢复混为同一动作。

### 私网 Base URL

- `JUHE_AI_UPSTREAM_BASE_URL_PRIVATE_ALLOWLIST` 默认未设置或为空，生产部署和发布示例不自动配置。
- 允许部署者显式配置精确 `scheme + IP + effective port` origin；URL 路径不参与匹配。
- `JUHE_AI_ALLOW_PRIVATE_UPSTREAM_BASE_URLS` 仍只用于本地开发和回归测试，生产继续禁止。
- 保存、导入、草稿测试、账户测试、模型检测和网关最终出站复用同一安全策略。
- 上游请求禁止自动重定向逃逸到未放行的私网 origin。
- 本次不支持 CIDR，不开放全局生产私网开关。
