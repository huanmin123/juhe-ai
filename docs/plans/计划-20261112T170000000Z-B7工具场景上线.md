## 1. 上线范围

- 场景类型：`embedding`（向量）、`rerank`（重排）、`moderation`（安全）。
- 对外端点：`POST /v1/embeddings`、`POST /v1/rerank`、`POST /v1/moderations`。
- 供应商：gpt（embeddings、moderations）、qwen（embeddings、DashScope rerank）；Gemini embedding 暂缓，其余厂商无官方端点不开放。
- 账户能力：独立场景账户、独立 Base URL/凭据、`pending_test → active`、J1 周期/激活/冷却恢复/锁死 hold、后台探测开关、人工连通性测试。
- 调度与计费：`utility` lane → `stateless` 调度域；不产生会话亲和；使用模型目录输入 token 单价（moderation 目录价 0）。

## 5. 真实上游验收清单

> 2026-11-12 真实上游实测（workspace `ws-ikwoabqwvldjh3mo.cn-beijing.maas.aliyuncs.com`）：
> - `POST /compatible-mode/v1/embeddings`，`text-embedding-v4`：HTTP 200，返回 1 条 1024 维向量，usage `prompt_tokens=6/total_tokens=6`。
> - `POST /api/v1/services/rerank/text-rerank/text-rerank`，`qwen3.7-text-rerank`：HTTP 200，返回 `output.results` 2 条（含 `index`/`relevance_score`/`document`），usage `prompt_tokens=72/total_tokens=72`；真实上游返回 `prompt_tokens`，网关 `ExtractUsage` 可直接计费，`normalizeRerankUsage` 的 `total_tokens` 兜底不触发。
> - 空输入探针：embeddings `input:[]` 与 rerank 空 query/documents 均返回 HTTP 400 `InvalidParameter`（`input should not be none` / `query should not be empty`），符合 J1「400/422 = Key 可达」判定。
> - 首把 Key 曾返回 `401 invalid_api_key`（workspace 与公共域名一致），换有效 Key 后通过；真实上游验收的鉴权前置已打通，剩余为网关完整链路与 gpt 侧验收。

### 5.1 gpt

- 创建 `embedding` 场景账户：`text-embedding-3-small`（或 large）支持模型；保存后 `pending_test`。
- 人工连通性测试：空 input 得到 2xx 或 400/422；账户转 `active`。
- `POST /v1/embeddings` 正常请求返回 `data[].embedding`，usage 有 `prompt_tokens`，usage/cost 落库。
- 创建 `moderation` 场景账户：`omni-moderation-latest`；`POST /v1/moderations` 返回 `results`；usage 为 0/免费口径。
- 401/403 错误分类为凭据失败；5xx 不错误转 active。

### 5.2 qwen

- 创建 `embedding` 场景账户：`text-embedding-v4`；`POST /v1/embeddings` 走 `/compatible-mode/v1/embeddings`，返回 `data[].embedding`。
- 创建 `rerank` 场景账户：`qwen3.7-text-rerank`；`POST /v1/rerank` 返回 `results[{index,relevance_score,document?}]`，上游 DashScope 报文与响应归一正确。
- rerank usage：响应含 `input_tokens`（由 `total_tokens` 归一），usage/cost 落库不为 NULL。
- Base URL 误配 `/compatible-mode/v1`、`/api/v1`、`/v1` 时，工具出站先剥到 origin，不出现双重版本段。

### 5.3 通用

- 账户列表场景筛选、创建场景选项、模型选择器只显示本场景模型。
- 测试入口只显示连通性测试，不要求模型/协议。
- `/v1/models` 账户并集包含工具模型。
- 安全策略（mask/placeholder）对 embedding input、rerank query/documents、moderation input 生效；工具请求不注入系统提示。
- 调度无会话亲和/组亲和/Key 亲和；失败不派发请求失败健康检查；锁死/特供/时间计划/并发/优先级按共享内核工作。
- 对话/媒体账户既有行为回归通过。
