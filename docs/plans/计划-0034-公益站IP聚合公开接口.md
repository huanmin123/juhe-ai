## 需求目标

- 背景：`juhe-ai-public-welfare` 前端排行榜已先用 mock 对接，后续需要从 `sub2api-lite` 拉取公开数据；已确认 `sub2api-lite` 只提供底层 IP 维度聚合，不做公益站业务快照。
- 目标：复用 `/__aipublic__` 来源系统鉴权和 `juhe_ai_ip_usage:read` scope，提供真实 IP 聚合读取接口、IP 消耗排行便利视图和接入信息接口。
- 交付物：后端公开接口、接入文档目录、回归测试和功能文档更新。

## 方案概述

- 接口统一挂载在 `/__aipublic__`，复用 `requireExternalIntegrationSource(externalIntegrationIpUsageReadScope)`。
- `ip-usage` 只调用 `listClientIpStats`，读取已经 ready 的 `client_ip_usage_range_windows` 和 `client_ip_registry`。
- `consumption-ranking` 是 `ip-usage` 的 TopN 排序包装，不引入新聚合表，也不扫描明细。
- `access-info` 只返回接入边界和可用指标，不返回 API Key、上游账号凭据或公益站业务配置。
- 对测试 token 走 mock 分支，保证公益站后端可以不依赖真实统计数据先验证解析。
