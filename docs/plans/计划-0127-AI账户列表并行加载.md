# 计划-0127 AI 账户列表并行加载

## 基本信息

- 状态：已完成
- 创建时间：2026-07-17
- 需求来源：生产管理端卡顿与页面缓存专题
- 影响范围：AI 账户前端列表加载时序

## 目标

账户 provider / proxy 筛选 options 与主列表并行请求，options 不再阻塞列表首屏。options 失败只显示独立中文错误，不清空已加载列表，不禁用行级操作，也不改变字段、筛选、分页、权限或后端契约。

## 边界

- 保留现有 request signature、作用域和迟到响应拒绝。
- 不移除字段或按钮，不返回假空数据或假零值。
- 本包不拆后端 base DTO；余额独立快照尚未完成前，后端列表继续返回完整真实字段。
- IndexedDB、统一 revision / confirm / outbox 留在页面缓存后续阶段。
