## 需求目标

- 背景：`我的使用记录` 和管理端使用记录当前暴露详情入口、操作列、请求 / 响应快照及日志跳转，不符合普通用户权限和使用记录仅承担列表统计事实展示的产品边界。

- 交付物：Vue 页面与 API 清理、Node / Go 路由清理、回归与性能清单更新、权威文档和验证记录。

## 方案概述

- 方案原则：删除完整能力链，不保留隐藏按钮、死 API、兼容路由或专用竞态代码。
- 数据变化：无 schema 和历史数据变化；保留内部写入与脱敏存储。
- 接口变化：仅保留管理 / 个人使用记录列表，两个按 ID 详情路径返回 404。
- 前端变化：表格无操作列；移动端无详情或日志跳转；traceId 仍可复制。
- 后端变化：Node 和 Go 不再注册详情路由；Go 删除详情 service/store port/query。
