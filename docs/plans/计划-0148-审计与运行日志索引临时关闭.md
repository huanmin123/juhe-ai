# PLAN-0148 审计与运行日志索引临时关闭

## 基本信息

- 状态：本地验证完成，待生产
- 创建时间：2026-07-22
- 需求来源：生产 Node 旁路数据处理放大，用户要求在 Go 迁移前临时关闭原始审计和日志搜索数据库索引
- 执行者：Codex

## 需求目标

- 用部署环境变量临时整体关闭原始审计的新捕获、传输、队列和持久化。
- 临时关闭普通运行日志文件到数据库搜索索引的导入，同时保留正常日志文件、轮转和 grep。
- 功能代码、schema、管理页面、查询接口和重新启用能力保留。
- 发布稳定后清空生产审计数据和运行日志数据库索引数据。

## 范围边界

本次不修改、不关闭、不清理 `usage_records`，也不影响统计、额度、成本和账户质量。操作日志、公开 API 日志、模型检测、网关路由、重试和账号状态同样不在范围内。本轮不改 Pino JSON 文件格式。
