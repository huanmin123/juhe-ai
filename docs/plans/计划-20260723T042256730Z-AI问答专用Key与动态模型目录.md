## 需求目标

- 修复 AI 问答创建新会话后模型下拉为空、无法默认选择的问题。
- 将 AI 问答从旧发布模型快照迁移到当前按 API Key 路由供应商合集动态聚合的目录链路。
- 为每个系统账户提供唯一、可修改策略路由、可识别且不可删除的 AI 对话专用 API Key。

## 风险与注意事项

- 模型目录按路由全部 active 分组供应商聚合，不代表每个模型此刻一定有健康账户；发送时仍由网关最终裁决。
- 专用 Key 被用户停用、过期或改到空绑定路由后，模型为空或发送失败是配置事实，页面不得回退公开目录。
- migration 只增加字段与索引，不生成历史密钥；发布时需先应用 schema，再运行新代码。
