- 独立发布工作树从当前已提交 master 创建，主工作树中的用户未提交改动未被携带或覆盖。

- 用户于本计划执行期间明确改为前向修复策略；旧 Node release 兼容实跑和数据库反向转换已取消，不进入发布产物。
