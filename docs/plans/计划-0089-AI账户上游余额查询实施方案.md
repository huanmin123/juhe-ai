# AI 账户上游余额查询 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为物理单 API Key AI 账户提供可配置的上游余额自动/手动查询，并在账户列表安全展示当前结果。

**Architecture:** 账户业务表保存启用、配置与下次到期时间，`account_usage_snapshots(kind='relay_balance')` 保存唯一当前结果；内置适配器和受限自定义适配器统一返回 decimal string 结果。`ops-worker` 每分钟按业务索引领取到期账户，手动刷新与自动刷新复用 `background_job_leases` 去重，列表只按当前页 ID 批量补齐快照。

**Tech Stack:** Node.js 22、TypeScript、Express、Zod、SQLite/PostgreSQL、Vue 3、Ant Design Vue、现有代理与后台 worker 基础设施。

```ts
assert.equal(firstFailureSnapshot?.consecutiveTransientFailures, 1)
assert.equal(firstFailureSnapshot?.remainingUsd, '7.310000')
```

- [x] **Step 4: 实现错误分类和后台失败状态机**

快照增加可选元数据：

```ts
consecutiveTransientFailures?: number
lastTransientErrorMessage?: string
lastTransientFailureAt?: string
```

余额服务增加 `mode?: 'automatic' | 'manual'`，默认 `automatic`。错误分类规则固定为：超时、网络异常、HTTP `408/429/5xx` 属于 transient；`401/403`、本地凭据/Base URL/自定义配置错误和其他确定性 `4xx` 属于 deterministic。自动 transient 通过旧快照生成 1/3、2/3 或第 3 次 `failed`；deterministic 立即 `failed`；成功快照不复制失败元数据。
