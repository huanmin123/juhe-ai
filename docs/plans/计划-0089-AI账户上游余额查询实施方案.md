# AI 账户上游余额查询 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为物理单 API Key AI 账户提供可配置的上游余额自动/手动查询，并在账户列表安全展示当前结果。

**Architecture:** 账户业务表保存启用、配置与下次到期时间，`account_usage_snapshots(kind='relay_balance')` 保存唯一当前结果；内置适配器和受限自定义适配器统一返回 decimal string 结果。`ops-worker` 每分钟按业务索引领取到期账户，手动刷新与自动刷新复用 `background_job_leases` 去重，列表只按当前页 ID 批量补齐快照。

**Tech Stack:** Node.js 22、TypeScript、Express、Zod、SQLite/PostgreSQL、Vue 3、Ant Design Vue、现有代理与后台 worker 基础设施。
