## 验收标准

- 失败时清空金额并显示“查询失败”，悬浮可见具体原因。
- 自动刷新只处理启用、到期、当前可用的物理单 Key API Key 账户。
- 功能关闭、OAuth、多 Key 池和授权实例不展示、不查询。
- 四类适配器只消费明确查询接口响应，不使用兼容特征或本地数据推算余额。
- 手动刷新使用无边框 `ReloadOutlined` 图标，最长等待 8 秒且不重复并发查询。
- 查询结果不影响账户状态、调度、健康检查和本地用量统计。
- 列表读取无 N+1，后台单轮查询有固定上限和稳定排序。
