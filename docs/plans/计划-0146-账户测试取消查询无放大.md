## 需求目标

- 删除活动账号测试在开始、完成和异常路径上的重复取消状态 DB service 读取。
- 保留 worker IPC + `AbortController` 的即时取消能力。
- 通过 SQLite/PostgreSQL 条件状态转换保证取消不能被完成或失败结果覆盖。
- 在 100 任务并发回归和 `192.168.1.203` 测试 PostgreSQL/Redis 环境中验证，不调整生产连接数或部署生产。

## 方案概述

- 取消接口继续先落库、后发送 worker cancel IPC。
- worker 活动任务只依据本地 `AbortSignal` 立即停止，不再轮询数据库取消状态。
- claim 保持 queued 且未取消的条件写；complete/fail 增加未取消条件写。
- 条件写未命中时，仅在 repository 内部处理稀有取消竞态，正常任务不增加 DB service 往返。
- 现有 `is_account_test_task_cancel_requested` operation 可保留给诊断或兼容调用，但账号测试队列不得调用。
