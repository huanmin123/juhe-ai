# PLAN-20260715T101708000Z 模型目录校准与自定义模型配置复制

## 1. 目标

- 修复模型目录把总上下文、最大输入和最大输出混用的问题。
- 修正 2026-07-15 仍可由厂商官方资料确认的目录、生命周期和计价错误。
- 重做管理员与普通用户共用的自定义模型创建流程。
- 将“价格模板”改为“配置模板”，其语义是选择当前供应商的已有模型并复制配置，不新增模板实体、不保存模板引用。

## 2. 已确认设计

### 2.1 配置复制

- 新建表单顶部展示“配置模板”，候选只来自当前供应商、当前用途下对操作者可见的已有模型。
- 选择已有模型后复制：用途、接口协议、服务等级、思考级别、总上下文、最大输入、最大输出和完整价格配置。
- 不复制模型 ID、发布时间、停用时间、作用域和状态。
- 保存后只保存复制结果；源模型后续变化不会自动改写已创建模型。
- 不创建模板表、模板管理 API、模板版本或长期引用关系。

### 2.2 权限

- 管理员和普通用户使用同一个表单与同一个创建契约。
- 管理员额外拥有作用域、目标系统账户和直接改价权限。
- 本条历史限制已于 2026-07-16 按最新需求调整：普通用户可提交并维护自己个人自定义模型的价格；服务端仍严格限制所有者和作用域。
- 服务端只接受当前供应商目录中对操作者可见且启用的配置模板；OpenAI 聚合与 Hybrid 可复制其目录内的来源供应商模型。
- 配置模板是推荐的创建基线而非强制项；没有合适模板时，管理员仍可完整手工配置，普通用户只能在价格完整性规则允许的状态下保存。

### 2.3 供应商差异

- 用途、协议、服务等级和思考级别从当前供应商已有目录生成，不维护第二套前端硬编码供应商矩阵。
- 当前供应商没有某项能力时隐藏对应字段。
- 服务等级和思考级别使用确定选项，不再允许 `tags` 任意输入。
- 删除自定义模型表单中的“默认思考级别”。

### 2.4 目录字段

- `contextWindowTokens`：总上下文窗口。
- `maxInputTokens`：厂商明确公布的最大输入；未公布时保持空值，不通过总上下文减最大输出推导。
- `maxOutputTokens`：最大输出。
- 前端分别展示三项，不再以 `maxInputTokens` 冒充“上下文”。

## 3. 本轮目录校准范围

官方资料核验日期固定为 2026-07-15：

- OpenAI：补齐 GPT-5.x 已确认的总上下文与最大输入，校准 Flex / Priority 价格和长上下文倍率。
- Gemini：关闭已到期模型，修正已确认的 Embedding 价格与 Pro 长上下文阶梯。
- DeepSeek：移除官方 List Models 不存在的公开重复 ID，并拆分 1M 总上下文语义。
- GLM：修正官方模型总览可确认的上下文和最大输出。
- Anthropic：仅纳入官方 Models / List Models 可确认的直连模型；兼容网关别名必须保持隐藏。

无法由厂商官方页面确认的字段保持空值，不使用第三方价格表或模型名推断补齐。
