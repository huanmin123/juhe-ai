# PLAN-0093 AI 问答编辑器与模型工具实施计划

> **执行要求：** 在隔离分支内按 TDD 顺序逐项实现，每项通过定向回归后提交；完成后执行 Mock、真实模型和 Browser UI 验收。

**目标：** 使用 Tiptap 3 落地可扩展 AIComposer，修复消息方向与发送清空，并让 AI 问答按模型能力接入 Responses 原生工具事件。

**架构：** 编辑器只维护输入文档和附件预览，输出统一内容块；聊天 transport 根据服务端返回的协议能力选择 Chat Completions 或 Responses。模型原生工具由上游执行，本站只透传、解析和展示；未注册本地工具明确失败。

**技术栈：** Vue 3、TypeScript、Tiptap 3 / ProseMirror、OpenAI Chat Completions、OpenAI Responses SSE、现有 Node 网关、Browser 插件。

---

## 文件边界

- `frontend/src/views/chat/composer/AIComposer.vue`：编辑器 UI、快捷键、发送/恢复、工具栏。
- `frontend/src/views/chat/composer/chatComposerDocument.ts`：Tiptap JSON 到聊天内容块的纯函数转换。
- `frontend/src/views/chat/composer/ChatImageAttachment.ts`：受限图片预览节点，不负责上传。
- `frontend/src/views/chat/composer/chatComposerCommands.ts`：`/` 命令定义和过滤。
- `frontend/src/views/chat/ChatMessageList.vue`：用户右侧、AI 左侧和工具事件展示。
- `backend/src/modules/chat/chat-responses-sse.ts`：Responses SSE 增量解析，不访问存储。
- `backend/src/modules/chat/chat-transport.ts`：协议选择、请求构造和统一流事件。
- `backend/src/storage/chat.repository.ts`：内容块与工具事件的有界持久化。

## 验收标准

- 用户消息右侧，AI 和工具事件左侧。
- Enter 发送立即清空；Shift+Enter 换行；失败恢复原草稿；IME 不误发送。
- 编辑器支持撤销/重做、Markdown 结构、图片粘贴预览和 `/` 命令。
- Chat Completions 账户行为不回退；Responses 账户可展示模型原生工具事件。
- 本站不执行未注册本地工具，不绕过网关、代理、额度、审计或使用记录。
- Mock、类型检查、构建、真实模型和 Browser UI 验收通过。
