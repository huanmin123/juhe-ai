## 范围边界

### 确认后实施

- Node 将 AI 性能 overview 拆为默认最多 10 个账户的 base 和按 `accountIds` 返回可见追加账户的 series。
- 为 base/series 增加独立 DTO、repository、缓存 domain、SQLite read-worker operation 和 PostgreSQL 路径。
- Vue 首屏只读 base，新增账户仅补 series，并实现 scope/range/ID/generation 合并与局部错误。
- AI/IP 改用按身份和 admin/self 隔离的 usage-window singleflight/短缓存；首次隐式范围必须由服务端窗口锚定。
- 表监控 database history 改用专用窄 row/DTO/worker/API/前端类型，保留视口加载和现有图表语义。
- 补齐 HTTP、query guard、worker、真实 PG、前端请求矩阵、时区和竞态测试，并修复发现的测试夹具漂移。

## 已确认的设计候选

- AI base：保留现有管理/个人 `/ai-performance` 路径，但只接受 scope/range，旧 `accountIds` 返回 400；响应为 `range + summary + 默认 accounts(<=10) + 默认 hourlySeries`。
- AI series：新增管理/个人 `/ai-performance/series`，要求 1..20 个重复裸键 `accountIds`，返回 `range + 可见 accounts + hourlySeries`，不可见/不存在 ID 静默省略。
- 前端：首屏不请求 series；搜索新增仅补缺失 ID，删除不请求，日期/owner/身份变化后按新范围重载 base 和仍需的追加 IDs。
- usage-window：admin/self + 用户 + 角色 + auth revision 隔离，精确 singleflight、约 60 秒短缓存；AI/IP 页面加载不再传 `force`。
- 首次时区：没有显式日期时，AI 三日与 IP 快捷范围必须等待真实服务端窗口；浏览器 fallback 不得驱动首个业务请求。
- table history：严格 `databaseRole/sampledAt/fileBytes/walBytes/freeBytes/tableCount` 六字段，SQL 和 mapper 不读取 `shmBytes` 或其他宽快照列；history 使用专用主库加 WAL 计算，不复用 overview 宽 helper。
- 预聚合：AI 仅读排行/小时/摘要窗口，IP 仅读现有 IP 窗口，table history 仅读数据库快照；禁止请求时扫描明细或实时采样降级。

## 测试项

- AI parser/HTTP：base 无追加 IDs；series 重复裸键/bracket、去重、1/20/21、非法形状和范围。
- AI DTO/query：base 最多 10、series 只返请求可见项、无重复 summary/rank、无 overview 裁剪、无 N+1/明细扫描。
- 权限：管理全局/owner、个人 self、自有/授权/授权分组、撤销授权、伪造 scope、不可见/不存在省略。
- 窗口：admin/self/身份 revision 隔离、singleflight、TTL、失败不伪装服务端成功、AI/IP 首次跨时区日界。
- 表 history：精确六字段、窄 SQL/mapper、每角色 limit、稳定排序、主库加 WAL 曲线与 tooltip 不变。
- 存储：SQLite 同步/read worker 与真实 PostgreSQL 逐字段等价；PG SKIP 不计通过。
- 前端：首屏请求矩阵、新增/删除/重置、日期/owner 切换、A→B→A、迟到成功/失败、卸载、局部重试。
- fixture：旧 overview、账户/profile、统计窗口和快照 fixture 对齐当前生产构造；不得放宽生产约束掩盖漂移。
- 回归：AI options/小时图、IP list/detail、usage-window、table overview/history 和 page-data revision 不退化。

## 验收标准

- AI 首屏最多返回并渲染默认 10 个账户；增加账户不重取 base，只按 ID 请求 series。
- AI series 对不可见 ID 静默省略，管理/个人统计作用域与摘要口径保持不变。
- AI/IP 普通加载、筛选、分页、排序和刷新不再强制请求 usage-window；缓存未过期时窗口网络请求为 0。
- 首次隐式日期范围有服务端时区窗口作为证据，窗口失败时不按浏览器本地日界误发业务请求。
- table history 从 SQL 到 Vue 严格只传六字段，同时主库加 WAL 曲线、空闲和表数 tooltip 与专用 history 口径一致。
- 三类页面均不退化到明细扫描、实时聚合或实时数据库采样。
- SQLite worker、真实 PostgreSQL、前端竞态、浏览器请求矩阵、fixture 和独立复核全部闭合。

## 风险与注意事项

- base DTO 删除 `defaultAccounts/selectedAccounts` 是显式契约变更，必须同步所有 Node/Vue 类型和回归，不能保留宽数组只为少改代码。
- series 的可见省略会使请求数与响应数不同，前端必须按 ID 合并，不能依赖数组位置补占位。
- usage-window 的浏览器 fallback 不能被误认为服务端统计日界；错误状态必须可见并可重试。
- history 不返回 `shmBytes`，前端不能再复用 overview 的 `totalDatabaseBytes`；`tableCount` 参与 tooltip，不能从六字段投影删除。
- fixture 修复必须证明是旧假设漂移，不能用测试修改掩盖真实权限、SQL 或时区回归。
- 当前工作树已有大量既有改动，禁止整理、回退或提交无关差异。
