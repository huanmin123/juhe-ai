## 风险与注意事项

1. **外部 API 形态漂移**：协议契约按置信度分级（契约文档 §1）；C 级条目（xai/glm 端点、三家国内厂商语音细节）**接入前必须以官方文档回填，回填前不得实现 adapter**；Mock 上游场景字段只允许引用契约文档，不得在测试代码私造。
2. **Mock 基建是 M1 第一交付物**：先有 Mock 再写链路（`mockupstream` 端点/异步任务状态机/二进制载荷三项均为新增机制）；E2E 验收不依赖真实账户。
3. **异步任务是网关架构新增面**：现有链路是"一次真实上游请求"同步模型；`media_jobs` + 账户亲和 + 轮询驱动终态是新形态，M2 实施前需独立复审数据流与并发（多网关实例并发轮询同一行、状态机竞态）。
4. **读链两份同源实现**（`providers/catalog.go` 与 `chain_catalog.go`）必须同批修改，防止管理面与 `/v1` 目录口径漂移。
5. **不做开关**：媒体能力按期交付即默认生效，不引入 feature flag；超时/并发等档位为系统设置（诊断/调参性质），非功能开关。
6. **文档同步是完成条件**：各期交付未同步设计文档 §11.13 清单不得宣称完成。
7. 敏感性：厂商 API Key 等凭据只存加密凭据面，测试产物脱敏；零存储原则违反即 blocker。
