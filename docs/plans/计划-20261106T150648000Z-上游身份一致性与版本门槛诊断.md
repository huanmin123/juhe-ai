## 1. 目标

1. **dateline 隐写清洗**：补上透传路线自身的信号泄漏。行为契约见 [Anthropic透传dateline隐写清洗设计](../functions/Anthropic透传dateline隐写清洗设计.md)。
2. **请求内身份原子快照**：同一次上游请求的全部身份字段必须派生自同一次三层合并读取，杜绝 gateway 60s 热刷新切换瞬间 UA 与 body 版本字段自相矛盾（上游可判非正版）。契约登记于《上游客户端身份版本覆盖》§请求内身份快照。
3. **版本门槛诊断归类与跟版失败可见性**：网关链上游 426 归类为诊断 reason class `version_gate`（纯状态码判定、零文案解析，遵循《客户端版本自动跟版设计》§8.3 既有裁决）；跟版任务部分源失败的可见性从 Info 升 Warn。只做诊断面，不驱动账户状态变更（《AI账户错误语义与状态变更边界》§2/§6 边界）。
