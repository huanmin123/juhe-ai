## 范围边界

### 本计划包含

- 品牌公开设置会话内 loaded cache、singleflight、失败重试和管理保存后缓存同步。
- login/change-password 收窄为现有 `CurrentUserSummary`。
- 删除 Chat API Key 无调用 GET、Vue method 和 type，保留聊天默认 Key 内部链路。
- 公告 create/update/publish/unpublish 轻响应。
- 删除团队/用户授权用量页无调用聚合 options loader。
- 注册已存在的外部来源轻量 HTTP 回归；删除无调用 Vue `updateToken`，保留 Node token PATCH。

### 本计划不包含

- 不改 Go、schema、会话存储、授权统计口径、聊天路由策略或外部来源权限模型。
- 不删除 Node 外部来源 token PATCH；当前只能证明 Vue wrapper 无调用，不能证明后端 HTTP 无仓库外调用方。
- 不在本计划拆授权用量 rows/summary DTO，不做系统设置 section 拆分。
- 不提交、不推送、不部署、不操作生产。

## 验收标准

- 五个阶段各有明确用户确认、代码 diff、专项命令、回归证据和独立复核结论。
- 品牌在同一页面生命期不重复请求，失败可重试，管理保存后不回填旧 cache。
- login/change-password 与 me/update-profile 使用同一 `CurrentUserSummary`，真实 HTTP 无多余账户字段。
- Chat 死 GET 及其前端契约删除，聊天默认 Key 主流程不退化。
- 公告写操作只返回轻响应，操作日志、公开变更通知和页面刷新结果正确。
- 授权用量死 loader 删除，下拉仍是按首次交互加载，admin/self 范围不变。
- 外部来源轻量 HTTP 回归已纳入命令门禁，Vue `updateToken` 删除而 Node PATCH 继续可用。
- Node/Vue 必要门禁通过，Go 未触碰，未提交、未部署、未操作生产。

## 风险与注意事项

- TypeScript 已把 login/change-password 声明为 `CurrentUserSummary` 不等于后端契约已收窄；必须验证真实 JSON 字段集。
- 删除仓库内无调用的 HTTP 仍可影响仓库外客户端，因此 Chat GET 必须明确确认；Node 外部来源 PATCH 则因证据不足而保留。
- 品牌 cache 必须处理管理员写后同步，否则请求减少会引入当前会话品牌陈旧。
- 公告轻响应不得减少服务端操作日志和 public change 所需的完整对象。
- 当前工作树已有大量既有改动，实施与回滚只限本计划文件，不整理、覆盖或提交无关差异。
