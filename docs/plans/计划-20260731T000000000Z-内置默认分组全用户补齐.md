# 内置默认分组全用户补齐计划

- 目标：让默认数据初始化和 PostgreSQL xAI 升级迁移为每个系统账户幂等补齐缺失的内置默认分组。
- 范围：SQLite/Node 与 PostgreSQL 默认 seed、xAI 专项升级迁移、默认分组回归和相关存储/xAI 文档。
- 非目标：前端、缓存、登录流程、默认路由/API Key，以及历史路由/API Key 的补齐。
- 实现：保留已有默认分组；仅在 `sys_admin` 静态 ID 行缺失默认标记时恢复其 `is_default`，其他系统账户仅在同一供应商没有默认分组时批量插入缺失分组；名称冲突按大小写无关判断，同名自定义分组保留，并用携带系统账户 ID 的系统默认后缀名称避免冲突。
- 验收：历史普通账户在 seed 后具有全部 `DEFAULT_BUILT_IN_GROUPS`，包括启用的 xAI 默认分组；PostgreSQL 升级迁移只补 xAI；新增系统账户行为不变。
- 验证：`test:default-group-current-contract`、`test:postgres-seed-defaults`、`test:user-reference-data`、`typecheck`。
- 状态：已完成。
