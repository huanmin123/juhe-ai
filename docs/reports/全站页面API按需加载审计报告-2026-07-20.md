# 全站页面 API 按需加载审计报告（2026-07-20）

## 1. 结论

- 本轮已完成六个页面域、约 30 个实际路由页面的静态调用链审计。结论不是“所有接口都要复用一个轻量 Summary”，而是按页面和功能定义小而快的 API：列表只返回首屏真实列，下拉默认只返回 `id/name`，统计与运行态使用批量快照异步补充，详情、大数组、原始正文、能力矩阵和敏感信息在用户触发后按 ID 获取。
- 本轮审计基线识别出的 P0 问题集中在：AI 账户列表 9 类附加读取、账号测试模型打开即加载、聊天模型能力首屏加载、系统指标 2.5 秒运行态链路、用量统计整页趋势、审计日志宽列表与运行态伴随请求、授权列表“完整组装后再丢字段”、授权目标分组复用宽 DTO。2026-07-21 已完成第一批高成本路径的整合验证，具体范围见 1.1；未列入收口范围的 P1/P2 项仍按后文状态继续推进。

## 4. 统一目标契约

| 场景 | 默认返回 | 禁止行为 | 按需补充方式 |
| --- | --- | --- | --- |
| 下拉 / 搜索 | `id`、`name`；确需禁用态时增加最小 `disabled` / `disabledReason` | 复用完整 Summary、Definition、成员、调度、授权、统计、模型能力数组 | `keyword + limit + selectedIds`；按供应商或用途限定；详情按 ID 获取 |
| 列表首屏 | 当前桌面表格与移动卡片真实可见列、筛选状态、必要操作权限 | `SELECT *` 后裁剪；附带完整详情、大 JSON、成员、规则、payload、完整趋势 | 次要统计和运行态通过 `snapshot?ids=` 异步批量补充 |
| 详情 / 编辑 | 用户打开后请求基础详情 | 为复用把高级配置和秘密塞入列表 | 高级 section、规则、映射、成员、正文、能力矩阵分别按展开或点击加载 |
| 统计 / 趋势 | worker 预聚合 summary / window | 请求链扫描明细、为未展示账户返回完整序列 | 摘要先返回，趋势按可见图表与已选 ID 请求 |
| 运行态 | 页面真正需要的轻告警或状态摘要 | 每次翻页伴随完整 runtime、IPC、Redis 队列与 worker 状态 | 首屏后异步；完整运行态进入独立面板或主动刷新 |
| 敏感 / 原始内容 | 列表只返回存在性、掩码或摘要 | secret、完整 token、原始 payload 进入列表缓存 | 独立鉴权、`no-store`、操作日志、分块或窗口读取 |

后端必须从 SELECT / repository 开始按 DTO 投影。禁止“查询完整对象、做全部关联、解密凭据、构造 Summary，最后 route 再删除字段”。

| 回归 | 页面真实可见列、操作禁用、已选 label 补齐、授权范围、移动端卡片、刷新/缓存失效均保持正确 | 前后端专项回归、typecheck、build、浏览器网络与中文 UI 验收 |
| 资源边界 | 大正文、日志、消息、历史趋势使用 cursor/offset/window；无自动全量循环、无无界并发 | 分块边界测试、大 payload fixture、取消与超时测试 |

### 7.1 账号测试专项验收

- 打开测试弹窗时，模型列表请求次数为 0；默认模型等于当前账户检查模型，默认请求形态等于当前账户检查请求形态。
- 首次展开模型下拉后，`test-options` 请求次数为 1，列表项严格为 `id/name`；再次展开命中当前缓存或 singleflight。
- 选择不同模型后只按该 model ID 获取能力；特殊字符编码、模型不存在、无可用请求形态、管理/个人权限镜像均有真实 HTTP 测试。
- POST 测试不信任前端缓存，后端重新校验模型、请求形态和账户能力。

### 7.2 全页面浏览器验收

- 为本报告每一行记录页面导航后的网络请求清单，明确“首屏必需、首屏异步、交互触发、禁止出现”。
- 首屏不出现未展开下拉的 options、未打开详情的 detail、完整正文、完整模型能力、完整 runtime 或非可见图表的历史序列。
- 重接口异步补充时，主列表和主要操作先可交互；补充接口失败有独立中文错误，不清空已经加载的主数据。

## 8. 边界与未验证项

- 本轮是本地静态审计，没有请求生产地址、没有执行生产写操作、没有采集生产 payload，也没有进行 PostgreSQL / Redis 真实依赖压测。
- 行号对应 2026-07-20 共享工作树；并行修改可能使后续行号漂移，权威证据应以最终 diff 和回归输出为准。
- 路由入口已逐项枚举，但本报告对各页首屏和主要交互链路做了优先级审计，不等同于已经穷尽所有非首屏操作接口。AI 账户的导入预览/确认、余额刷新与草稿测试、API Key runtime、流量迁移、批量编辑和代理测试等交互端点仍需在实现阶段补入接口矩阵与契约回归。
- 表格中的“实现中，待验证”是 2026-07-20 审计时点状态；已列入 1.1 的项目已完成本地整合回归，未列入的项目仍不得视为完成。全页面浏览器请求矩阵和真实依赖压测尚未执行。
- 本报告不要求把所有 API 机械改成相同格式。`id/name` 是默认下拉契约；只有页面真实需要且能证明用途时，才增加少量状态、协议或禁用原因字段。
- 统计、额度、趋势和 TopN 仍必须来自 worker 预聚合表或窗口表；接口拆小不能把统计计算转移到前端或请求链实时扫描明细。
