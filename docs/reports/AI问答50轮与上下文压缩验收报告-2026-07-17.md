## 8. 图片与 UI 验收

本节来自独立浏览器 + 开发 SQLite 证据链，不是 50 轮 JSON 字段。

### 8.1 图片链路

- 浏览器粘贴源图：3000x2000 PNG。
- 前端 Compressor.js 上传结果：1024x682 JPEG、4,888 bytes。
- 后端 Sharp 处理结果：1024x682 JPEG、2,390 bytes。
- 页面与持久化消息保持“文字 -> 图片 -> 文字”顺序，聊天 JSON 只携带 `assetId`。
- 一次聚焦后连续粘贴 6 张图，编辑器只保留 5 张并显示中文上限提示；切换会话后数据库未提交资产计数回到 0。
- 后端并发集成测试验证合法第 5 张成功、第 6 张在读取大正文前拒绝，reservation、临时文件和账本最终收口。

### 8.2 交互与响应式

- Enter 发送后输入框立即清空；用户消息位于右侧、助手位于左侧，无角色头像或“我”标签。
- AI 消息底部显示时间和复制按钮；复制调用只读取最终 `contentText`，不包含 reasoning 或工具事件。受控浏览器剪贴板隔离不作为正向复制证据，Clipboard API + 选区降级由自动回归覆盖。
- 发送图片后立即切换“统计概览”再返回，生成仍继续并最终显示“收到。”。
- 会话抽屉可打开，移动端“更多”菜单含重命名、置顶、详情和删除；详情展示完整会话 ID。
- `390x844`、`360x800` 和 `390x420` 三个视口中，消息区保持可滚动，输入区和底栏可见，模型/思考/服务控件、上下文圆环和发送按钮无重叠。
- 浏览器额外发现统计页把 `undefined` 传给 `a-segmented` 的 Vue 告警；修为 `quickRangeValue ?? ''` 后，新页签跨菜单 error/warn 为 `[]`，记录见 BUG-0114。
