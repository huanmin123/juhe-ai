## 首轮失败与根因

首轮 required smoke 已连通 PgBouncer，并完成 `IssueInput` 与 proxy lease，但在 `AdmitExecution` 返回 `ErrInputFence`，因此当时不能宣称通过。

根因是 PostgreSQL schema 将 `payload` 定义为 `JSONB`：写入路径对 Go `json.Marshal` 的原始字节计算 `payload_digest`，读回路径却直接对 PostgreSQL 返回的 JSONB 字节计算 digest。JSONB 允许重排对象键，读回字节不再保证与写入字节相同，导致合法输入被错误判定为 fence 不匹配。

修复后：

1. 对读回的 `IssuedInput`/`Outcome` 先完成 JSON 解码与结构校验，再按类型重新 `json.Marshal` 计算 canonical digest。
2. SQLite 继续校验原始 payload 字节，保留已有 poisoned payload 回归语义。
3. 增加 JSONB 键顺序变化仍保持 digest 一致的单测，避免把 JSONB 误当作 byte-preserving 存储。
