# 全链路真实 AI 业务场景验收报告（2026-09-18）

## 1. 结论

- 全链路真实 AI 业务场景验收**通过**，达到「路由 → 分组 → 账户 → 网关链 → 用量/审计」在上线前的最低验收标准：mock 矩阵 0 skip / 0 fail，真号 + 真实客户端门 100% 全绿。
- 适用版本：Go 后端 `backend-go`（gateway/jobs/maintenance 三项目，Node 后端已归档）；本报告只对提交 `377f0c74a`～`0267064c5`（含 F9–F13 缺陷修复）所在基线有效。
- 上游错误瞬态规则以**供应商级**落地（gpt 过载/限流），OpenAI 官方直连 `server_error` 亦覆盖；规则匹配基于错误描述关键词，后续上游服务若保留原生 `type` 字段可切换到更抗文案变化的匹配。

## 2. 范围

- 测试对象：真实 `juhe-ai-gateway` 二进制 + SQLite 六库临时目录；生产账户只读导入；真实 CLI 客户端（codex / claude / opencode）出网调用。
- 覆盖链路：管理面配置（API Key → 路由策略 → 分组 → AI 账户）→ `/v1` 网关链（5 种路由模式、切号语义、账户状态机、高并发分组、多 Key 池、协议转换）→ 用量/审计归因。
- 不覆盖内容：页面交互 UI 测试（维持既有约定）；压测/性能验收（另有专项）；生产写操作（生产侧全程只读）。

## 5. 观察

- **本轮修复的真实缺陷 F9–F13**（详见计划文档 §5.4）：F9 anthropic 流式缺终止事件误判；F10 成功审计采样率恒 0 致归因空；F11 审计 body JSON 桥 `json:"-"` 丢弃；F12 失败 usage 归因口径修正（`account_upstream`，非缺陷）；F13 两层高并发队列缺失与槽位不释放（`ConcurrencyTracker` 未接线 + 成功路径不 `ReleaseConcurrency`）。
- **开放项已收口**（计划 §5.5）：smoke fixture 缺口、R6 hybrid_smart、G3 tier 序、策略创建 400 可观测性均已补并 PASS。
- **仍开放观察项（不阻断验收门）**：
  1. R5 FINDING #4：speed-first 同请求切号走 latency 重排触发，未在 degrade 观察上触发（测试 PASS）；有人并行补强 R5 元数据断言。
  2. 上下文超限的中转改写形态可后补 `errorMessageIncludes` 匹配（影响小）。
  3. Anthropic / Gemini 的中转包装形态待遇到实际样本按 gpt 供应商级规则模式补。
  4. 流式路径的首字截止 cutover 补齐（B2 保留项）尚未接线，保持不激活。
- **环境噪声**：openai 池候选上游中转偶发 503 与慢头、gpt 流式偶发零字节——套件按 provider 依次尝试 + 流式重试加固，网关侧行为正确（重试 → 耗尽 → 503 统一消息）。

## 6. 边界

- 本报告证明的是**功能与契约符合预期**，非性能/容量结论（性能另见 `docs/reports/` 压测专项）。
- 上游错误关键词匹配规则依赖上游错误文案稳定；若上游服务保留原生 `type` 字段，网关规则可切换到原生字段匹配（需上游改造，属跨仓库用户基建）。
- 生产侧全程只读验证；生产部署变更仍须走 GitOps。
- 本计划相关源码落点（验收套件 + 缺陷修复文件）已随 377f0c74a～0267064c5 提交；工作区其余未提交改动属其他并行会话，不在本报告范围。
