## 2. 方法与证据标准

- 每个候选问题由第一轮取证代理给出 Node/Go 双侧 file:line 证据；第二轮由不同档位的独立复核代理**只拿候选项、重新从源码推导**，允许推翻；两侧结论一致才定案（CONFIRMED/PARTIAL/REFUTED）。
- 修复仅针对双重确证、修复方案明确、不与另一审计线在途文件（authz/team_cascade.go、systemteams/*）冲突的项；修复后由未参与写入的终审代理对全部 diff 独立复审（7/7 PASS）。
- 未验证项如实保留：真实 PostgreSQL/Redis 运行时行为、statsagg 聚合 SQL 逐行等价、oauthrefresh 加密 golden 复现、Node 实跑脱敏样例比对等均未执行，相关结论仅基于静态源码与现有测试。
