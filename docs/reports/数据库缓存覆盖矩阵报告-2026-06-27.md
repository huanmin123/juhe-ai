### 6.25 剩余本地缓存复核结论

| 缓存 | 结论 |
| --- | --- |
| `sessionAffinityCache` / `trafficMigrationPreferenceCache` | 暂不迁 Redis。它们参与每次账号排序，当前是同步 O(1) 调度状态；直接改 Redis 会给普通网关请求增加网络 IO。后续如要跨 server 共享，应单独设计异步预热或 runtime state 方案并压测。 |
| `clientIpErrorCircuitCache` / `preAuthCache` | 暂不迁 Redis。认证前和请求错误熔断在请求早期同步执行，Redis 往返会放大异常流量下的延迟和 Redis 压力。更适合保留本地保护，再通过网关前置限流 / WAF 解决跨节点攻击面。 |
| `clientIpAccountAvoidanceCache` | 暂不迁 Redis。该状态包含账号失败原因、账号名和 IP 维度短期规避结果，调度路径同步读取；跨节点收益低于每请求 Redis 成本。 |
| `hybridRouteAffinityBindings` | 暂不迁 Redis。混合路由评分结果已共享；亲和状态仍是每次 hybrid 路由的同步决策，继续保留本地，避免在评分缓存命中后又引入 Redis 往返。 |
| `gatewaySettingsCache` | 已补 Redis shared cache。网关设置只包含请求体上限、超时、熔断和错误策略数字 / 布尔字段，不含上游凭据；server 异步读取按本地 LRU -> Redis shared cache -> DB service 读取，DB 命中后回填两层缓存。 |
| `providerModelRouteIndexCache` | 已补 Redis shared cache。缓存值是 `modelKey -> providerCodes` 路由索引，不含上游凭据；本地 miss 后读取 Redis，Redis miss 才基于模型目录构建索引。 |
| `gatewayRuntimeCache` / `openAIAccountsCache` | 暂不迁 Redis。缓存值包含上游账号 credentials / OAuth token / proxy 等敏感运行态，不能直接写 shared cache。当前只共享不含凭据的 API Key 校验、网关设置、分组访问、模型目录、模型路由索引和响应检查策略。 |
| `proxyAgents` | 必须保留本地。缓存对象是 `http.Agent` 实例，不是 JSON 数据，不能 Redis 化。 |
| `recentRefreshByAccountId`、`codexTurnRetryCache`、`proxy-health` 短状态 | 暂不迁 Redis。均属于短期恢复、重试或本进程连接健康状态；没有真实积压或跨节点错误扩散证据前，继续改会偏负优化。 |

补充判断：当前缓存侧已接近本轮最大收益。继续优化应转向真实慢 SQL、真实队列积压、PG explain 门禁缺口或长周期压测暴露的问题，不再为了“所有 `createAppCache` 都 Redis 化”而迁移同步热路径状态。

## 8. 建议顺序

1. 先不要盲目优化已经通过的网关主链路，继续补短板。
2. 建立 PG explain / query guard 清单，优先覆盖统计页、审计页、日志页、账号列表、授权列表、API Key 列表。
3. 把高价值 `createAppCache` 调用点分级：API Key 校验、额度、授权、系统设置、网关设置、网关分组访问元数据、分组绑定账号 ID、授权统计与授权来源 lookup、网关模型目录、模型路由索引、管理端模型目录、响应检查策略、授权读资源 lookup、客户端 IP 封禁策略快照和混合路由评分结果已迁 Redis shared cache；下一步只评估剩余不含凭据且非同步热路径的缓存，包含上游凭据的完整网关运行态、代理 agent、短期重试态继续留内存。
4. 继续迁移清理任务和未覆盖查询入口，迁移一个补一个真实 PG 回归或 readiness；客户端 IP 统计链路已完成，下一步不要重复优化它，除非慢查询或高并发压测证明仍是短板。
5. 本地队列先不要一次性全改 Redis Streams；audit、operation、public API log、record maintenance 和 runtime log index 已完成，账号测试任务表 PG async 链路和账户内 API Key runtime state PG 读写已补齐。下一步只优先评估账号测试执行队列 / 探测执行缓冲是否存在真实积压、重启延迟、取消语义和幂等成本问题。
