## 阅读规则

- 不要从 `docs/deploy/部署指南.md` 开始通读所有内容；先选本目录的场景文档。
- 场景文档只保留该场景需要的部署路径、环境变量、验证点和风险边界。
- 平台文档只回答 Windows、macOS、Linux 的启动、服务化、防火墙和 Docker 差异。
- HTTPS、网络代理、高性能模式和高并发隧道是专题文档，只有当前场景需要时再看。

## 场景边界

- 服务器部署：入口机器本身具备公网 IP、稳定内网入口或可控安全组，Caddy/Nginx 通常和 juhe-ai 在同一台服务器或同一内网。
- 家庭宽带反代：juhe-ai 跑在家里电脑或家用主机上，公网入口可能依赖家庭宽带公网 IP、DDNS、路由器端口映射，或一台公网服务器通过 WireGuard 回源。
- 公网 Edge + 高并发回源的权威参数、生命周期、压测和回滚只由 [反向代理与高并发隧道部署指南](../反向代理与高并发隧道部署指南.md) 维护，场景示例不复制完整配置。
- 两个场景都可能需要 sing-box 账号代理；这是上游 API 访问问题，不是客户端访问入口问题。
