最小可用链路

请求固定经过 API Key、策略路由、分组、AI 账户，再访问上游。第一次配置按以下顺序完成，避免 API Key 指向空策略或未检查账户。

  1. 创建分组：分组是账户集合与供应商过滤边界；只接纳同一供应商的账户。
  2. 创建 AI 账户：填供应商、接入类型、凭据、模型和分组。
  3. 在账户列表执行检查，账户通过后激活；新建或导入的待检查账户不会参与调度。
  4. 创建策略路由：普通策略绑定一个分组；按需要选择权重、故障回退、轮询或混合智能。
  5. 创建 API Key：仅绑定策略路由，设置额度、有效期和时间计划。
  6. 把网关地址、API Key 与模型名填入客户端，再用实际客户端请求完成调用确认；AI 问答使用系统为当前账户维护的专属对话 Key，不替代客户端 API Key。
账户有凭据不等于可用。检查成功并激活后，才会成为策略可调度的上游。

资源配置要点

每一层只负责自己的边界：API Key 不直接绑定账户，策略路由不保存凭据，分组不替代账户的模型与并发配置。

分组

创建时选择供应商和分组类型。个人分组适合稳定低并发；高并发分组适合多人或程序共享调用。分组的供应商必须与加入账户一致。

配置分组
AI 账户

填写真实上游凭据、Base URL、支持模型、并发、代理和分组。Base URL 填服务根地址，不填 /responses、/chat/completions 或 /messages 等具体接口路径。

账户导入与迁移

在我的 AI 账户使用导入。普通用户只导入到自己名下；管理员可在管理账户页选择目标系统账户导入。

  1. 下载协议说明，或把来源数据交给 AI 转换。
  2. 仅粘贴 juhe-ai-account-import v1 JSON；不要粘贴 Markdown 代码块或 CSV。
  3. 先执行“解析预览”，处理字段、分组或重复项提示。
  4. 确认导入。引用不存在的分组可按选项自动创建；同名账户可跳过。

单次请求受约 256KB JSON 请求体限制，最多 50 个账户，最多 20 个代理。导入可包含代理引用，但普通用户不能创建新代理；需要新代理请联系管理员。即使源数据声明 active，导入账户也会创建为 pending_test，检查通过后再激活。协议只需下载阅读，不要复制完整协议正文到业务数据。

给 AI 的转换提示词

请根据我附上的《juhe-ai AI 账户导入协议 v1》Markdown，把下面账号数据转换为 juhe-ai-account-import v1 JSON。

要求：
1. 协议文件优先于你的默认认知；字段名、必填项、枚举值和示例都按协议文件执行。
2. 只输出合法 JSON，不要输出解释、Markdown 代码块或注释。
3. 顶层 type 固定为 juhe-ai-account-import，version 固定为数字 1。
4. 每个账户必须显式填写 name、providerCode、providerProtocolProfileId、type、status、credentials，以及 groupName 或 groupId。
5. API Key 账号使用 type: api_key；GPT OAuth 使用 type: oauth；Gemini Google OAuth 使用 type: google_oauth。
6. providerProtocolProfileId 是协议档案唯一入口；不要根据 base_url、供应商默认值或旧字段猜测档案。
7. 普通 OpenAI v1 账户可以用 modelMappings 显式填写 Responses -> Chat Completions；其他跨协议映射只能写入 providerCode 为 hybrid 的混合供应商账户。
8. 不要编造来源数据里不存在的 token、API Key、邮箱、账号 ID、代理密码或模型列表。
9. 如果有代理，请放到 proxies 数组，并用账号的 proxyRef 引用代理 ref。
10. 不确定的信息放到 notes；无法判断是否可立即调度时 status 填 pending_test 或 disabled。
迁移前确认每个账户的供应商、协议档案、凭据和分组一致；AI 转换只能整理已有数据，不应编造 token 或 API Key。

排障顺序

  1. 账户不可调度：检查账户是否为 active、检查是否成功、是否绑定正确分组。
  2. 模型不可用：在模型目录和账户支持模型中确认模型名与映射。
  3. 调用未按预期分流：确认 API Key 绑定的策略，以及策略绑定的分组。
  4. 请求失败或变慢：依次查看使用记录、AI 健康、AI 性能；必要时查看自己的操作日志。
帮助页只说明可见配置与操作，不展示 API Key 明文、OAuth token、上游凭据或代理密码。
